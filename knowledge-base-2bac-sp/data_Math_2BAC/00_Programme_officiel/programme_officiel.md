# Programme officiel — Maths 2BAC Sciences Physiques (Maroc)

## 1. Place de la matière
- Horaire : **5 h/semaine** (filière SP).
- Examen national : **coefficient 7, durée 3 h, noté /20** (à confirmer via le cadre de référence en vigueur).
- Avec la physique-chimie (coef 7 aussi), les maths décident de la mention — c'est la matière la plus rentable en points.

## 2. Les 14 chapitres exigibles (v1 — à recouper avec le cadre de référence)

### Semestre 1 — Analyse de base + complexes (partie 1)
| # | Chapitre (dossier) | Notions exigibles |
|---|---|---|
| 01 | Limites et continuité | Limites finies/infinies, opérations, formes indéterminées, limites usuelles, continuité, TVI + corollaire (solution unique), prolongement par continuité |
| 02 | Dérivation et étude de fonctions | Dérivabilité (taux d'accroissement), fonctions dérivées, variations, extrema, branches infinies/asymptotes, concavité (selon cadre), représentation graphique |
| 03 | Suites numériques | Convergence (définitions, théorèmes), monotonie, suites arithmétiques/géométriques, suites récurrentes $u_{n+1} = f(u_n)$, suites adjacentes, raisonnement par récurrence |
| 04 | Fonctions primitives | Définition, primitives usuelles, opérations — outil pour le calcul intégral |
| 05 | Fonction logarithme népérien | Définition via primitive de $1/x$, propriétés algébriques, étude de $\ln$, équations/inéquations, limites et croissances comparées |
| 06 | Nombres complexes (partie 1) | Forme algébrique, opérations, conjugué, module, interprétation géométrique de base, équations du 2nd degré dans $\mathbb{C}$ |

### Semestre 2 — Fonctions, complexes (partie 2), intégrales, géométrie, probas
| # | Chapitre | Notions exigibles |
|---|---|---|
| 07 | Fonctions exponentielles | $\exp$ (réciproque de $\ln$), propriétés, étude, fonctions $a^x$ / $x^n$ / puissances, croissances comparées |
| 08 | Nombres complexes (partie 2) | Forme trigonométrique, argument, forme exponentielle $re^{i\theta}$, formule de Moivre, racines $n$-ièmes (selon cadre), transformations (translation, rotation, homothétie) |
| 09 | Calcul intégral | Intégrale et aire, propriétés (linéarité, positivité, ordre), intégration par parties (IPP), calcul d'aires/volumes simples, valeur moyenne |
| 10 | Équations différentielles | $y' = ay + b$, $y'' + \omega^2 y = 0$ (cadre SP — recouper : certaines formes sont réservées SM) |
| 11 | Produit scalaire dans l'espace | Définitions, orthogonalité, équation cartésienne de plan, sphères, distances (point-plan) |
| 12 | Produit vectoriel dans l'espace | Définition, déterminant, équations de plans/droites, positions relatives, distances |
| 13 | Dénombrement | Principe multiplicatif, arrangements, permutations, combinaisons $\binom{n}{p}$, triangle de Pascal |
| 14 | Probabilités | Probabilités conditionnelles, indépendance, formule des probabilités totales, variable aléatoire (loi, espérance), loi binomiale |

## 3. Format de l'épreuve nationale (structure typique SP — à confirmer Phase 3)

- **Durée 3 h, /20**, en général **4 à 5 exercices indépendants** :
  1. **Problème d'analyse (≈ 7-8 pts, le morceau)** : étude de fonction (ln/exp) + suite liée + parfois intégrale — tout s'enchaîne, ne pas bloquer sur une question.
  2. **Nombres complexes (≈ 3 pts)** : calculs + équations + interprétation géométrique.
  3. **Géométrie dans l'espace (≈ 3 pts)** : plans, orthogonalité, distances.
  4. **Probabilités (≈ 2-3 pts)** : arbre + conditionnelles + loi binomiale.
  5. Question de cours / QROC possible (énoncé précis d'un théorème : TVI, primitives, etc.).
- Compétences : **calcul exact, raisonnement rédigé (récurrence, contraposée), figure propre, conclusion chiffrée**. Voir `15_Methodologie/`.
