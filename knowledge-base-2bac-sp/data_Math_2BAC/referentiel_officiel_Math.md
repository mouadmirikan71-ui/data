# Référentiel officiel — Maths 2BAC SP (cadre de référence + verdict structure)

> Sources : cadre de référence 2015 (options internationales, Sciences Expérimentales — SP+SVT),
> PDF AlloSchool element/89455 (8 p., vérifié 2026-09-15) ; cadre adapté 2020 element/106779 (COVID uniquement).
> Le cadre 2015 reste la référence en vigueur (aucune refonte publiée depuis).

## 1. Format de l'épreuve

- **Durée 3 h, coefficient 7 (SP)**, 5 h/semaine. Sujet commun SP+SVT (même énoncé national).
- **Format stable observé** : 4–5 exercices — **problème d'analyse 7–8 pts** (étude de fonction + suites + intégrale,
  parfois ED), **complexes ~3 pts**, **géométrie espace ~3 pts**, **probabilités ~2–3 pts**.

## 2. Domaines exigibles (cadre 2015)

### Analyse — 55 %

| Sous-domaine | Savoirs exigibles (repères cadre) | Chapitre base |
|---|---|---|
| Suites | arithmétiques/géométriques, $u_{n+1}=au_n+b$, homographiques $(au_n+b)/(cu_n+d)$, limites + critères, $v_n=f(u_n)$, récurrentes $u_{n+1}=f(u_n)$ ($f(I)\subset I$) + limite | M03 |
| Continuité/dérivation/étude | continuité + TVI (+ unicité si strictement monotone), image d'intervalle, dérivabilité, **fonction réciproque** (dérivée, monotonie, graphe), min/max, **$f'$ et $f''$** (concavité, points d'inflexion), primitives usuelles, **ln + log décimal** ($10^x=a$), **exp**, branches infinies, symétries | M01, M02, M04, M05, M07 |
| Équa. différentielles | $y'=ay+b$ ET **$y''+ay'+by=0$** (ordre 2 complet) | M10 |
| Calcul intégral | primitives, **IPP**, propriétés, **aires entre courbes, volumes de révolution** (rotation autour de $Ox$) | M09 |

### Algèbre et géométrie

| Sous-domaine | Savoirs exigibles | Chapitre base |
|---|---|---|
| Produit scalaire $V_3$ + espace | orthogonalité (vectoriel + analytique), plan (point + normal), droite ⊥ plan (paramétrique), sphères (centre/rayon, équation $x^2+y^2+z^2+ax+by+cz+d=0$, $MA\cdot MB=0$), distance point-plan, positions relatives | M11 |
| Produit vectoriel | aire triangle, plan par 3 points, distance point-droite, problèmes géométriques | M12 |
| Complexes | calcul (3 écritures), algébrique↔trigo, **linéarisation** (via forme expo), géométrie (distances, angles, alignement, colinéarité, orthogonalité), **translation/homothétie/rotation** (exprimer + reconnaître), $az^2+bz+c=0$ (coeffs réels) + ramenées au 2nd degré | M06, M08 |
| Probabilités | **dénombrement** adapté, $P(A\cup B)$, contraire, intersection, **conditionnelles**, indépendance, **loi d'une VA + paramètres** ($E$, $V$, $\sigma$), **loi binomiale** | M13, M14 |

### Niveaux d'habileté (barème-cible)

- **50 %** application directe (définition, formule, technique) ; **35 %** connaissances non explicites en situation habituelle ;
  **15 %** situations inhabituelles (synthèse). → Un élève « technique » (sans génie) vise ~10–12/20.

## 3. ⛔ Exclus du SP (réservés SM) — correctement absents de la base

Arithmétique (congruences, Bézout…), structures algébriques, espaces vectoriels généraux. Toute apparition = hors-programme SP.

| # | Gap vs cadre | Gravité | Action |

Couverts ✅ : TVI (M01), concavité/inflexion (M02), homographiques (M03), IPP (M09), rotations/homothéties (M08),
