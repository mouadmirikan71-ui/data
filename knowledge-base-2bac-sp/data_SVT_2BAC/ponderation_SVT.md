## 1. Format réel (vérifié Tier A, ≠ lecture naïve du cadre)

- **Partie I — Restitution des connaissances : 5 pts**, UN seul domaine (D1/D2/D3/D4).
  Items : définitions, QCM, vrai/faux, schéma annoté, texte lacunaire.
- **Partie II — Raisonnement scientifique : 15 pts** couvrant les **3 autres domaines** :
  - soit **3 exercices 5/5/5** (un par domaine) — ex. 2022R ;
  - soit **4 exercices 5 / 2,5 / 2,5 / 5** — le split 2,5+2,5 porte **toujours sur D2**
    (D2a génétique moléculaire 2,5 + D2b lois de transmission 2,5) — 2023N, 2023R.
- **Invariant : les 4 domaines tombent TOUJOURS, 5 pts chacun.** La pondération
  par domaine est donc PLATE (25 % × 4) ; toute la différenciation se joue
  **intra-domaine** (quel chapitre ?) et sur la **rotation de la restitution**.
- Exception COVID : 2021R = restitution **6 pts** (D3) + raisonnement **14 pts**
  (Ex1 D1 6 pts, Ex2 D2a 3,5, Ex3 D2b 4,5), **D4 géologie absent**. 2020R même
  logique allégée (restitution D1 + raisonnement D1 : métabolisme musculaire,
  cycle de Krebs). Ces 2 sessions servent aux MOTIFS, pas aux moyennes.

## 5. Motifs récurrents par exo-type (le « barème caché »)

- **D1 raisonnement** : myogrammes + tétanos parfait/imparfait (S02) ;
  mitochondrie/O₂/ATP, inhibiteurs (cyanure, complexe IV), fermentation vs
  respiration, glycogène/myophosphorylase (S01). Maladie-type : myopathie,
  NARP mitochondriale.
- **D2a** : maladie monogénique (HCF/LDLR, Xeroderma/XPC, Wilson/ATP7B, MCR1) →
  relation protéine-caractère → **code génétique (table)** → mutation ponctuelle.
- **D2b** : 2 croisements (dominance, X-linked, liés vs indépendants) → test-cross →
  **échiquier de croisement** → % recombinés → **carte factorielle** (drosophile,
  porc) ; schéma crossing-over parfois exigé.
- **D3 raisonnement** : site marocain réel (Meknès, Marrakech) : DBO5/DCO/O₂ dissous,
  **normes OMS**, lixiviats, métaux lourds, microplastiques/bioaccumulation,
  bioplastiques. Restitution : définitions + QCM/V-F salubrité.
- **D4 raisonnement** : massif réel (Arize/Pyrénées, Chenaillet) : ophiolites,
  collision/subduction/obduction, **métamorphisme P-T**, lecture carte/coupe.
  Restitution : prisme d'accrétion, gneiss, faille.
