## 2. Règles de sélection

1. **4 domaines obligatoires** : chaque séance touche D1+D2+D3+D4 (jamais
   d'impasse : chaque domaine vaut 5/20 à coup sûr).
2. **Lacunes d'abord** : tout chapitre < 50 % passe devant, quel que soit son poids.
3. **Poids arbitre** : à lacune égale, priorité au poids le plus fort.
4. **Supports via porteurs** : S03/S05 travaillés VIA exos S04/S06 (jamais seuls) ;
   S09 via restitution D3 ; S11/S13 via restitution D4 + exos S10/S12.
5. **Double compétence** : chaque chapitre révisé sous ses 2 formes — restitution
   (définitions/QCM/schéma) ET raisonnement (exo national) — car tout domaine
   peut tomber en Partie I.
6. **Motifs imposés** : code génétique (S04), échiquier + carte factorielle (S06),
   myogrammes (S02), normes OMS/DBO5/DCO (S07/S08), lecture P-T/coupe (S10/S12)
   : ≥ 1 passage/séance en alternance.
7. **Trend-boost** : restitution D4 en priorité (absente depuis 2022R) ; D3 « site
   marocain + normes » systématique.

## 3. Séance-type 2 h (IA teacher)

- 30 min : D1 — alterner exo mito/énergie (S01) et myogrammes (S02) + 5 QCM restitution.
- 35 min : D2 — 1 D2a (maladie→code génétique) + 1 D2b (croisement→échiquier→carte).
- 30 min : D3 — site réel + paramètres eaux/normes (S07/S08) + flash définitions (S09).
- 25 min : D4 — massif + ophiolites/P-T (S10/S12) + flash restitution (S11/S13).
