# Référentiel officiel — SVT 2BAC SP (cadre de référence + verdict structure)

> Source : cadre de référence 2015 (options internationales, Sciences Expérimentales filière SP),
> PDF AlloSchool element/48555 (20 p., vérifié 2026-09-15). Référence en vigueur.

## 1. Format de l'épreuve (2 h, coef 2)

| Partie | Contenu | Barème |
|---|---|---|
| **I — Restitution des connaissances** | QCM, vrai/faux, appariement, réponses courtes, définitions, légendes — sur **UN** des 4 domaines | **5 pts** (25 %) |
| **II — Raisonnement scientifique** | **3 exercices × 5 pts**, chacun sur un domaine **différent** (ni Partie I, ni les autres exos) : exploitation de données, démarche scientifique, schémas, communication | **15 pts** (75 %) |

**Conséquence clé** : les **4 domaines tombent TOUJOURS** (5 pts chacun) — la rotation porte sur
*qui passe en restitution (facile) vs en raisonnement (dur)*. La pondération = analyse de cette rotation
+ rotation des sous-thèmes (vrai/faux ciblés, exercices-types par domaine).

## 2. Domaines exigibles → chapitres base

| Domaine (5 pts/sujet, toujours) | Contenus cadre | Chapitres |
|---|---|---|
| **D1** Conso matière organique + flux énergie | Respiration (glycolyse, Krebs, chaîne respiratoire, bilans) vs fermentation (bilans, rendements) ; mitochondrie ; **muscle strié** (myogramme, secousse/tétanos, ultra-structure, mécanisme contraction, régénération ATP) ; schéma bilan ATP | S01, S02 |
| **D2** Info génétique + reproduction | Mitose/interphase, cycle cellulaire, ADN (structure, réplication), gène/allèle/mutation, **code génétique**, transcription/traduction ; méiose + fécondation (brassages, caryotype) ; **Mendel** (monohybridisme auto + lié au sexe, dihybridisme gènes indépendants/liés, crossing-over, **carte factorielle**) | S03, S04, S05, S06 |
| **D3** Matières organiques/inorganiques | Ordures ménagères (tri, recyclage, impacts) ; pollutions (milieux pollués, alternatives) ; **radioactivité** (avantages, dangers, déchets nucléaires, alternatives) ; contrôle qualité/salubrité des milieux | S07, S08, S09 |
| **D4** Chaînes de montagnes + tectonique | Chaînes subduction/obduction/collision (pétrographie, reconstitution) ; **déformations** (contraintes) ; **métamorphisme** (minéral index, séries, dynamique vs thermodynamique) ; **granitisation** (anatexie vs intrusif, lien métamorphisme) ; schéma bilan | S10, S11, S12, S13 |
