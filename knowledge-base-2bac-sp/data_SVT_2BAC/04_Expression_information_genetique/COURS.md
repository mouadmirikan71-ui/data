# Chapitre 04 — Expression de l'information génétique

> 📋 **Exigible au bac (cadre de référence)** : Transcription (ARNm), code génétique, traduction (ribosome, ARNt), mutations et conséquences (faux-sens, non-sens, décalage)
> *Source : `00_Programme_officiel/programme_officiel.md` (v1 — à recouper avec le PDF officiel en Phase 3).*

## 1. Accroche — une image de la vraie vie 🍳

**FR :** Une caille japonaise naît avec un plumage rouge-jaune au lieu de noir-brun (national 2017 !). Un enfant ne peut pas réparer son ADN et développe des cancers de la peau (national 2023 !). Dans les deux cas, la cause tient en **quelques lettres d'ADN changées** : la recette (gène) a une faute de frappe → le cuisinier (ribosome) suit la recette fautive → le plat (protéine) est raté → le caractère change. Ce chapitre raconte comment la cellule **LIT** le manuel du Ch.03 pour **fabriquer des protéines**.

**بالدارجة:** سمانة (caille) تزادت بريش حمر-صفر بدل الكحل-قهوي (وطني 2017!)، وطفل ما كيقدرش يصلح الـ ADN ديالو وكيمرض بسرطان الجلد (وطني 2023!). فالحالتين السبب هو **حروف قلال تبدلو فالدفتر**: الوصفة (الجين) فيها غلطة مطبعية ← الطباخ (الريبوزوم) تبع الوصفة الغالطة ← الطبق (البروتين) خرج خاسر ← الصفة تبدلات. هاد الفصل كيحكي كيفاش الخلية **كتقرا** الدفتر ديال الفصل 3 باش **تصنع البروتينات**.

## 2. Résumé du cours (français, exigible au bac)

### 2.1 La transcription : copier UNE recette (noyau)
- Lieu : **noyau**. On copie le **brin transcrit (matrice, lu 3'→5')** en **ARNm** (synthétisé 5'→3').
- Règles : complémentarité avec **U à la place de T** (A→U, T→A, C→G, G→C).
- **Point crucial** : l'ARNm ressemble au brin **NON transcrit (codant)** à U près — c'est LUI qu'on lit comme les codons (national 2017 : l'énoncé donne le non-transcrit, l'ARNm s'en déduit directement !).
- L'ARNm sort du noyau vers le **cytoplasme** (chez les eucaryotes ; pas de maturation détaillée exigée au niveau PC).

### 2.2 Le code génétique : le dictionnaire
- **Codon** = triplet de nucléotides de l'ARNm = **1 acide aminé** (ou STOP : UAA, UAG, UGA).
- Propriétés : **universel** (même code pour presque tout le vivant), **redondant/dégénéré** (plusieurs codons → même AA, ex. AAA et AAG → Lys), non chevauchant, lecture par triplets à partir d'un cadre.
- Au national, le tableau (ou un extrait) est **toujours fourni** — il faut savoir le LIRE, pas le réciter.

### 2.3 La traduction : cuisiner la protéine (cytoplasme)
- Lieu : **cytoplasme**, acteurs : **ribosome** (le cuisinier) + **ARNt** (les livreurs, portant chacun 1 AA + 1 **anticodon** complémentaire du codon).
- Étapes : **initiation** (codon start AUG, assemblage) → **élongation** (les ARNt apportent les AA dans l'ordre des codons, liaisons peptidiques) → **terminaison** (codon **STOP** → libération de la protéine).
- Sens : ARNm lu **5'→3'**, protéine synthétisée de l'extrémité N-terminale vers C-terminale.

### 2.4 Les mutations : fautes de frappe et conséquences
| Type | Exemple | Effet sur la protéine |
|---|---|---|
| **Silencieuse** (substitution) | AAA→AAG (Lys→Lys) | Aucun (même AA, code redondant) |
| **Faux-sens** (substitution) | AAA(Lys)→CAA(Gln) — cas XP 2023 R ! | 1 AA changé → protéine modifiée (ici : xpc inactive) |
| **Non-sens** (substitution) | …→UAA (STOP) | Protéine **tronquée** (stop prématuré) |
| **Décalage** (délétion/insertion non multiple de 3) | Délétion 7 nt — cas Mc1-R 2017 N ! | TOUT l'aval change + souvent un STOP apparaît → protéine méconnaissable |
- **Relation gène → protéine → caractère** (question 2017 N !) : le gène code une protéine ; une protéine altérée change la fonction cellulaire ; la fonction change le **caractère observable** (plumage, réparation de l'ADN...).

### 2.5 Schémas à savoir refaire (décrits en texte pour le RAG)
- **Schéma transcription** : portion d'ADN ouverte, brin transcrit (3'→5') vs brin codant, ARNm naissant (5'→3', avec U), flèche noyau→cytoplasme.
- **Schéma traduction** : ribosome à cheval sur l'ARNm, 2 ARNt (anticodons appariés aux codons), chaîne d'AA qui s'allonge, codon STOP en attente.
- **Schéma mutation-décalage** : triplets alignés avant/après délétion d'1 lettre, cadres décalés en couleur, STOP prématuré marqué.

## 3. الشرح بالدارجة — كيفاش تشرحها لأي واحد 🇲🇦

**الفكرة الكبيرة:** الخلية **مطبخ**: الوصفات (الجينات) محفوظين فالخزنة (النواة)، والطباخ (الريبوزوم) خدام فالكوزينة (السيتوبلازم):

1. **النسخ (transcription):** الخلية ما كتخرجش الدفتر الأصلي من الخزنة — كتصور **ورقة وحدة** (ARNm) من الوصفة المطلوبة وكتصيفطها للكوزينة. القاعدة: الورقة كتشبه الشريط **غير المنسوخ** (codant) مع U بدل T. هاد النقطة كطيح فالوطني — اللي خدم بالشريط الغالط خرج ليه كلشي مقلوب!
2. **القاموس (code génétique):** كل **3 حروف** (codon) = حمض أميني واحد. القاموس عالمي (نفسو عند البشر والبكتيريا!) وفيه ترادف: بزاف ديال الكلمات كيعنيو نفس الحاجة (AAA وAAG = Lys). فالوطني القاموس **كيعطى** — خاصك غير تعرف تقراه!
3. **الترجمة (traduction):** الطباخ (الريبوزوم) كيقرا الورقة 3 حروف بـ 3 حروف، والخدامة (ARNt) كيجيبو المكونات (الأحماض الأمينية) بالترتيب، حتى كيوصل لكلمة **قف (STOP)** وكيحبس — الطبق (البروتين) واجد!
4. **الغلطات (mutations):** غلطة مطبعية فالوصفة:
   - **صامتة**: الكلمة تبدلات ولكن المعنى بقى (AAA→AAG = Lys) — لا تأثير!
   - **مغيرة للمعنى (faux-sens)**: مكون تبدل (Lys→Gln فمرض XP) — الطبق تبدل!
   - **وقوف مبكر (non-sens)**: ظهرت كلمة «قف» فالوسط — طبق ناقص!
   - **إزاحة (décalage)**: تحذفات حروف (7 فحالة Mc1-R) — **كلشي من بعد الغلطة تخربق** + غالباً كيبان «قف» — الطبق ما كيتعرفش!

**القاعدة الذهبية:** **الجين → البروتين → الصفة.** أي سؤال «اشرح العلاقة» الجواب فيه هاد السلسلة: الغلطة فالدفتر ← بروتين مخربق ← وظيفة خاسرة ← صفة باينة (الريش، المرض...).

## 4. How to understand this chapter the easy way 🎯
*(بصوت الأستاذ فالقسم — تقراه بصوت عالي)*

**الخطوة 1 — سول راسك: شنو الفرق بين هاد الفصل واللي قبلو؟**
الفصل 3: **نسخ الدفتر كامل** (réplication) باش يتقسم على البنات. هاد الفصل: **قراءة ورقة وحدة** (transcription) باش تصنع بروتين. **نسخ ≠ قراءة!** اللي خلط بيناتهم ضاع فالنص. حفظ: 3 = photocopie du manuel, 4 = lecture d'une recette.

**الخطوة 2 — حفظ الترتيب: خزنة ← ورقة ← كوزينة.**
ADN (النواة) ← ARNm (الرسول) ← ريبوزوم + ARNt (السيتوبلازم) ← بروتين ← صفة. أي سؤال «اشرح التعبير» كتجاوب بهاد السلسلة من الأول للآخر.

**الخطوة 3 — فهم «علاش» زوج حوايج.**
- علاش الورقة (ARNm) كتشبه الشريط **غير** المنسوخ؟ حيت المنسوخ هو **القالب** (كيتقرا)، والورقة هي **النسخة المعكوسة ديال القالب** — والمعكوس ديال المعكوس = الأصل! (شريط codant ≈ ARNm). هادي هي اللي كتخلي تمرين 2017 ساهل: عطاوك codant = عطاوك ARNm تقريباً!
- علاش حذف حرف واحد أخطر من تبديل حرف؟ حيت التبديل كيخرب **كلمة وحدة**، والحذف كيخرب **الترقيم كامل** من بعدو (décalage) — بحال SMS بلا فراغات: حذف حرف = كل الكلمات اللي موراه تخربقو!

**الخطوة 4 — تشبيه واحد يعاونك فالوطني.**
**المطبخ:** الدفتر = كتاب الطبخ فالخزنة. ARNm = ورقة مصورة من وصفة وحدة. الريبوزوم = الطباخ. ARNt = الخدامة اللي كيجيبو المكونات. STOP = كلمة «صافي، قدم الطبق!». والطفرة = غلطة فالوصفة المصورة. ملي تشوف تمرين فيه تسلسل + قاموس، سول راسك: **شنو مكتوب فالورقة؟ وشنو غادي يطيب الطباخ؟**

**الخطوة 5 — ثبت بالتسلسلات.**
هاد الفصل **تطبيقي**: 90% ديال الأسئلة = عطاوك تسلسل + قاموس ← جبد ARNm ← جبد الأحماض ← حدد الطفرة. تدرب على تمريني 2017 (Mc1-R) و2023 (XP) اللي فملف التمارين — ملي تضبطهم، أي تسلسل وطني غادي يبان ليك مألوف!

## 6. FAQ du chapitre (questions que les élèves posent vraiment)

**Q1. Brin transcrit ou non transcrit — lequel utiliser ?**
Ça dépend de la consigne ! Si on donne le **transcrit** (matrice) → ARNm = **complémentaire** (XP 2023). Si on donne le **non-transcrit** (codant) → ARNm = **recopie** + T→U (Mc1-R 2017). Lire l'énoncé AVANT de calculer !
على حساب المعطى! المنسوخ = الورقة هي **المعكوس**، وغير المنسوخ = الورقة هي **النقل** مع U. قرا السؤال اللول!

**Q2. Codon ou anticodon ?**
**Codon** = sur l'ARNm (ce qu'on lit) ; **anticodon** = sur l'ARNt (qui s'apparie). Le ribosome fait se rencontrer les deux.
الكودون فالورقة (المقروء)، والأنتيكودون فالخدام (المطابق).

**Q3. Toute mutation est-elle grave ?**
Non ! **Silencieuse** = aucun effet (redondance). Gravité croissante : silencieuse < faux-sens < non-sens ≈ décalage (tout l'aval + stop fréquent).
لا! الصامتة = والو. الخطورة كتطلع: صامتة < مغيرة < وقوف ≈ إزاحة.

**Q4. Pourquoi une délétion de 3 nucléotides est-elle moins grave ?**
Parce que 3 = un codon entier : on perd **1 seul AA**, le cadre est **conservé**. Le décalage n'existe que si le nombre ≠ multiple de 3.
حيت 3 = كلمة كاملة: كضيع غير مكون واحد والترقيم كيبقى! الإزاحة غير ملي العدد ماشي من مضاعفات 3.

**Q5. Où ont lieu transcription et traduction ?**
Transcription : **noyau** (l'ADN ne sort jamais). Traduction : **cytoplasme** (ribosomes). L'ARNm fait le voyage entre les deux.
النسخ فالنواة (الدفتر ما كيخرجش)، والترجمة فالسيتوبلازم (الطباخة تماك) — والورقة هي الرسول!

**Q6. C'est quoi la relation gène-protéine-caractère ? (question 2017 !)**
Le **gène** code une **protéine** ; la protéine assure une **fonction** ; la fonction détermine le **caractère**. Mutation → protéine altérée → fonction perturbée → caractère modifié (plumage Mc1-R, réparation XP).
الجين كيصنع البروتين، والبروتين كيدير الوظيفة، والوظيفة كتبان كصفة. الغلطة ← بروتين خاسر ← وظيفة معطوبة ← صفة متبدلة!

## 7. Mots-clés obligatoires + erreurs fréquentes ⚠️

**À placer absolument** : noyau/cytoplasme, brin transcrit (3'→5') / codant, ARNm (5'→3', U), codon/anticodon, ribosome/ARNt, AUG/START, STOP (UAA-UAG-UGA), substitution (silencieuse/faux-sens/non-sens), délétion/décalage, gène→protéine→caractère.
**Erreurs qui coûtent cher** :
- ARNm avec des T ❌ (l'ARN a U, jamais T).
- Utiliser le mauvais brin (transcrit vs codant) ❌ — lire la consigne !
- Oublier le sens 5'→3' de l'ARNm ❌ (séquence à l'envers = AA faux).
- Dire que toute substitution change la protéine ❌ (silencieuses existent !).
- Confondre codon (ARNm) et anticodon (ARNt) ❌.
- Traiter une délétion comme une simple substitution ❌ (décalage = tout l'aval !).

## 9. 🚀 Pour aller plus loin — le pourquoi que les manuels sautent (niveau maître)

**P1. Pourquoi le code génétique est-il redondant (64 codons pour 20 AA) ?**
C'est un **tampon anti-erreurs** : la 3e base du codon est souvent « flexible » (wobble) — AAA et AAG donnent tous deux Lys. Résultat : une mutation sur la 3e base est **souvent silencieuse**. La nature a préféré un dictionnaire avec des synonymes plutôt qu'un code minimal fragile : la redondance absorbe les fautes de frappe. C'est le même principe que la redondance en informatique (bits de parité) !
بالدارجة: القاموس فيه **مترادفات** باش يمتص الغلطات! الحرف الثالث غالباً ما مهمش (AAA وAAG = Lys) — يعني غلطة فالثالث كدوز صامتة. الطبيعة اختارت قاموساً فيه احتياط بدل قاموس هش — بحال النسخ الاحتياطي فالمعلوميات!

**P2. Pourquoi UNE seule base changée peut tout casser — ou ne rien faire ?**
Tout dépend de **OÙ** : même codon, 3 destins — (a) 3e base redondante → silencieuse (rien) ; (b) 1ère/2e base → faux-sens (1 AA changé, gravité variable) ; (c) création d'un STOP → non-sens (protéine coupée, souvent catastrophique). **La position compte plus que la taille** : une substitution bien placée (non-sens) est pire qu'une délétion de 3 nt ! C'est exactement ce que teste le national quand il demande « expliquer l'origine génétique » (XP 2023 : Lys→Gln = 1 AA, mais l'enzyme entière est morte).
بالدارجة: **البلاصة أهم من الحجم!** نفس التبديل: فالحرف الثالث = والو، فاللول = مكون تبدل، وخلق «قف» = كارثة! لهدا الوطني كيسول «اشرح الأصل الوراثي» — الجواب ماشي «كاينة طفرة» بل **شنو بدلات هاد الطفرة بالضبط**.

**P3. Pourquoi le décalage est-il si dévastateur ? (pire que la taille perdue)**
Parce que le ribosome lit **aveuglément par triplets** sans ponctuation : enlever 1 lettre décale TOUS les triplets suivants — des dizaines d'AA changés + quasi-certitude de tomber sur un STOP prématuré. Perdre 7 nucléotides (Mc1-R) ne fait pas perdre « 2-3 AA » : ça **réécrit toute la fin** de la protéine. Démo : THE BIG CAT (3 codons) → enlever H → TEB IGC AT (3 codons méconnaissables). Le cadre de lecture, une fois perdu, ne se retrouve jamais.
بالدارجة: الريبوزوم كيقرا **بعمى 3 بـ 3** بلا نقط! حذف حرف واحد = كل الكلمات اللي موراه تخربقو + غالباً «قف» كيبان. خسارة 7 حروف (Mc1-R) ماشي خسارة 2 أحماض — هي **إعادة كتابة النهاية كاملة**!

## 10. 😶‍🌫️ Les confusions garanties (quand les yeux se voilent)

**C1. « L'ARNm est la copie du brin transcrit »** — Non, et c'est LE piège du chapitre : l'ARNm est le **complémentaire** du transcrit (matrice), donc la **copie** du NON-transcrit (codant, à U près). Test : « l'énoncé donne le codant CAG → l'ARNm commence par ? » → CAG (recopie + U). Si l'élève répond GUC (complément), il a pris le mauvais brin — le ramener au schéma §2.5.
**C2. « Codon = anticodon »** — Non : le **codon** est le mot LU (sur l'ARNm), l'**anticodon** est la clé qui S'EMBOÎTE (sur l'ARNt). Question qui dissout : « qui porte l'acide aminé ? » → L'ARNt (donc l'anticodon est du côté du livreur, pas du message).
**C3. « Mutation = maladie grave, toujours »** — Non : la plupart des substitutions sont **silencieuses** (redondance) ou neutres. La gravité dépend du TYPE (silencieuse < faux-sens < non-sens ≈ décalage) et de la FONCTION de la protéine. XP est grave non parce qu'il y a « une mutation », mais parce que l'enzyme de réparation est morte.

## 11. 🧭 Signaux adaptatifs (pour l'AI teacher)

**Carte des prérequis (ordre obligatoire) :**
`complémentarité A-U/C-G (CH.03) → brin transcrit vs codant (LES 2 BRINS) → ARNm 5'→3' (LE MESSAGE) → code/codons (LE DICTIONNAIRE) → ribosome + ARNt (LA CUISINE) → protéine → mutation (LA FAUTE)`
- Si l'élève rate les **séquences d'AA** → redescendre aux **2 brins** (il utilise le mauvais dans 80 % des cas).
- Si l'élève bloque sur les **mutations** → vérifier le **code** (sans codons/STOP, « faux-sens » ne veut rien dire).
- Si l'élève mélange **transcription/traduction** → revenir aux **lieux** (noyau vs cytoplasme : 2 pièces = 2 étapes).

**🔄 Angle de secours (si le décalage ne passe pas) : le SMS sans espaces.**
Oublie la biologie : écris THEBIGCAT (lis THE-BIG-CAT). Enlève UNE lettre (H) : TEBIGCAT → lis TEB-IGC-AT : **aucun mot d'origine ne survit**. Puis montre qu'enlever 3 lettres (BIG) : THECAT → THE-CAT : les mots restants sont intacts ! L'élève VOIT alors : non-multiple-de-3 = catastrophe, multiple-de-3 = perte locale. Remapper ensuite : lettres = nucléotides, mots = codons.
