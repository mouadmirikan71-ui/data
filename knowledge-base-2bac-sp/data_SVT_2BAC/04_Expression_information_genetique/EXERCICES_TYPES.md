## Question 1 — VRAIE (2017 N, Ex.1 Q1, 1 pt)

🏷️ matière=SVT · année=2017 · session=N · chapitre=S4 · type=VRAIE · fidélité=reconstitué-corrigé · niveau=— · barème=voir énoncé
**Données :** brin **NON transcrit** de l'allèle normal (triplets 225-234) : CAG CCC ACC ATC TAC CGC ACC AGC AGC CTG + tableau du code génétique fourni.
**Énoncé officiel :** « En utilisant le tableau du code génétique, **donnez** le brin d'ARNm et la séquence d'acides aminés correspondante (triplet 225 au triplet 234). »

**Corrigé :**
1. Identifier le brin : **non transcrit = codant** → l'ARNm s'obtient par **recopie + T→U** (pas de complément !).
2. ARNm 5'→3' : $\boxed{\text{CAG CCC ACC AUC UAC CGC ACC AGC AGC CUG}}$
3. Lire le code codon par codon : CAG→Gln, CCC→Pro, ACC→Thr, AUC→Ile, UAC→Tyr, CGC→Arg, ACC→Thr, AGC→Ser, AGC→Ser, CUG→Leu.
4. Séquence : $\boxed{\text{Gln - Pro - Thr - Ile - Tyr - Arg - Thr - Ser - Ser - Leu}}$
> بالدارجة: عطاوك الشريط **غير المنسوخ** = عطاوك الجواب تقريباً! غير نقل + بدل T بـ U. اللي دار المعكوس (complément) خدم بالشريط الغالط — **قرا نوع الشريط قبل ما تحسب!**

## Question 2 — VRAIE (2017 N, Ex.1 Q2, 1.25 pt)

🏷️ matière=SVT · année=2017 · session=N · chapitre=S4 · type=VRAIE · fidélité=reconstitué-corrigé · niveau=— · barème=voir énoncé
**Données :** allèle mutant (délétion) : CAG CCC ACC GCA CCA GCA GCC TGA → AA : Gln - Pro - Thr - Ala - Pro - Ala - Ala (+ UGA = STOP).
**Énoncé officiel :** « **Déterminez** l'emplacement et le nombre des nucléotides perdus par délétion, puis **montrez** la relation caractère – gène. »

**Corrigé :**
1. Aligner normal vs mutant : début identique CAG CCC ACC (triplets 225-227), puis ça diverge.
2. Retrouver la suite du mutant (GCA CCA GCA GCC TGA) dans le normal : elle correspond à la fin de 230 (…G) + 231-234 décalés → nucléotides perdus : **ATC TAC C** = triplets 228-229 entiers + 1er nt du triplet 230.
3. Nombre : $\boxed{\text{7 nucléotides}}$ → 7 ≠ multiple de 3 → **décalage du cadre de lecture** (nouveaux AA + STOP prématuré UGA).
> ✅ **Vérifié conforme au corrigé officiel** (2017 N, ÉlémDAQts de réponse Ex.1 Q2 : « Délétion de sept nucléotides : les six nucléotides des triplets 228 et 229 avec le premier nucléotide du triplet 230… (ou ATC TAC C du brin non transcrit) »). ARNm et séquence AA également vérifiés identiques au corrigé officiel.
4. Relation caractère-gène : le gène Mc1-R code le pigment (eumélanine) ; l'allèle muté code une protéine **différente** (phéomélanine) → plumage **rouge-jaune** au lieu de noir-brun. $\boxed{\text{mutation → protéine modifiée → caractère modifié}}$.
> بالدارجة: الطريقة: **طابق البداية، وقلب على فين رجعات التطابق** — اللي بيناتهم هو المحذوف (7 حروف)! و7 ماشي من مضاعفات 3 = **إزاحة** = كلشي تخربق + STOP. والعلاقة: الجين ← البروتين ← الصفة (الريش)!

## Question 3 — VRAIE (2023 R, Ex.1 Q2, 1.5 pt)

🏷️ matière=SVT · année=2023 · session=R · chapitre=S4 · type=VRAIE · fidélité=verbatim · niveau=— · barème=voir énoncé
**Données :** brin **TRANSCRIT** — normal : ACG-CTC-CTT-AAG-TTT-CTG ; anormal : ACG-CTC-CTT-AAG-GTT-CTG + extrait du code.
**Énoncé officiel :** « **Donner** la séquence de l'ARNm et des acides aminés pour chacun des deux allèles et **expliquer** l'origine génétique de la maladie. »

**Corrigé :**
1. Identifier : brin **transcrit** → ARNm = **complémentaire** (A→U, T→A, C→G, G→C).
2. ARNm normal : $\boxed{\text{UGC - GAG - GAA - UUC - AAA - GAC}}$ → AA : $\boxed{\text{Cys - Glu - Glu - Phe - Lys - Asp}}$
3. ARNm anormal : $\boxed{\text{UGC - GAG - GAA - UUC - CAA - GAC}}$ → AA : $\boxed{\text{Cys - Glu - Glu - Phe - Gln - Asp}}$
4. Mutation : TTT→GTT sur l'ADN (substitution T→G) → AAA→CAA sur l'ARNm → **Lys→Gln** : **faux-sens** (1 AA changé).
5. Origine génétique : l'enzyme xpc modifiée est **non fonctionnelle** → dimères non réparés → XP. $\boxed{\text{substitution faux-sens → xpc inactive → maladie}}$.
> بالدارجة: هنا عطاوك **المنسوخ** (عكس تمرين 2017!) = الورقة هي **المعكوس**. النتيجة: حمض واحد تبدل (Lys→Gln) ولكن الأنزيم كامل مات! **غلطة صغيرة + بلاصة حساسة = مرض كبير.** لاحظ الفرق مع 2017: تماكان الإزاحة، وهنايا تبديل بسيط — بجوج كيمرضو!

## 🔀 Question 1 résolue autrement (2e méthode valide)
**Méthode 1 (ci-dessus) : recopie directe** — brin codant → ARNm (T→U).
**Méthode 2 : via le brin transcrit reconstitué (vérification croisée).**
1. Reconstituer le transcrit (complément du codant) : CAG… → GTC… (3'→5').
2. Reprendre le complément pour l'ARNm (avec U) : on retrouve CAG CCC ACC AUC… ✅ identique.
3. Intérêt : si les deux chemins donnent la même séquence, le calcul est **vérifié** ; s'ils divergent, on a inversé un brin → on corrige AVANT de lire les AA. Les bons élèves vérifient, les autres subissent !
> بالدارجة: الطريقة الثانية = **المراقبة**: سير بالطريق المعاكس (استنتج المنسوخ ومنو الورقة) — إلا خرجات نفس النتيجة = صحيح، إلا خرجات مختلفة = راك قالب الشريط! هاد التحقق كيحميك من الغلطة اللي كتضيع التمرين كامل.

## VRAIE — 2022R Ex2-partie D2a (MCR1 + code génétique)

🏷️ matière=SVT · année=2022 · session=R · chapitre=S4 · type=VRAIE · fidélité=reconstitué-corrigé · niveau=★★★ · barème=partie de l'exo D2 unifié (5)

> ⚠️ **Reconstituée** depuis le mining Tier A (neosvt 2022-ratt : 1re partie de l'exo D2 — récepteur MCR1, comparaison de séquences, table du code génétique, mutation). Séquences exactes non reproduites — démarche officielle.
> Thème : relation protéine-caractère — le récepteur MCR1 (mélanocortine : pigmentation, cheveux roux) normal vs mutant.

**Q1.** Comparer les séquences protéiques (ou nucléiques) normal/mutant : identifier la différence (1 acide aminé substitué).
**Q2.** À l'aide de la table du code génétique, retrouver les codons (ARNm) des deux versions et en déduire la mutation ponctuelle sur l'ADN (1 nucléotide).
**Q3.** Expliquer le passage mutation → protéine altérée → caractère modifié (MCR1 non fonctionnel → pigmentation rousse).
**Corrigé-type :** Q1 : 1 AA changé (ex : Asp → ...). Q2 : codon normal vs codon mutant (table !) → 1 nt substitué sur le brin codant → $\boxed{\text{mutation faux-sens}}$. Q3 : récepteur de membrane défectueux → signalisation mélanocytes modifiée → $\boxed{\text{phénotype roux}}$ : la chaîne causale complète ADN → protéine → caractère exigée !
> بالدارجة: قارن البروتينين ← حمض أميني واحد متبدل! رجع للكودونات (الجدول!) ← نيوكليوتيدة وحدة ← **طفرة مغلوطة المعنى**! والسلسلة الكاملة إجبارية: ADN ← بروتين خاسر (المستقبل MCR1!) ← الصفة (الشعر الأحمر)! اللي وقف فالطفرة بلا الصفة خسر!

## VRAIE — 2021R Ex2 (Wilson/ATP7B, 3,5 pts)

🏷️ matière=SVT · année=2021 · session=R · chapitre=S4 · type=VRAIE · fidélité=reconstitué-corrigé · niveau=★★★ · barème=3,5 (D2a, format COVID)

> ⚠️ **Reconstituée** depuis le mining Tier A (neosvt 2021-ratt : maladie de Wilson, gène ATP7B, transporteur du cuivre, code génétique). Séquences exactes non reproduites — démarche officielle.
> Thème : ATP7B (pompe à cuivre hépatique) : mutant → cuivre accumulé (foie, cerveau, anneau de Kayser-Fleischer).

**Q1.** Identifier la mutation (comparaison séquences + table du code : faux-sens ou non-sens selon l'allèle du sujet).
**Q2.** Expliquer pourquoi la protéine mutante est non fonctionnelle (AA clé du site actif / protéine tronquée par STOP prématuré).
**Q3.** Relier au phénotype Wilson (surcharge cuprique → atteintes hépatique/neurologique).
**Corrigé-type :** même moteur D2a (séquence → codon → mutation → protéine → caractère) ; spécificité Wilson : protéine = TRANSPORTEUR (pas enzyme !) → vocabulaire « transport/excrétion du cuivre » attendu ; $\boxed{\text{mutation} \to \text{ATP7B muet} \to \text{Cu accumulé} \to \text{Wilson}}$.
> بالدارجة: نفس المحرك (التسلسل ← الكودون ← الطفرة ← البروتين ← الصفة)! خصوصية ويلسون: البروتين **ناقل** (ماشي أنزيم!) ← مفردات النقل/الإفراز! السلسلة: طفرة ← ATP7B ميت ← النحاس متراكم (الكبد، الدماغ!) ← **مرض ويلسون**!

## 🪤 Pièges testés par question
- **Q1** : ARNm en complément du codant ❌ (c'est une RECOPIE + U) ; T laissés dans l'ARNm ❌ ; sens 5'→3' inversé ❌.
- **Q2** : compter les triplets au lieu des nucléotides (perdus = 7 nt, pas « 2 triplets ») ; oublier de dire que 7 ≠ multiple de 3 (le décalage doit être JUSTIFIÉ) ; relation caractère-gène récitée sans les mots du sujet (Mc1-R, phéomélanine, plumage).
- **Q3** : traiter le transcrit comme un codant (recopie au lieu de complément) ❌ — le miroir du piège Q1, fait exprès par les concepteurs qui alternent les deux cas d'une année à l'autre ! ; s'arrêter aux séquences sans « expliquer l'origine » (faux-sens → xpc morte → XP).
- **2022R** : mutation nommée sans preuve (table du code OBLIGATOIRE : codon normal vs mutant !) ❌ ; chaîne causale incomplète (s'arrêter à la protéine, sans le caractère !) ❌.
- **2021R** : ATP7B traitée comme enzyme (c'est un TRANSPORTEUR : « transport/excrétion » !) ❌ ; phénotype Wilson récité sans le lien Cu (foie/cerveau !) ❌.

## VRAIE — 2023N Ex2 (HCF : un STOP qui coupe le récepteur LDL)

🏷️ matière=SVT · année=2023 · session=N · chapitre=S4 · type=VRAIE · fidélité=verbatim · niveau=— · barème=voir énoncé
Allèle normal : ARNm AGA AAC GAG UUC CAG UGC CAA → Arg-Asn-Glu-Phe-Gln-Cys-Gln. Allèle anomal : ...UUC **UAG** UGC CAA → Arg-Asn-Glu-Phe (STOP !). Cause : substitution C→T au triplet 33 du brin NON transcrit → codon stop UAG → protéine tronquée → récepteur LDL non fonctionnel → LDL restent dehors (11→10 UA vs 11→2 chez sain) → cholestérol ↑ → HCF.
🪤 *vraie : brin non transcrit = codant (recopie T→U !) ; UAG = fin (tout après = poubelle !).*
