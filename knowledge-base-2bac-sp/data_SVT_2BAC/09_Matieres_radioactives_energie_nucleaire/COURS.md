# 09. Matières radioactives et énergie nucléaire — le feu du noyau

## 1. Accroche — le château de cartes instable 🏰

Un noyau lourd (uranium : 92 protons qui se repoussent !), c'est un château de cartes sous tension : tôt ou tard, il s'effondre en château plus stable — en crachant de l'énergie. Cette « chute » ($E = mc^2$ : 1 g = ville entière !), c'est la radioactivité. La maîtriser = dater la Terre (S10 !), soigner le cancer, éclairer des pays… ou les dévaster. Ce chapitre = comprendre le château, sa chute, et nos choix.

> بالدارجة : النواة الثقيلة (اليورانيوم : 92 بروتون كيتدافعو !) بحال قصر ورق متوتر : عاجلاً ولا آجلاً كيطيح لقصر أثبت — وكيطلق الطاقة. هاد «الطيحة» ($E = mc^2$ : غرام واحد = مدينة كاملة !) هي النشاط الإشعاعي. التحكم فيه = تأريخ الأرض (S10 !)، علاج السرطان، إنارة البلدان... ولا تدميرها.

## 2. Résumé du cours (exigible au bac)

**Stabilité nucléaire.** Un noyau $^A_ZX$ ($Z$ protons, $N = A-Z$ neutrons) tient par l'interaction forte (courte portée) contre la répulsion électrique des protons. Trop de protons (lourds) ou mauvais ratio $N/Z$ → **instable** → désintégration vers la stabilité. Isotopes : même $Z$, $N$ différent ($^{12}C$ stable, $^{14}C$ radioactif).

**Les 3 rayonnements (+ 1).** **$\alpha$** : noyau d'hélium $^4_2He$ — gros, lent, **arrêté par une feuille de papier** (mais ravageur ingéré !). **$\beta^-$** : électron issu de $n \to p + e^-$ — arrêté par l'aluminium. **$\beta^+$** : positron ($p \to n + e^+$). **$\gamma$** : photon ultra-énergétique — **traverse le corps** (béton/plomb pour arrêter), accompagne souvent $\alpha/\beta$. Pouvoir pénétrant : $\alpha < \beta < \gamma$ ; dangerosité interne : inverse !

**Lois de Soddy (conservation).** $\alpha$ : $^A_ZX \to ^{A-4}_{Z-2}Y + ^4_2He$ ($A$ : $-4$, $Z$ : $-2$). $\beta^-$ : $^A_ZX \to ^A_{Z+1}Y + e^-$ ($A$ inchangé, $Z$ : $+1$). $\beta^+$ : $Z$ : $-1$. **$A$ et $Z$ se conservent** (somme égale des 2 côtés) — la méthode de TOUTES les équations.

**Loi de décroissance (pont maths !).** $\boxed{N(t) = N_0 e^{-\lambda t}}$ (M10 : $N' = -\lambda N$ !) ; activité $A = \lambda N$ (en **becquerels** : désintégrations/s) ; **demi-vie** $\boxed{t_{1/2} = \ln 2/\lambda}$ (M05 !). Après $n$ demi-vies : $N_0/2^n$. Aléatoire par noyau, **exacte en masse** (milliards de noyaux).

**Datation.** **$^{14}C$** ($t_{1/2} = 5730$ ans) : vivant = équilibre avec l'atmosphère ; mort = décroissance → âge ($t = -\ln(N/N_0)/\lambda$) ; limite ~50 000 ans ; archéologie. **$^{40}K$/$^{40}Ar$** ($t_{1/2} = 1,25$ Ga) : roches volcaniques, fossiles anciens (S10 : les -45 Ma du Karakorum !). Conditions : système **fermé**, $N_0$ connu, pas de contamination.

**Fission vs fusion.** **Fission** : lourd + neutron → 2 moyens + 2-3 neutrons + **E** ($^{235}U$ : $E = \Delta m\,c^2$) → **réaction en chaîne** (contrôlée : réacteur — modérateur ralentit, barres absorbent ; incontrôlée : bombe). **Fusion** : légers → lourd + E ($4H \to He$ : le Soleil ! ; ITER : $D + T \to He + n$) — propre, inépuisable, mais confinement extrême (100 M°C !).

**Déchets et sûreté.** Déchets HA-VL (haute activité, vie longue : milliers d'années) → **stockage géologique profond** (argile/granite). Accidents : Tchernobyl (1986 : emballement + pas d'enceinte), Fukushima (2011 : tsunami → perte refroidissement) → leçons : enceintes, redondances, culture sûreté. **Radioprotection** : temps (court), distance (loin), écran (plomb/béton) ; dose en **sievert** (effet bio) vs becquerel (activité physique). Maroc : pas de centrale (choix renouvelables S08 !) ; réacteur de recherche (Maâmora, médecine/industrie).

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**الاستقرار النووي :** النواة $^A_ZX$ ($Z$ بروتونات) شادّة بالقوة الشديدة ضد تنافر البروتونات. البروتونات بزاف ولا النسبة $N/Z$ غالطة ← **غير مستقرة** ← تفكك نحو الاستقرار. النظائر : نفس $Z$، $N$ مختلف ($^{12}C$ ثابت، $^{14}C$ مشع).

**الإشعاعات الثلاثة (+1) :** **ألفا** : نواة هيليوم — كبيرة، بطيئة، **كتحبسها ورقة** (ولكن مدمرة إلا تبلعات !). **بيتا-** : إلكترون من $n \to p$ — كيحبسو الألمنيوم. **بيتا+** : بوزيترون. **غاما** : فوتون — **كيخترق الجسم** (الخرسانة/الرصاص باش تحبسو). القدرة على الاختراق : $\alpha < \beta < \gamma$ ؛ والخطورة الداخلية : العكس !

**قوانين سودي (الانحفاظ) :** ألفا : $A$ : $-4$، $Z$ : $-2$. بيتا- : $A$ ثابت، $Z$ : $+1$. بيتا+ : $Z$ : $-1$. **$A$ و $Z$ كيتحافظو** (المجموع متساوي في الجهتين) — منهجية كاع المعادلات.

**قانون التناقص (جسر الرياضيات !) :** $N(t) = N_0 e^{-\lambda t}$ (M10 !) ؛ النشاط $A = \lambda N$ (**بكريل** : تفكك/ثانية) ؛ **عمر النصف** $t_{1/2} = \ln 2/\lambda$ (M05 !). من بعد $n$ أنصاف : $N_0/2^n$. عشوائي للنواة الواحدة، **مضبوط للملايير**.

**التأريخ :** **الكربون-14** (5730 سنة) : الحي = توازن مع الجو ؛ الميت = تناقص ← العمر ؛ الحد ~50.000 سنة ؛ الآثار. **بوتاسيوم-أرغون** (1,25 مليار سنة) : الصخور البركانية (S10 : الـ -45 مليون سنة ديال كاراكوروم !). الشروط : نظام **مغلق**، $N_0$ معروف، بلا تلوث.

**الانشطار والاندماج :** **الانشطار** : ثقيل + نيوترون ← 2 متوسطين + نيوترونات + **طاقة** ← **تفاعل متسلسل** (مراقب : مفاعل — المهدّئ، القضبان ؛ غير مراقب : قنبلة). **الاندماج** : خفاف ← ثقيل + طاقة ($4H \to He$ : الشمس ! ؛ ITER) — نظيف، لا نهائي، ولكن الحصر صعب (100 مليون درجة !).

**النفايات والسلامة :** نفايات عالية النشاط طويلة العمر (آلاف السنين) ← **التخزين الجيولوجي العميق**. الحوادث : تشيرنوبيل (1986)، فوكوشيما (2011) ← الدروس : الأغلفة، التكرار، ثقافة السلامة. **الوقاية** : الوقت (قصير)، المسافة (بعيد)، الحاجز (رصاص). الجرعة بـ **سيفرت** (الأثر الحيوي) ماشي بكريل. المغرب : ما كايناش محطة (اختيار المتجددة S08 !).

## 4. How to understand this chapter the easy way 🎯

*(كأن الأستاذ كيشرح لك شفوياً — خطوة بخطوة)*

**الخطوة 1 — علاش النواة كتفكك ؟** البروتونات كيتنافرو (كهرباء) والقوة الشديدة قصيرة المدى : في النواة الكبيرة، البروتونات البعاد ما كيتحكموش ← القصر كيطيح. **التفكك = البحث عن الاستقرار** (النسبة $N/Z$ المثالية + الحجم المناسب). كل إشعاع كيقرّب للاستقرار بطريقتو.

**الخطوة 2 — المعادلات : احفظ $A$ و $Z$ فقط.** ألفا : $A-4$، $Z-2$. بيتا- : $A$ ثابت، $Z+1$. بيتا+ : $Z-1$. مثال : $^{238}_{92}U \to ^{234}_{90}Th + ^4_2He$ (تحقق : $234+4 = 238$ ✓، $90+2 = 92$ ✓). **أي معادلة : طبّق القاعدة ← تحقق بالجمع.** غاما ما كتبدّل والو ($A, Z$ ثابتين — غير الطاقة !).

**الخطوة 3 — عمر النصف : العدّ بالأنصاف.** $t_{1/2}$ : المدة اللي كينقص فيها العدد للنص. تبقى الربع ؟ $2 \times t_{1/2}$ (نص النص !). الثمن ؟ $3 \times t_{1/2}$. **80% من تمارين التأريخ = عدّ الأنصاف** ($1 \to 1/2 \to 1/4 \to 1/8$). والصيغة العامة ($t = -\ln(N/N_0)/\lambda$) غير للحالات المكسّرة.

**الخطوة 4 — التأريخ : 3 شروط مقدسة.** نظام مغلق (لا دخول لا خروج)، $N_0$ معروف (التوازن الجوي للكربون)، بلا تلوث. **سؤال «ناقش النتيجة» = راجع الشروط الثلاثة** (مثال : عظم ملوث بمياه جوفية ← العمر غالط !).

**الخطوة 5 — الانشطار والاندماج : الاتجاه المعاكس.** الانشطار : **كبير كيتفرّق** (يورانيوم ← متوسطين). الاندماج : **صغار كيتجمعو** (هيدروجين ← هيليوم). بجوج كيطلقو طاقة ($E = \Delta m\,c^2$ : الكتلة الناقصة = الطاقة !) حيت النوى المتوسطة (الحديد !) هي الأكثر استقراراً — الكل كيمشي نحو الحديد من الجهتين.

## 6. FAQ du chapitre

**1. $\alpha$ dangereux ou pas ?** Dehors : non (papier l'arrête, peau suffit). Dedans (inhalé/ingéré : radon !) : oui, très (gros + lent = ravage local). Le contexte fait le danger. / برا : لا (الورقة كتحبسو). الداخل (مستنشق : الرادون !) : إيه، بزاف. السياق كيصنع الخطر.

**2. Pourquoi $t_{1/2}$ et pas « durée de vie » ?** Chaque noyau est imprévisible (peut tenir 1 s ou 10 $t_{1/2}$ !) ; seule la POPULATION suit la loi. Demi-vie = statistique, pas destin individuel. / كل نواة غير متوقعة ؛ القانون للجماعة فقط. عمر النصف = إحصاء، ماشي قدر فردي.

**3. Datation : pourquoi système fermé ?** Si du $^{14}C$ entre/sort après la mort (contamination), $N$ ne reflète plus l'âge. Comme un sablier percé : le sable ne dit plus l'heure. / إلا دخل/خرج كربون من بعد الموت، العدد ما كيبقاش كيعني العمر — بحال الساعة الرملية المثقوبة.

**4. Fission : d'où vient l'énergie ?** Défaut de masse : produits + légers que le départ ($\Delta m$) → $E = \Delta m\,c^2$. $c^2$ énorme → 1 g $\to$ ~25 GWh ! / نقص الكتلة ← $E = \Delta m\,c^2$. $c^2$ هائل ← غرام = مدينة !

**5. Bq ou Sv ?** Bq = activité physique (combien de désintégrations/s). Sv = effet sur le vivant (quelle particule ? quel organe ?). 1 Bq $\alpha$ ingéré ≫ 1 Bq $\gamma$ externe en Sv ! / بكريل = فيزياء (شحال/ثانية). سيفرت = أثر حيوي (شمن جسيم ؟ شمن عضو ؟).

**6. Pourquoi le Maroc n'a pas de centrale ?** Choix stratégique : soleil/vent exceptionnels (S08 !), coût + déchets + eau de refroidissement (sécheresse !) du nucléaire. Débat ouvert, pas dogme. / اختيار استراتيجي : الشمس/الريح + التكلفة والنفايات والماء (الجفاف !). نقاش مفتوح.

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **$\beta^-$ : « $Z$ diminue »** : non, $n \to p$ AJOUTE un proton : $Z$ AUGMENTE (+1), $A$ fixe. ($\beta^+$ : l'inverse !)
- 🪤 **Demi-vie = « tout a disparu après 2 $t_{1/2}$ »** : non ! Après 2 $t_{1/2}$ : $1/4$ RESTE. Jamais zéro (asymptote !).
- 🪤 **Datation $^{14}C$ sur roche** : non ! $^{14}C$ = matière ORGANIQUE récente (< 50 000 ans). Roche = K-Ar (ou U-Pb). Le couple dépend de l'objet !
- 🪤 **Fission/fusion inversées** : fission = on CASSE (lourd→moyens) ; fusion = on SOUDE (légers→lourd). *Fission = fissure (casse) ; fusion = fusionne (soude).*
- Mots-clés : *Soddy ($A$, $Z$), $N_0e^{-\lambda t}$, $t_{1/2} = \ln2/\lambda$, système fermé, chaîne contrôlée, Bq vs Sv.*

## 9. Le « pourquoi » profond — pourquoi le noyau paie cash 🔬

**Pourquoi $E = mc^2$ change tout ?** Chimie : on réarrange des ÉLECTRONS (eV). Nucléaire : on réarrange des NUCLÉONS (MeV, ×1 million !) — et le défaut de masse ($\Delta m$) converti par $c^2$ ($9\times10^{16}$ !) donne des énergies obscènes : 1 kg d'U-235 ≈ 3000 T de charbon. **Le nucléaire n'est pas « un peu » plus dense : c'est un autre monde** (d'où déchets minuscules en volume, énormes en durée).

**Pourquoi tout va vers le fer ?** Courbe d'Aston : l'énergie de liaison par nucléon culmine au fer-56. Légers → fusionner (monter vers Fe) ; lourds → fissionner (descendre vers Fe). Les étoiles brûlent H→He→…→Fe puis s'arrêtent (au-delà, ça CONSOMME) ; les supernovae fabriquent le reste. **Ton corps (C, O, Ca, Fe) = cendres d'étoiles ; l'uranium vient d'une supernova.**

**Pourquoi la décroissance est-elle exponentielle ?** Chaque noyau a une probabilité $\lambda\,dt$ de se désintégrer (Pile ou Face continu, sans mémoire !). $dN = -\lambda N\,dt$ → $N_0e^{-\lambda t}$ (M10 : même équation que le compte en banque inversé, le refroidissement, RC !). **Sans mémoire** : un noyau vieux de 10 $t_{1/2}$ a les mêmes chances qu'un neuf — comme une pièce qui « oublie » ses lancers.

**Liens croisés :** M10 — $N' = -\lambda N$ (l'équation apprise en maths VIT ici) ; M05 — $t_{1/2} = \ln2/\lambda$ ; S10 — K-Ar date les granitoïdes (-45 Ma !) ; PC-P04/P05 — même chapitre côté physique (défaut de masse, diagramme N-Z) ; SVT génétique — $\gamma$ = mutagène (mécanisme des cancers radio-induits).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « $\beta^-$ : l'atome perd un électron. »** Non ! Le $\beta^-$ NAÎT dans le noyau ($n \to p + e^-$) : $Z$ AUGMENTE (nouvel élément !), ce n'est pas une ionisation (cortège). **Le déclic :** *ionisation = perdre un électron du CORTÈGE (même élément) ; $\beta^-$ = créer un électron du NOYAU (élément suivant).*

**2. « Irradié = contaminé. »** Irradié = exposé au RAYONNEMENT (radio passée, comme bronzer) ; contaminé = particules radioactives SUR/DANS toi (source continue !). **Le déclic :** *irradié = photo prise (flash parti) ; contaminé = urgence qui te suit (matière présente).* Scanners : irradié, pas contaminé.

**3. « La fusion, c'est bientôt. »** ITER (2035+ : premier plasma D-T significatif ?, électricité ~2050+ si tout va bien) : la fusion reste un pari, pas un plan. Au bac : citer comme perspective, pas comme solution actuelle. **Le déclic :** *fission = industrie (440 réacteurs) ; fusion = recherche (0 kWh réseau).* Ne pas les mettre au même temps.
