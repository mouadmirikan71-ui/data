# Chapitre 07 — Ordures ménagères & matières organiques

> 📋 **Exigible au bac** : composition des déchets ménagers, traitement (décharge, compostage, recyclage,
> incinération), impacts sur les eaux (nitrates, contamination microbienne CF/SF), gestion durable.

## 1. Accroche — la poubelle qui empoisonne le puits 🗑️💧

**FR :** À M'nasra (près de Kénitra), des puits d'eau potable affichent 198 mg/L de nitrates (norme : 50 !) et des
milliers de bactéries fécales — à cause du FUMIER de bovins épandu sur les sols : la pluie lessive l'ammoniac,
le sol le transforme en nitrates, la nappe boit tout. Le national 2017 raconte exactement cette histoire
(Ex.2 : 4 puits, nitrates, coliformes, solutions). Tout le chapitre = suivre les déchets organiques de la poubelle
à la nappe... et apprendre à les arrêter.

**بالدارجة:** فالمناصرة (حدا القنيطرة)، آبار الماء الصالح للشرب فيها 198 mg/L ديال النترات (المعيار: 50!) وآلاف البكتيريا — بسبب **الغبار** ديال البقر: الشتا كتغسل الأمونياك، والتربة كتحولو لنترات، والفرشة كتشرب كلشي! الوطني 2017 عاود هاد القصة بالضبط (تمرين 2: 4 آبار، نترات، بكتيريا، حلول). هاد الفصل = تبع النفايات العضوية من الزبل للفرشة... وتعلم كيفاش تحبسها!

## 2. Résumé du cours (exigible au bac)

### 2.1 Composition des ordures ménagères
- Fraction organique (restes alimentaires, fumier, lisier : riche en C, N, P) + recyclables (plastique, verre,
  métal, papier) + inertes + dangereux (piles, huiles : filière spéciale !).
- Au Maroc : fraction organique DOMINANTE (~60-70 % des ordures !) → compostage/méthanisation prioritaires.

### 2.2 Modes de traitement (4 voies)
- **Décharge** (contrôlée : étanche + lixiviats traités + biogaz capté ; sauvage : interdite, pollue tout !).
- **Compostage** : fermentation aérobie → humus (amendement). **Recyclage** : matière → matière (tri !).
- **Incinération** : volume ÷ 10, énergie récupérable, MAIS fumées à traiter (dioxines !) + mâchefers.

### 2.3 Impacts sur les eaux — le circuit du nitrate (2017N !)
- Chaîne : fumier/déchets organiques → ammoniac $NH_4^+$ (ammonification) → nitrites $NO_2^-$ → **nitrates $NO_3^-$**
  (nitrification, sol aérobie) → lessivage par les pluies → **nappe phréatique** (M'nasra : jusqu'à 198 mg/L !).
- Norme potabilité : $NO_3^- \le 50$ mg/L (au-delà : méthémoglobinémie du nourrisson « bébé bleu » !).
- Lixiviats de décharges : jus chargés (organique + minéral + métaux) → étanchéité obligatoire.

### 2.4 Contamination microbienne — CF & SF (2017N !)
- **Coliformes fécaux (CF)** + **streptocoques fécaux (SF)** : indicateurs de contamination fécale (norme : 0/100 mL !).
- **Rapport CF/SF** : $< 0,7$ → origine ANIMALE ; $> 1$ (jusqu'à 4) → origine HUMAINE (entre : mixte).
  M'nasra : 0,0003 à 0,02 → animale (élevage bovin ✔, cohérent avec le fumier !).
- Danger : pathogènes associés (salmonelles, choléra...) → eau impropre SANS traitement.

### 2.5 Gestion durable (solutions 2017N !)
- Réduire à la source (tri, compostage domestique) → moins de lixiviats, moins d'épandage brut.
- **Rotation avec légumineuses** (fèverole : fixe $N_2$ → moins d'engrais/fumier ; courbe 2 du doc 3 : nitrates < 50 !).
- **Arrêt du fumier brut** (courbe 4 : teneur redescend vers la norme !) ; fumier COMPOSTÉ (hygiénisé, dosé).
- Protection des captages (périmètres), traitement des eaux (dénitrification, désinfection), contrôle régulier.

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**الفكرة الكبيرة:** النفايات العضوية = **طعام متحلل**! المشكل ماشي وجودها — المشكل فين كتمشي: إلا مشات للفرشة (عبر الماء) ولا للهوا (عبر الحرق العشوائي) كتولي سم!

1. **التركيبة:** الزبل المغربي غالبيتو عضوي (~60-70%!) — الخضرة والخبز والغبار! هادشي كنز إلا تدبر (كومبوست!) وسم إلا ترمى عشوائياً (عصارة + روائح + حشرات)!
2. **المعالجة:** المطرح المراقب (معزول + العصارة معالجة + الغاز مجمع!)، الكومبوست (تخمير هوائي ← سماد)، إعادة التدوير (الفرز!)، الحرق (كيصغر الحجم ولكن الدخان خاصو معالجة — الديوكسينات!).
3. **سلسلة النترات (2017N!):** الغبار ← أمونياك ← نتريت ← **نترات** (فالتربة) ← الشتا كتغسلو ← **الفرشة**! المناصرة: 198 mg/L (المعيار 50)! والرضيع كيزراق (ميتيموغلوبين!) إلا شربها!
4. **البكتيريا (2017N!):** القولونيات (CF) والمكورات (SF): المعيار **صفر**! والنسبة CF/SF: $< 0,7$ ← حيواني، $> 1$ ← بشري! المناصرة: 0,0003-0,02 ← **حيواني** (البقر — متوافق مع الغبار!)!
5. **الحلول (2017N!):** التناوب مع الفول (كيثبت الآزوت ← نترات تحت 50!)، حبس الغبار الخام (المنحنى كيهبط!)، الغبار **المخمر** (معقم ومقدار!)، حماية الآبار ومعالجة الماء!

## 4. How to understand this chapter the easy way 🎯
*(بصوت الأستاذ — خطوة بخطوة)*

**الخطوة 1 — أي تمرين تلوث: مصدر ← مسار ← مستقبل!** المصدر (الغبار/المطرح)، المسار (الشتا/التسرب/التربة)، المستقبل (الفرشة/الواد)! هاد السلسلة كتجاوب على «expliquez l'origine» بوحدها!

**الخطوة 2 — الجدول: قارن بالمعيار!** كل قيمة حدا معيارها (نترات ≤ 50، CF/SF = 0): فوق ← ملوث ✗، تحت ← مطابق ✔! المقارنة **المنهجية** (قيمة بقيمة) هي اللي كتجيب النقط — ماشي الانطباع العام!

**الخطوة 3 — النسبة CF/SF = البصمة!** حسب ($CF \div SF$) ← $< 0,7$ حيواني، $> 1$ بشري! وتأكد بالسياق (تربية بقر؟ صرف صحي؟)! الرقم + السياق = استنتاج صلب!

**الخطوة 4 — المنحنى: صف قبل ما تقترح!** وصف المنحنيات (كيطلع؟ كيهبط؟ فوق المعيار؟) ← استنتج الممارسة المثالية (الفول! حبس الغبار!) ← اقترح الحل **من المعطيات** (ماشي من راسك)! الحل المستخرج من الوثيقة = النقطة الكاملة!

**الخطوة 5 — الأخطاء القاتلة:** «المعيار 50» بلا وحدة (mg/L!)؛ CF/SF معكوسة (SF/CF!)؛ $0,02 < 0,7$ ← «بشري» (غلط! حيواني!)؛ الحل العام («توعية الناس» — خاص حل **من الوثيقة**: الفول/حبس الغبار!)؛ نسيان أن P1 (نترات سليمة!) ملوثة بكتيرياً (العين الشاملة: نترات **و** بكتيريا!)!

## 6. FAQ du chapitre

**Q1. Pourquoi les nitrates montent-ils dans la nappe ?**
$NO_3^-$ est très SOLUBLE et peu retenu par le sol (anion !) : les pluies le lessivent jusqu'à la nappe.
$NH_4^+$ (cation) est retenu, mais le sol l'oxyde en $NO_3^-$ (nitrification) → tout finit en nitrates mobiles !
بالدارجة: النترات **ذوابة** والتربة ما كتشدهاش (سالبة!) — الشتا كتجرفها للفرشة! والأمونياك (موجب، مشدود) التربة كتأكسدو لنترات ← كلشي كيولي متحرك!

**Q2. 50 mg/L : pourquoi ce seuil ?**
Au-delà, risque de méthémoglobinémie du nourrisson (le $NO_3^-$ → $NO_2^-$ bloque l'hémoglobine : « bébé bleu » !)
+ suspicion nitrosamines (cancérogènes). C'est un seuil SANITAIRE (OMS).
بالدارجة: الفوق ← خطر «الرضيع الأزرق» (النتريت كيبلوكي الهيموغلوبين!) + شبهة مسرطنة! عتبة **صحية** (OMS)!

**Q3. CF/SF : pourquoi ce rapport indique l'origine ?**
Homme et animaux n'hébergent pas les mêmes proportions de CF et SF (flores différentes !) : l'Homme excrète
relativement plus de CF, les animaux plus de SF. Le rapport = signature de l'hôte !
بالدارجة: الإنسان والحيوان عندهم نسب مختلفة (فلورا مختلفة!): الإنسان قولونيات أكثر، والحيوان مكورات أكثر! النسبة = **بصمة** المضيف!

**Q4. P1 : nitrates OK mais eau polluée ?**
OUI (2017N !) : $NO_3^- = 26$ ✔ mais CF $= 380$ ✗, SF $= 1250\times10^3$ ✗ → NON potable ! La potabilité exige
TOUS les paramètres (chimie ET microbio). Un seul ✗ = impropre !
بالدارجة: إيه! النترات سليمة ولكن البكتيريا كارثة ← **غير صالحة**! الصلاحية خاصها **جميع** المعايير (كيمياء **و** بكتيريا)! وحدة خاسرة = الماء خاسر!

**Q5. Pourquoi la fèverole fait baisser les nitrates ?**
Légumineuse : symbiose Rhizobium FIXE $N_2$ de l'air → azote pour la culture SUIVANTE → moins de fumier/engrais
épandu → moins de lessivage ! (Courbe 2 < 50 mg/L pendant 25 ans !) C'est l'agronomie qui soigne l'eau.
بالدارجة: الفول كيثبت آزوت الهوا (ريزوبيوم) ← الزراعة الجاية ما كتحتاجش غبار ← نترات أقل! (المنحنى 2 تحت 50 لمدة 25 عام!) الفلاحة الذكية كتداوي الماء!

**Q6. Décharge contrôlée vs sauvage ?**
Contrôlée : étanchéité (géomembrane) + collecte/épuration des lixiviats + captage du biogaz ($CH_4$ valorisé !) +
couverture finale. Sauvage : RIEN de tout ça → nappe + air + sols pollués. Le national adore ce contraste !
بالدارجة: المراقب: عزل + عصارة معالجة + غاز مجمع (يستغل!) + تغطية! العشوائي: والو ← كلشي ملوث! الوطني كيبغي هاد المقارنة!

## 9. Le « pourquoi » profond — le déchet voyage 🔬

**Pourquoi le fumier finit-il dans l'eau ? (la cascade de l'azote)**
L'azote organique (protéines du fumier) → $NH_4^+$ (ammonification, microbes) → $NO_2^-$ → $NO_3^-$ (nitrification,
Nitrosomonas puis Nitrobacter — ch.01 : respiration !). Chaque étape est une OXYDATION microbienne : le sol est un
RÉACTEUR qui transforme l'azote « lent » (organique, cation retenu) en azote « rapide » ($NO_3^-$ : anion soluble,
non retenu !). La pluie fait le reste (lessivage). Moral : TOUT épandage azoté non dosé = future pollution de
nappe — c'est de la CHIMIE, pas de la malchance !

**Pourquoi CF/SF signe l'origine ? (l'écologie intestinale)**
L'intestin humain (omnivore, $37°$C, transit rapide) sélectionne des flores riches en coliformes ; la panse des
ruminants (fermentation lente, anaérobie) favorise les streptocoques fécaux. Le rapport CF/SF d'une eau = le
MÉLANGE des flores qui l'ont contaminée : $< 0,7$ = signature « ruminant » (M'nasra : bovins !), $> 1$ = signature
« homme » (égouts !). C'est de l'ÉPIDÉMIOLOGIE environnementale : on piste un coupable invisible par ses microbes !

**Pourquoi la fèverole protège l'eau ? (l'azote gratuit du ciel)**
$N_2$ (78 % de l'air !) est inutilisable directement... sauf par Rhizobium (nodosités des légumineuses) qui le FIXE
en $NH_3$ (fixation biologique !). La fèverole ENRICHIT le sol en azote « lent » (résidus) pour le blé suivant →
l'agriculteur épand MOINS de fumier → moins de $NO_3^-$ lessivé (courbe 2 : 25 ans sous la norme !). C'est une
solution AGRONOMIQUE (rotation) à un problème HYDROLOGIQUE : le national 2017 récompense ceux qui voient ce pont !

**Ponts :** ch.01 (respiration microbienne : nitrification = oxydation !) ; ch.08 (pollutions énergétiques : l'AUTRE
famille — air/fossiles ; ici c'est l'EAU et l'ORGANIQUE) ; ch.02 (muscle : non — mais $NO_2^-$ bloque AUSSI la
myoglobine !) ; PC acide/base (nitrification ACIDIFIE le sol : $NH_4^+ \to NO_3^- + 2H^+$ !) ; géo ch.10-12 (nappe
phréatique : le RÉSERVOIR vulnérable !).

> بالدارجة: علاش الغبار كيوصل للماء؟ حيت التربة **مفاعل**: الآزوت العضوي (بطيء، مشدود) ← أمونياك ← نترات (**سريعة، ذوابة**)! والشتا كتكمل! أي فرش عضوي غير مضبوط = تلوث مستقبلي — **كيمياء** ماشي سوء حظ! وعلاش CF/SF كيبين الأصل؟ حيت مصارن الإنسان والبقر فيهم فلورا مختلفة — النسبة = **بصمة الجاني**! وعلاش الفول كيحمي؟ كيثبت آزوت الهوا (مجاناً!) ← غبار أقل ← نترات أقل — حل **فلاحي** لمشكل **مائي**!

## 10. Les 3 confusions qui coûtent des points 😵

**C1. $0,02 < 0,7$ → « humain » — l'inversion fatale.**
*Le clic :* PETIT rapport = PEU de CF par rapport aux SF = signature ANIMALE (les ruminants = usines à SF !).
GRAND rapport ($> 1$) = beaucoup de CF = HUMAIN. M'nasra : 0,0003 à 0,02, TOUS $< 0,7$ → animal partout !
Phrase-mémoire : « petit = bête, grand = gens ».
بالدارجة: النسبة الصغيرة = CF قلال حدا SF = **حيواني** (البقر = مصانع SF)! الكبيرة ($> 1$) = **بشري**! المناصرة: كولشي $< 0,7$ ← حيواني فكل الآبار! حفظ: «صغيرة = بهيمة، كبيرة = بنادم»!

**C2. P1 « potable » (nitrates OK) — le piège de l'œillère.**
*Le clic :* P1 : $NO_3^- = 26$ ✔ MAIS CF $= 380$ ✗, SF énorme ✗ → NON potable ! La potabilité = TOUS les critères
(chimie + microbio + ... Un seul rouge = impropre. Le national a PLACÉ P1 exprès : ceux qui ne regardent que les
nitrates tombent ! Balayage complet, TOUJOURS.
بالدارجة: P1: النترات خضرا ولكن البكتيريا حمرا ← **غير صالحة**! الصلاحية = **جميع** المعايير! الوطني حط P1 **بالعاني**: اللي شاف غير النترات طاح! المسح الشامل ديماً!

**C3. Solution « sensibiliser » — le hors-document.**
*Le clic :* « Il faut sensibiliser les agriculteurs » = 0 (générique, non extrait !). Le national veut une solution
LIÉE AU DOC 3 : rotation avec fèverole (courbe 2 !) et/ou arrêt du fumier brut (courbe 4 !) — avec les CHIFFRES
(< 50 mg/L !). Règle : « ma solution cite le document, ou elle n'existe pas ».
بالدارجة: «خاص التوعية» = صفر (عامة، ماشي من الوثيقة)! الوطني بغا حل **من الوثيقة 3**: التناوب مع الفول (المنحنى 2!) و/ولا حبس الغبار (المنحنى 4!) — **مع الأرقام**! القاعدة: «الحل اللي ما كيستشهد بالوثيقة ما كاينش»!
