# FAQ — Chapitre 04 (Décroissance radioactive)

**1. $\beta^-$ : $A-1$ (un neutron part) ?**
Non ! Le neutron se TRANSFORME en proton ($n \to p + e^-$) : il RESTE dans le noyau. $A$ inchangé, $Z$ +1. $A-1$, ce serait une expulsion (type $\alpha$ partielle) — pas un $\beta$.
/ لا ! النيوترون كيتحوّل لبروتون ($n \to p$) : كيبقى في النواة. $A$ ثابت، $Z$ زائد واحد.

**2. Le $\gamma$ change-t-il $A$ ou $Z$ ?**
Non : le $\gamma$ est un PHOTON (zéro nucléon !). $A$/$Z$ inchangés, seule l'ÉNERGIE baisse (désexcitation — comme un atome qui émet de la lumière en se désexcitant).
/ لا : الغاما فوتون (صفر نويات !). $A$/$Z$ ثابتين، غير الطاقة كتهبط (إزالة إثارة).

**3. $A$ (activité) ou $A$ (nucléons) — comment distinguer ?**
Même lettre, 2 sens ! Contexte + UNITÉ : $A = \lambda N$ en Bq (dés/s) vs $^A_ZX$ entier (sans unité). Le bac adore cette collision — lire l'unité avant de calculer.
/ نفس الحرف، جوج معاني ! السياق + الوحدة : بكريل (نشاط) ولا عدد صحيح (نويات). قرا الوحدة قبل الحساب.

**4. Après 2 demi-vies, tout est parti ?**
Non ! Il RESTE $1/2^2 = 1/4$ (25 %). La décroissance est une asymptote : jamais zéro. Après 10 demi-vies : $1/1024$ — quasi rien, mais pas zéro.
/ لا ! كيبقى $1/4$ (25 %). التناقص مقارب : ما كيوصلش للصفر أبداً.

**5. À $t = 2t_{1/2}$ : désintégré = 25 % ou 75 % ?**
RESTANT = 25 % ($1/2^2$), DÉSINTÉGRÉ = 75 % ($1 - 1/4$). La question 2023N piégeait là-dessus : « désintégré » = les morts ($1 - 1/2^n$), pas les survivants !
/ الباقي = 25 %، المتفكك = 75 %. سؤال 2023N كان على «المتفكك» = الموتى ($1 - 1/2^n$)، ماشي الناجين !

**6. Quel est le principe de la datation au $^{14}$C ?**
Vivant : $^{14}$C/$^{12}$C constant (échanges avec l'air). Mort : plus d'échanges, le $^{14}$C décroît ($t_{1/2} = 5730$ ans). Mesurer le rapport restant → $t = -\ln(N/N_0)/\lambda$ = âge depuis la mort. Détails/récit : S09.
/ الحي : النسبة ثابتة (التبادل مع الهواء). الميت : لا تبادل، $^{14}$C كيتناقص. قيس النسبة الباقية ← العمر منذ الموت. التفاصيل : S09.
