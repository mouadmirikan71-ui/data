# How to understand this chapter the easy way — 04 Décroissance radioactive

> بصوت الأستاذ فالقسم : سودي + الأسي + نصف العمر — 5 خطوات والتأريخ كيولي لعبة.

## الخطوة 1 — سودي : $A$ و $Z$ في الجهتين (ديما تحقق !)

ألفا : $A-4$، $Z-2$ (الهيليوم خرج). بيتا- : **$A$ ثابت**، $Z+1$ (النيوترون تحوّل لبروتون — بقى في النواة !). بيتا+ : $A$ ثابت، $Z-1$. غاما : **والو** (الفوتون ما فيهش نويات — النواة كتبرد فقط).

**المنهجية :** كتب المعادلة ← جمع $A$ في اليمين وقارن مع اليسار ← نفس الشي لـ $Z$. جوج تحققات = صفر خطأ. (إشارة البيتا كتعطي اتجاه $Z$ : $-$ ← $+1$، $+$ ← $-1$.)

## الخطوة 2 — الأسي : $N = N_0e^{-\lambda t}$ (نفس M10 !)

كل نواة عندها نفس الحظ باش تتفكك في كل لحظة (ما كتعقلش على عمرها !) ← المعادلة $N' = -\lambda N$ ← الحل أسي. إلا ضبطتي M10 ($y' = ay$)، راه ضبطتي هاد القانون بلا حفظ جديد.

**والنشاط $A = \lambda N$ ؟** نفس القانون تماماً ($A = A_0e^{-\lambda t}$) — حيت $A$ متناسب مع $N$ ! عطاوك $A$ بدل $N$ ؟ نفس الحساب. (⚠️ $A$ بالبكريل ماشي $A$ النويات — شوف الوحدة !)

## الخطوة 3 — نصف العمر : $t_{1/2} = \ln2/\lambda$ (اللوغاريتم ديال M05)

من بعد $t_{1/2}$ : كيبقى النص. من بعد $n$ أنصاف : كيبقى **$1/2^n$** ($n=3$ ← $1/8$، $n=10$ ← $1/1024$).

**كيفاش تجبد الصيغة ؟** $N_0/2 = N_0e^{-\lambda t}$ ← اختصر $N_0$ ← $1/2 = e^{-\lambda t}$ ← خد $\ln$ : $-\ln2 = -\lambda t$ ← $t = \ln2/\lambda$. سطرين وخرجات (مطلوبة في الوطني : 2023N !).

## الخطوة 4 — التأريخ : قيس الباقي، رجّع الزمن

$t = -\ln(N/N_0)/\lambda$ : كتقيس الكسر الباقي ($N/N_0$ — مثلاً $^{14}$C) وكترجع للزمن اللي داز. **علاش صالحة ؟** حيت $\lambda$ ما كيتبدلش (لا حرارة، لا ضغط، لا كيمياء — النواة عايشة في طاقات مليون مرة أكبر !) ← ساعة ما كتخربق.

**المثال :** بقى $1/4$ ← $n = 2$ ← $t = 2t_{1/2}$. بقى $70$ % ← $t = -\ln(0{,}7)/\lambda$ (VRAIE 2021N : $45{,}3$ عام !).

## الخطوة 5 — الباقي ماشي المتفكك (فخ 2023N !)

في $t = 2t_{1/2}$ : **الباقي** = $25$ % ($1/2^2$)، **المتفكك** = $75$ % ($1 - 1/4$). الوطني سول على «المتفكك» والجواب الصحيح 75 % — اللي جاوب 25 % عطى الباقي !

**القاعدة :** $1/2^n$ = **الناجون** ؛ المتفكك = $1 - 1/2^n$. قبل ما تجاوب : قرا السؤال واش طالب الباقي ولا المتفكك ؟

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. سودي : $A$ و $Z$ في الجهتين ($\beta$ : $A$ ثابت / $\gamma$ : والو).
2. $N = N_0e^{-\lambda t}$ + $A = \lambda N$ (نفس القانون، نفس M10).
3. $t_{1/2} = \ln2/\lambda$ + الكسر $1/2^n$.
4. التأريخ : $t = -\ln(N/N_0)/\lambda$ (ساعة لا تُغش).
5. الباقي ($1/2^n$) ماشي المتفكك ($1 - 1/2^n$) !
