# FAQ — Chapitre 24 (Piles)

**1. Anode : + ou − ?**
En PILE : anode (−), cathode (+) ! Anode = OXYDATION toujours — en pile, l'oxydation LIBÈRE des $e^-$ → pôle NÉGATIF (source !). En ÉLECTROLYSE (P25) : l'inverse (le générateur impose !). Le RÔLE est fixe, le SIGNE suit le montage.
/ في العمود : المصعد (−) ! المصعد = الأكسدة ديما — في العمود، الأكسدة كتحرر الإلكترونات ← القطب السالب (المصدر !). في التحليل (P25) : العكس ! الدور ثابت، العلامة كتبع التركيب.

**2. $e^-$ : quel sens ?**
Du MOINS vers le PLUS (fil) : les $e^-$ (négatifs !) fuient le − (répulsion) vers le + (attraction). Le COURANT (conventionnel !) : + vers −. Deux sens, deux objets — ne pas inverser !
/ من السالب للموجب (السلك) : الإلكترونات (السالبة !) كتهرب من − لـ +. التيار (الاصطلاحي !) : من + لـ −. جوج اتجاهات، جوج حوايج !

**3. Pont salin : pourquoi obligatoire ?**
Sans lui : contre-tension en microsecondes (cathode −, anode + : charges accumulées !) = blocage TOTAL. Le pont injecte $+$/$-$ qui neutralisent : il « paye » l'équilibre électrique pour que la chimie continue. Sans pont : pile morte-née !
/ بلا بيها : توتر مضاد في أجزاء من الثانية = بلوكاج كامل. القنطرة كتحقن $+$/$-$ اللي كيعادلو : «كتخلص» التوازن الكهربائي باش الكيمياء تكمل. بلا قنطرة : عمود ميت من الولادة !

**4. $E$ négatif ?**
IMPOSSIBLE pour une pile qui débite : $E = E(+) - E(-) > 0$ toujours ! Négatif = pôles INVERSÉS (recalculer dans le bon ordre : PLUS d'abord !). Une fém est positive — le signe − = erreur d'ordre.
/ مستحيل لعمود خدام : $E > 0$ ديما ! السالب = أقطاب مقلوبة (عاود بالترتيب الصحيح : الموجب اللول !).

**5. Pile morte : quand ?**
$Q_r = K$ → $E = 0$ (MORT thermodynamique — l'équilibre tue la pile !) OU zinc épuisé (MORT matière). La première arrivée gagne — calculer les DEUX ! (Morte-thermo : $x_{éq}$ — P19 ; morte-matière : $Q = nF$.)
/ $Q_r = K$ ← $E = 0$ (موت ترموديناميكي !) ولا الزنك تسالي (موت مادي). اللولة اللي توصل كتربح — حسب بجوج !

**6. $n$ (Nernst) ?**
$e^-$ ÉCHANGÉS dans le bilan (Daniell : 2 !) — PAS les coefficients stœchio. $n$ compte les électrons qui VOYAGENT dans le fil. $0{,}06/n$ : Daniell → $0{,}03$ ($n = 1$ : $0{,}06$ — FAUX !).
/ الإلكترونات المتبادلة في الحصيلة (دانيال : 2 !) — ماشي المعاملات. $n$ كيحسب الإلكترونات اللي كتسافر في السلك.
