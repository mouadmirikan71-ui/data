# Chapitre 24 — Piles électrochimiques

> 📋 **Exigible au bac (SI !)** : Daniell $(-)Zn\ |\ Zn^{2+}\ ||\ Cu^{2+}\ |\ Cu(+)$ : ANODE(−) = oxydation ($Zn \to Zn^{2+} + 2e^-$, rongée !), CATHODE(+) = réduction ($Cu^{2+} + 2e^- \to Cu$, grossit !), PONT SALIN (ferme le circuit + équilibre les charges — OBLIGATOIRE !), bilan ($e^-$ annulés !) ; $e^-$ : − vers + (fil) ; $\boxed{E° = E°(+) - E°(-)}$ (Daniell : $1{,}10$ V !) ; Nernst : $\boxed{E = E° - (0{,}06/n)\log Q_r}$ ; pile MORTE : $Q_r = K$ → $E = 0$ ; capacité $\boxed{Q = n(e^-)F}$ ($F = 96500$ C/mol), $W = E\cdot Q$, $Q = It$.

## 1. Accroche — la pile citron 🍋💡

Plante une lame de zinc et une pièce de cuivre dans un citron, relie avec des fils : une DEL s'allume ! Le citron = pont salin + électrolyte, les métaux = électrodes. Une réaction chimique SPONTANÉE ($Zn + Cu^{2+} \to Zn^{2+} + Cu$ — P23 !) pousse des électrons dans le fil : chimie → électricité. Tout le chapitre : *anatomie (Daniell), force ($E$), loi (Nernst), autonomie ($Q = nF$).* La spontanéité : P23 ; l'envers (forcer) : P25.

> بالدارجة : غرس صفيحة زنك وقطعة نحاس في حامضة، وصل بالأسلاك : ليد كتشعل ! الحامضة = قنطرة ملحية + محلول، المعادن = أقطاب. تفاعل كيميائي **تلقائي** ($Zn + Cu^{2+} \to Zn^{2+} + Cu$ — P23 !) كيدفع الإلكترونات في السلك : الكيمياء ← الكهرباء. كاع الفصل : *التشريح (دانيال)، القوة ($E$)، القانون (نرنست)، الاستقلالية ($Q = nF$).* التلقائية : P23 ؛ العكس (الفرض) : P25.

## 2. Résumé du cours (exigible au bac)

**Pile Daniell : anatomie.** $(-)Zn\ |\ Zn^{2+}\ ||\ Cu^{2+}\ |\ Cu(+)$. **Anode (−)** : OXYDATION $Zn \to Zn^{2+} + 2e^-$ (l'anode SE FAIT MANGER — zinc rongé !). **Cathode (+)** : RÉDUCTION $Cu^{2+} + 2e^- \to Cu$ (cuivre qui GROSSIT, solution bleue qui PÂLIT !). **Pont salin** ($KNO_3$, $KCl$) : ferme le circuit + équilibre les charges ($+$ vers cathode, $-$ vers anode) — SANS lui : blocage en microsecondes (contre-tension !). Bilan : $Zn + Cu^{2+} \to Zn^{2+} + Cu$ ($e^-$ annulés !). $e^-$ : − vers + (FIL) ; courant : + vers − !

**Fém.** $\boxed{E° = E°(+) - E°(-)}$ : le PLUS d'abord ! $E°(Cu^{2+}/Cu) = +0{,}34$ V, $E°(Zn^{2+}/Zn) = -0{,}76$ V → Daniell : $E° = 0{,}34 - (-0{,}76) = \boxed{1{,}10\text{ V}}$ (le nombre à connaître !). $E > 0$ TOUJOURS (négatif = pôles inversés !).

**Nernst (concentrations $\neq 1$ M).** $\boxed{E = E° - \frac{0{,}06}{n}\log Q_r}$ ($n$ = $e^-$ ÉCHANGÉS !). Ex. : $[Zn^{2+}] = 0{,}1$, $[Cu^{2+}] = 1$ : $Q_r = 0{,}1$ → $E = 1{,}10 - 0{,}03\times(-1) = 1{,}13$ V. Sens : dilué côté cathode ($Q_r$ ↑) → $E$ ↓ ; dilué côté anode ($Q_r$ ↓) → $E$ ↑.

**Pile MORTE.** $E = E° - (0{,}06/n)\log Q_r$ et $\log K = nE°/0{,}06$ → $E = (0{,}06/n)\log(K/Q_r)$ : $Q_r \to K$ → $\boxed{E \to 0}$ — l'équilibre TUE la pile ! (Prévoir « quand s'arrête-t-elle ? » = $x_{éq}$ — P19 !)

**Capacité / énergie.** $\boxed{Q = n(e^-)\times F}$ ($F = 96500$ C/mol ; $n(e^-) = \nu\times n$ : ×2 pour Zn !), $\boxed{Q = It}$ (autonomie !), $\boxed{W = E\cdot Q}$ (J). Ex. : $0{,}10$ mol Zn → $Q = 19300$ C → à $0{,}20$ A : $t = 96500$ s $\approx 26{,}8$ h ; $W = 1{,}10\times19300 = 21$ kJ.

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**عمود دانيال : التشريح.** $(-)Zn\ |\ Zn^{2+}\ ||\ Cu^{2+}\ |\ Cu(+)$. **المصعد (−)** : الأكسدة $Zn \to Zn^{2+} + 2e^-$ (المصعد **كيتكال** — زنك متآكل !). **المهبط (+)** : الإرجاع ($Cu^{2+} + 2e^- \to Cu$ — نحاس كيكبر، المحلول الأزرق كيشحب !). **القنطرة الملحية** : كتسد الدائرة وكتعادل الشحنات — **بلا بيها : بلوكاج في أجزاء من الثانية** (توتر مضاد !). الحصيلة : $Zn + Cu^{2+} \to Zn^{2+} + Cu$. الإلكترونات : من − لـ + (السلك) ؛ التيار : من + لـ − !

**القوة المحركة :** $\boxed{E° = E°(+) - E°(-)}$ : **الموجب اللول** ! دانيال : $0{,}34 - (-0{,}76) = \boxed{1{,}10\text{ V}}$ (الرقم اللي خاصك تعرف !). $E > 0$ ديما (سالب = قلبتي الأقطاب !).

**نرنست (التراكيز $\neq 1$ M) :** $\boxed{E = E° - (0{,}06/n)\log Q_r}$ ($n$ = الإلكترونات **المتبادلة** !). الاتجاه : مخفف جيهة المهبط ($Q_r$ ↑) ← $E$ ↓ ؛ مخفف جيهة المصعد ← $E$ ↑.

**العمود الميت :** $Q_r \to K$ ← $\boxed{E \to 0}$ — التوازن **كيقتل** العمود ! («إيمتى كيحبس ؟» = $x_{éq}$ — P19 !)

**السعة / الطاقة :** $\boxed{Q = n(e^-)\times F}$ ($F = 96500$ ؛ $n(e^-) = \nu\times n$ : ×2 للزنك !)، $\boxed{Q = It}$ (الاستقلالية !)، $\boxed{W = E\cdot Q}$.

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **Anode = +** : en PILE : anode (−), cathode (+) ! (En ÉLECTROLYSE P25 : l'inverse !) Anode = OXYDATION toujours — en pile, l'oxydation LIBÈRE des $e^-$ → pôle NÉGATIF (source !).
- 🪤 **$E = E(-) - E(+)$** : ORDRE : $E = E(+) - E(-) > 0$ TOUJOURS (une fém est positive !). Si $E$ sort négatif : pôles inversés — une pile ne débite pas « à l'envers ».
- 🪤 **$n = 1$ (Daniell)** : $n = 2$ $e^-$ échangés : $0{,}06/2 = 0{,}03$ ! ($E = 1{,}16$ V avec $n = 1$ : FAUX.)
- 🪤 **$Q = n(Zn)\times F$ (×1 !)** : $n(e^-) = 2\times n(Zn)$ : UN Zn libère DEUX $e^-$ ! ($Q = 0{,}10\times2\times96500$.)
- Mots-clés : *anode(−) mangée/cathode(+) grossit, $E = E(+) - E(-)$ ($> 0$ !), Nernst ($n$ = $e^-$ !), morte ($Q_r = K$), $Q = n(e^-)F$ ($\times\nu$ !).*

## 9. Le « pourquoi » profond — pourquoi la pile pousse (et meurt) 🔬

**Pourquoi le pont salin ?** Sans lui : la cathode accumule des $-$ ($Cu^{2+}$ consommé → excès de $SO_4^{2-}$ : pôle négatif) et l'anode des $+$ ($Zn^{2+}$ produit !) : en microsecondes, cette contre-tension ÉGALISE $E$ et stoppe tout. Le pont injecte $+$/$-$ qui neutralisent : **il « paye » l'équilibre électrique pour que la chimie continue** (sans lui : pile morte-née !).

**Pourquoi la pile MEURT à $Q_r = K$ ?** $E = (0{,}06/n)\log(K/Q_r)$ : $Q_r = K$ → $\log 1 = 0$ → $E = 0$ — plus de « pente » thermodynamique, plus de courant. **La pile est un P19 qui s'épuise : débiter = avancer vers $K$ = scier la branche ($E$) sur laquelle on est assis !**

**Pourquoi $E = E(+) - E(-)$ ?** Le potentiel = « faim d'électrons » : $Cu^{2+}$ affamé ($+0{,}34$) aspire les $e^-$ du zinc repu ($-0{,}76$) : la DIFFÉRENCE de faim = la force qui pousse. (Analogue : l'eau coule par différence de HAUTEUR — $E$ = dénivelé électronique !)

**Liens croisés :** P23 — spontanéité (le sens ! $Q_{r,i} < K$ = débite !) ; P19/P20 — $K$, $Q_r$ (la pile meurt à $K$ !) ; P25 — électrolyse = pile À L'ENVERS (générateur externe, $Q_r$ repoussé LOIN de $K$) ; M05 — $\log Q_r$ (Nernst !) ; 1BAC — Ohm/puissance ($Q = It$, $W = EQ$) ; techno — batteries (Li-ion : rechargeable = P24 + P25 !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « Anode = + (toujours). »** Non : en PILE, anode = − (l'oxydation LIBÈRE des $e^-$ → source → pôle négatif !). En ÉLECTROLYSE (P25) : anode = + (le générateur IMPOSE !). **Le déclic :** *anode = OXYDATION (toujours !) — le SIGNE dépend du montage : en pile, qui libère des $e^-$ est la source (−). Le rôle est fixe, le signe suit le montage.*

**2. « $e^-$ : + vers −. »** Non : les $e^-$ partent du MOINS (anode, source !) vers le PLUS — c'est le COURANT (conventionnel !) qui va de + vers −. **Le déclic :** *les électrons (négatifs !) fuient le pôle négatif (répulsion !) vers le positif (attraction !) — le courant, lui, est une convention historique (+ vers −). Deux sens, deux objets.*

**3. « La pile s'arrête quand le zinc est épuisé (seulement). »** Pas seulement ! Elle s'arrête quand $Q_r = K$ ($E = 0$) — zinc restant ou pas ! (Si $K$ est atteint avant épuisement : pile morte avec du zinc dedans.) **Le déclic :** *deux morts possibles : THERMO ($Q_r = K$, $E = 0$) ou MATIÈRE (zinc épuisé) — la première arrivée gagne. Calculer les deux !*
