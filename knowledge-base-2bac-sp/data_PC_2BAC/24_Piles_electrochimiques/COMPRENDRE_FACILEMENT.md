# How to understand this chapter the easy way — 24 Piles

> بصوت الأستاذ فالقسم : المصعد كيتكال والمهبط كيكبر — 5 خطوات والعمود ما عندو سر.

## الخطوة 1 — الأقطاب : المصعد (−) كيتكال، المهبط (+) كيكبر !

المصعد = الأكسدة = **السالب** (في العمود !) : $Zn \to Zn^{2+} + 2e^-$ — الزنك **متآكل** (كيذوب !). المهبط = الإرجاع = **الموجب** : $Cu^{2+} + 2e^- \to Cu$ — النحاس **كيترسب** (كيكبر !) والمحلول الأزرق **كيشحب**.

**الصورة اللي ما كتخدعش :** شوف المعدن : ذاب ← مصعد (−) ؛ كبر ← مهبط (+). والإلكترونات : من − لـ + (السلك) — كيهربو من السالب (التنافر !) للموجب (التجاذب !). التيار ؟ العكس (+ لـ −) : اصطلاح تاريخي !

## الخطوة 2 — $E$ : الموجب ناقص السالب (الموجب اللول !)

$E° = E°(+) - E°(-)$ : دانيال : $0{,}34 - (-0{,}76) = 1{,}10$ V — **الرقم اللي خاصك تعرف !**

**$E > 0$ ديما !** إلا خرجات لك سالبة : قلبتي الأقطاب (العمود ما كيخدمش «بالمقلوب»). الجهد = «الجوع » للإلكترونات : الفرق في الجوع ($+0{,}34$ مقابل $-0{,}76$) = القوة اللي كتدفع ($E$ = فرق الارتفاع الإلكتروني !).

## الخطوة 3 — نرنست : $E$ كيتبدل مع التراكيز !

$E = E° - (0{,}06/n)\log Q_r$ ($n$ = الإلكترونات **المتبادلة** : دانيال $n = 2$ ← $0{,}03$ !).

**الاتجاه بلا حساب :** مخفف جيهة المهبط ($Cu^{2+}$ ↓ ← $Q_r$ ↑) ← $E$ **كيهبط**. مخفف جيهة المصعد ($Zn^{2+}$ ↓ ← $Q_r$ ↓) ← $E$ **كيطلع**. (المثال : $[Zn^{2+}] = 0{,}1$ ← $Q_r = 0{,}1$ ← $E = 1{,}13$ V : طلعات !) الاتجاه كافي لنص QCM !

## الخطوة 4 — الموت : التوازن كيقتل العمود ($Q_r = K$ ← $E = 0$ !)

$E = (0{,}06/n)\log(K/Q_r)$ : ملي $Q_r$ كيوصل $K$ ← $\log 1 = 0$ ← **$E = 0$** : بلا منحدر ترموديناميكي، بلا تيار. العمود كيخدم = كيتقدم نحو $K$ = **كيقطع الغصن ($E$) اللي قاعد عليه !**

**جوج موتات ممكنة :** الترمو ($Q_r = K$) ولا المادة (الزنك تسالي) — **اللولة اللي توصل كتربح** ! حسب بجوج (موت ترمو : $x_{éq}$ — P19 ؛ موت مادة : $Q = nF$).

## الخطوة 5 — السعة : $Q = n(e^-)F$ (ضرب في $\nu$ !)

$0{,}10$ مول Zn ← $n(e^-) = 2\times0{,}10 = 0{,}20$ (ذرة Zn وحدة = **جوج** إلكترونات !) ← $Q = 0{,}20\times96500 = 19300$ C ← في $0{,}20$ A : $t = Q/I = 96500$ ث $\approx 27$ ساعة.

**الغلطة :** $Q = 0{,}10\times96500$ (×1 !) — نسيان الـ ×2. **$n(e^-) = \nu\times n$ : ديما ضرب في عدد الإلكترونات !** والطاقة : $W = E\cdot Q$ (الجول : $1{,}10\times19300 = 21$ kJ).

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. المصعد (−) ذاب / المهبط (+) كبر ($e^-$ : − ← + !).
2. $E = E(+) - E(-)$ (دانيال : $1{,}10$ V + الموجب اللول !).
3. نرنست : مخفف مهبط ← $E$ ↓ / مخفف مصعد ← $E$ ↑.
4. الموت : $Q_r = K$ ($E = 0$) ولا الزنك تسالي (بجوج !).
5. $Q = n(e^-)F$ (×$\nu$ !) + $Q = It$ + $W = EQ$.
