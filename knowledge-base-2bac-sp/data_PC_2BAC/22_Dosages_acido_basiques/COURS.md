# Chapitre 22 — Dosages acido-basiques

> 📋 **Exigible au bac (SI !)** : dosage = réaction quasi-TOTALE ($K > 10^4$ exigé !) ; ÉQUIVALENCE : proportions stœchio ($n_{ac} = n_{base}$ si 1-1, réactifs ÉPUISÉS) → $\boxed{C_aV_a = C_bV_{éq}}$ (1-1 !) → $C_a$ ; $pH_{éq}$ : « QUE RESTE-T-IL ? » (fort-fort : $7$ + GRAND saut ; acide faible : $> 7$ (base conjuguée !) ; base faible : $< 7$) ; DEMI-ÉQUIVALENCE : $V = V_{éq}/2$ → $[A] = [B]$ → $\boxed{pH = pK_a}$ (mesure du $pK_a$ !) ; indicateur : zone de virage $\ni$ $pH_{éq}$ (ET dans le saut !).

## 1. Accroche — le vinaigre est-il vraiment à 7° ? 🧪

L'étiquette dit « vinaigre 7° » (7 % d'acide acétique) : vrai ou arnaque ? On DOSE : on verse la soude goutte à goutte, le $pH$ saute à $V_{éq}$… et $C_aV_a = C_bV_{éq}$ donne la réponse ! Tout le chapitre : *verser ($V_{éq}$), conclure ($C_a$), prédire ($pH_{éq}$), choisir (indicateur), mesurer ($pK_a$ à la demi-éq).* Les calculs de $pH$ : P21.

> بالدارجة : التيكي كتقول «خل 7 درجات» (7 % حمض أسيتيك) : بصح ولا غش ؟ **كنعايرو** : كنصبّو الصودا قطرة بقطرة، pH كينقز في $V_{éq}$... و $C_aV_a = C_bV_{éq}$ كتعطي الجواب ! كاع الفصل : *صبّ ($V_{éq}$)، استنتج ($C_a$)، توقع ($pH_{éq}$)، اختار (الكاشف)، قيس ($pK_a$ في نصف التكافؤ).* حسابات pH : P21.

## 2. Résumé du cours (exigible au bac)

**Principe.** Dosage = réaction de TITRAGE quasi-TOTALE ($K > 10^4$ exigé : l'équivalence doit être FRANCHE !) + repérage de l'ÉQUIVALENCE (saut de $pH$ suivi au pH-mètre — P18 ! — ou indicateur coloré).

**Équivalence.** Proportions STŒCHIOMÉTRIQUES : les réactifs sont ÉPUISÉS ensemble ($n_{ac} = n_{base}$ si 1-1) → $\boxed{C_aV_a = C_bV_{éq}}$ (1-1 ! sinon : $n/ \nu$ égaux) → $C_a$ INCONNUE. ($V$ en L dans $CV$ — mL → L !)

**$pH_{éq}$ : « que reste-t-il ? »** Fort–fort : que de l'EAU → $\boxed{pH_{éq} = 7}$ + GRAND saut ($4 \to 10$). Acide FAIBLE–base forte : que la base CONJUGUÉE $A^-$ (basique !) → $\boxed{pH_{éq} > 7}$ (ex. : $8{,}7$). Base faible–acide fort : que $BH^+$ (acide !) → $\boxed{pH_{éq} < 7}$. L'équivalence n'est neutre QUE si les deux sont forts !

**Demi-équivalence = $pK_a$ cadeau.** $V = V_{éq}/2$ : moitié de $AH$ transformée en $A^-$ → $[A^-] = [AH]$ → Henderson : $\boxed{pH = pK_a}$. Mesure DIRECTE (lecture sur la courbe, pas de calcul !) — d'où son usage en TP/examens.

**Indicateurs.** Zone de virage doit CONTENIR $pH_{éq}$ (ET tomber dans le saut !). BBT ($6{,}0$–$7{,}6$) : fort-fort ✓ ; phénolphtaléine ($8{,}2$–$10$) : acide faible ✓ (BBT ✗ : vire trop tôt !) ; hélianthine ($3{,}1$–$4{,}4$) : base faible. Mauvais indicateur : $V_{éq}$ lu FAUX → $C_a$ fausse (vire trop tôt → $V_{éq}$ petit → $C_a$ SOUS-estimée !).

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**المبدأ :** المعايرة = تفاعل **شبه-تام** ($K > 10^4$ إجباري : التكافؤ خاصو يكون واضح !) + تحديد **التكافؤ** (قفزة pH بالـ pH-متر — P18 ! — ولا كاشف ملون).

**التكافؤ :** النسب **الستوكيومترية** : المتفاعلات كيتسالاو بجوج ($n_{حمض} = n_{قاعدة}$ إلا 1-1) ← $\boxed{C_aV_a = C_bV_{éq}}$ ← $C_a$ المجهولة. ($V$ باللتر في $CV$ — مل ← لتر !)

**$pH_{éq}$ : «شنو بقى ؟»** قوي-قوي : غير الماء ← $\boxed{pH_{éq} = 7}$ + قفزة كبيرة. حمض ضعيف : غير القاعدة **المرافقة** $A^-$ (قاعدية !) ← $\boxed{pH_{éq} > 7}$. قاعدة ضعيفة : غير $BH^+$ ← $\boxed{pH_{éq} < 7}$. التكافؤ ما كيكون متعادل **غير** إلا كانو بجوج أقوياء !

**نصف التكافؤ = $pK_a$ هدية :** $V = V_{éq}/2$ : نص $AH$ تحول لـ $A^-$ ← $[A^-] = [AH]$ ← هندرسون : $\boxed{pH = pK_a}$. قياس **مباشر** (قراءة على المنحنى، بلا حساب !).

**الكواشف :** منطقة التغير خاصها **تحتوي** $pH_{éq}$ (وتطيح في القفزة !). BBT ($6{,}0$–$7{,}6$) : قوي-قوي ✓ ؛ الفينولفثالين ($8{,}2$–$10$) : حمض ضعيف ✓ ؛ الهيليانتين ($3{,}1$–$4{,}4$) : قاعدة ضعيفة. الكاشف الغالط : $V_{éq}$ غالط ← $C_a$ غالطة !

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **$pH_{éq} = 7$ toujours** : 7 SEULEMENT fort–fort ! Réflexe : « QUE RESTE-T-IL ? » — $A^-$ (basique) → $> 7$ ; $BH^+$ (acide) → $< 7$ ; eau seule → $7$.
- 🪤 **$C'$ non diluée** : à l'éq, $V$ a DOUBLÉ ($20 + 20$ !) : $C' = C/2$ (R2 : $0{,}050$ M, pas $0{,}10$ !). TOUJOURS $V_{tot}$ à l'équivalence !
- 🪤 **« $pH = pK_a$ » hors demi-éq** : Henderson avec le VRAI rapport ($[B]/[A] = 1/3$ → $pH = pK_a - 0{,}48$ !). $pH = pK_a$ SEULEMENT si $[B] = [A]$ (demi-éq !).
- 🪤 **Zone SOUS le saut** : hélianthine ($3{,}1$–$4{,}4$) pour un saut $4 \to 10$ : vire trop TÔT → $V_{éq}$ petit → $C_a$ SOUS-estimée. La zone doit être DANS le saut !
- Mots-clés : *$V_{éq}$ → $C_aV_a = C_bV_{éq}$ (L !), que reste-t-il ? ($pH_{éq}$), demi-éq = $pK_a$, zone $\ni$ $pH_{éq}$ + saut, $V_{tot}$ (dilution !).*

## 9. Le « pourquoi » profond — pourquoi le saut et pourquoi $pK_a$ cadeau 🔬

**Pourquoi $pH = pK_a$ à la demi-équivalence ?** $V_{éq}/2$ = moitié de $AH$ transformée en $A^-$ → $[A^-] = [AH]$ → Henderson : $\log 1 = 0$ → $pH = pK_a$. C'est une mesure DIRECTE : pas de calcul, une LECTURE sur la courbe ! (D'où son usage en TP — et au bac : VRAIE 2021N.)

**Pourquoi le SAUT de pH ?** $pH = -\log$ : près de l'équivalence, une goutte fait passer $[H_3O^+]$ de $10^{-4}$ à $10^{-10}$ (×10⁶ !) → 6 unités de pH d'un coup. **Le log convertit les ordres de grandeur en marches d'escalier** — le saut = la signature de l'équivalence (et le terrain de chasse des indicateurs !).

**Pourquoi $pH_{éq} > 7$ (acide faible) ?** À l'équivalence il ne reste que la BASE CONJUGUÉE $A^-$ (+ eau) : $A^-$ est basique ($A^- + H_2O \rightleftharpoons AH + OH^-$) → $OH^-$ → $pH > 7$. **L'équivalence n'est neutre QUE si les deux sont forts** — sinon, le survivant impose SON $pH$.

**Liens croisés :** P21 — socle ($pH$, Henderson, $pK_a$ !) ; P18 — suivi pH-métrique (la courbe $pH = f(V)$ EST un suivi !) ; P19 — dosage = réaction quasi-totale ($K > 10^4$ exigé !) ; SVT/médecine — titrages biologiques, acidité gastrique ; industrie — contrôle qualité (vinaigre 7° !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « $pH_{éq} = 7$ (acide faible). »** Non : $8{,}7$ ! À l'éq : $A^-$ SEUL (basique) → $OH^-$ → $pH > 7$. **Le déclic :** *à l'équivalence, demande-toi « QUE RESTE-T-IL ? » — le survivant impose son $pH$ ($A^-$ : basique ; $BH^+$ : acide ; eau seule : 7). Jamais 7 par défaut !*

**2. « $C_aV_a = C_bV_{éq}$ (pas 1-1). »** Non : $C_aV_a = C_bV_b$ SEULEMENT si stœchio 1-1 ! Sinon : $n_a/\nu_a = n_b/\nu_b$ (ex. $H_2SO_4$ : $\nu = 2$ !). **Le déclic :** *l'équivalence = proportions STŒCHIO ($n/\nu$ égaux) — $C_aV_a = C_bV_b$ n'est que le cas 1-1. Vérifier les $\nu$ d'abord !*

**3. « Indicateur : n'importe, ça vire pareil. »** Non : hélianthine ($3{,}1$–$4{,}4$) sur un saut $4 \to 10$ : vire AVANT l'éq → $V_{éq}$ faux → $C_a$ fausse ! **Le déclic :** *l'indicateur = un témoin qui doit parler AU BON MOMENT (dans le saut, autour de $pH_{éq}$) — un témoin qui parle trop tôt fausse le verdict ($C_a$).*
