# Exercices types — Dosages (P22)

## Méthode — dosage en 5 gestes 🧭

1. $V_{éq}$ (saut : tangentes // ; ou indicateur).
2. $C_aV_a = C_bV_{éq}$ (1-1 ! $V$ en L !).
3. $pH_{éq}$ : « que reste-t-il ? » ($V_{tot}$ !).
4. Demi-éq : $pH = pK_a$ (lecture !).
5. Indicateur : zone $\ni$ $pH_{éq}$ DANS le saut.

## R1 — TYPE-BAC ($pH_{éq}$ acide faible, 2 méthodes !)

🏷️ matière=PC · année=— · session=— · chapitre=P22 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** $20{,}0$ mL $CH_3COOH$ $0{,}10$ M dosés par $NaOH$ $0{,}10$ M ($V_{éq} = 20{,}0$ mL). $pH_{éq}$ ? Indicateur ?

**Corrigé-type.** À l'éq : que $A^-$, $C' = 0{,}050$ M. **Méthode 1 (réflexe base)** : $[OH^-] = \sqrt{K_bC'} = \sqrt{5{,}56\times10^{-10}\times0{,}050} = 5{,}27\times10^{-6}$ → $pH = \boxed{8{,}72}$. **Méthode 2 (retour à $K_a$)** : $[H_3O^+] = \sqrt{K_aK_e/C'} = \sqrt{1{,}8\times10^{-5}\times10^{-14}/0{,}050} = 1{,}90\times10^{-9}$ → $pH = \boxed{8{,}72}$ ✓. Indicateur : phénolphtaléine ($8{,}2$–$10$ ∋ $8{,}72$ ✓, BBT ✗).
🪤 *Piège testé : $C' = 0{,}10$ (dilution oubliée !) — $V$ a DOUBLÉ ($20+20$) : $C' = 0{,}050$ M.*

## R2 — TYPE-BAC (demi-équivalence = $pK_a$ cadeau)

🏷️ matière=PC · année=— · session=— · chapitre=P22 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** Même dosage : a) $pH$ à $V = 10{,}0$ mL ? En déduire $K_a$. b) $pH$ à $V = 5{,}0$ mL ?

**Corrigé-type.** a) $V = V_{éq}/2$ → $pH = pK_a = \boxed{4{,}75}$ → $K_a = 10^{-4{,}75} = \boxed{1{,}8\times10^{-5}}$ ✓. b) $[B]/[A] = 0{,}5/1{,}5 = 1/3$ → $pH = 4{,}75 + \log(1/3) = \boxed{4{,}27}$.
🪤 *Piège testé : b) « $pH = pK_a$ aussi » — Henderson avec le VRAI rapport : $[B]/[A] = 1/3$ → $\log = -0{,}48$ !*

## R3 — TYPE-BAC (indicateur : fort-fort)

🏷️ matière=PC · année=— · session=— · chapitre=P22 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** $20{,}0$ mL HCl dosés par $NaOH$ $0{,}10$ M, $V_{éq} = 20{,}0$ mL (saut $4 \to 10$). a) $C_a$ ? b) BBT ($6{,}0$–$7{,}6$), hélianthine ($3{,}1$–$4{,}4$), phénolphtaléine ($8{,}2$–$10$) ? c) Erreur si hélianthine ?

**Corrigé-type.** a) $C_a = 0{,}10\times20/20 = \boxed{0{,}10\text{ M}}$. b) $\boxed{\text{BBT}}$ ✓ (phénolphtaléine OK limite, hélianthine ✗ — vire à $\approx 4$, AVANT le saut !). c) $V_{éq}$ lu trop PETIT → $C_a$ SOUS-estimée.
🪤 *Piège testé : « hélianthine OK car dans le saut » — $3{,}1$–$4{,}4$ est SOUS le saut ($4 \to 10$) : elle vire trop tôt !*

## R4 — TYPE-BAC (dosage + $V_{b1}$ : lecture inverse)

🏷️ matière=PC · année=— · session=— · chapitre=P22 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** Dosage $AH$ ($V_a = 20$ mL) par $HO^-$ ($C_b = 0{,}10$ M) : $V_{bE} = 20$ mL, $pH_{éq} = 8{,}8$. a) $C_a$ ? b) $pH = 4{,}4$ correspond à quel $V_b$ (courbe : $V_{b1} = 6$ mL) ? Vérifier via Henderson ($pK_a = 4{,}75$) !

**Corrigé-type.** a) $C_a = 0{,}10\times20/20 = \boxed{0{,}10\text{ M}}$. b) Lecture inverse : $pH = 4{,}4$ → $V_{b1} = \boxed{6\text{ mL}}$ ; vérif : $[B]/[A] = 6/14 = 0{,}43$ → $pH = 4{,}75 + \log(0{,}43) = 4{,}75 - 0{,}37 = 4{,}38 \approx 4{,}4$ ✓.
🪤 *Piège testé : $[B]/[A] = 6/20$ (sur $V_a$ !) — $[B]/[A] = V_b/(V_{bE}-V_b) = 6/14$ : versé/restant, pas versé/total !*

## VRAIE — 2024R Ex1-Partie 2 (dosage de $R\text{-}NH_2$ : $V_E$ + $x_f$)

🏷️ matière=PC · année=2024 · session=R · chapitre=P22 · type=VRAIE · fidélité=reconstitué-corrigé · niveau=★★★ · barème=2-1 0,5 · 2-2 0,75 · 2-3 0,5+

> ⚠️ **Reconstituée** depuis les éléments de réponse officiels (scribd 831498939, Tier B). $V_E$ lu ; concentrations non relues.
> Données (reconstituées) : dosage de la base $R\text{-}NH_2$ ($C_B$, $V_B$) par $H_3O^+$ fort ($C_A$, $V_A$) ; suivi pH-métrique.

**2-1.** Équation du dosage. (0,5)
**2-2.** Volume équivalent $V_E$. (0,75)
**2-3.** Expression de l'avancement final $x_f$ en fonction de $C_A$, $V_A$, $V_B$, pH.
**Corrigé-type :**
1. $\boxed{R\text{-}NH_2 + H_3O^+ \to R\text{-}NH_3^+ + H_2O}$ (totale !).
2. À l'équivalence : $C_AV_E = C_BV_B$ → $V_E = \boxed{20\text{ mL}}$ (AN officielle).
3. Tableau : $n(H_3O^+)_{restant} = C_AV_A - x_f = [H_3O^+]_f(V_A+V_B)$ → $\boxed{x_f = C_AV_A - 10^{-pH}(V_A+V_B)}$ (restes = versé − consommé !).
🪤 *Piège testé : $V_{tot} = V_B$ ($V_A+V_B$ : les deux versements !) ; $x_f = x_{max}$ (non : $x_f$ à un point QUELCONQUE via le pH !).*
🗣️ الخلاصة : المعايرة كلية! $V_E = 20$ mL ($C_AV_E = C_BV_B$)! و$x_f$ فأي نقطة: المصبوب ناقص الباقي ($10^{-pH}\times V_{tot}$)! الفخ: $V_{tot} = V_A+V_B$ (بجوج!) ماشي $V_B$ بوحدو!
