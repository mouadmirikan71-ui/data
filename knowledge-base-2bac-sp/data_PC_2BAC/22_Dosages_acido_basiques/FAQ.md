# FAQ — Chapitre 22 (Dosages)

**1. $pH_{éq} = 7$ toujours ?**
NON — 7 SEULEMENT fort–fort (reste : eau seule) ! Acide faible : $> 7$ (reste $A^-$, basique !). Base faible : $< 7$ (reste $BH^+$ !). Réflexe : « QUE RESTE-T-IL ? » — le survivant impose SON $pH$.
/ لا — 7 غير قوي-قوي ! حمض ضعيف : $> 7$ (بقات $A^-$ !). قاعدة ضعيفة : $< 7$. الانعكاس : «شنو بقى ؟» — الناجي كيفرض pH ديالو.

**2. $C_aV_a = C_bV_{éq}$ : toujours ?**
Seulement si stœchio 1-1 ! Sinon : $n_a/\nu_a = n_b/\nu_b$ (ex. $H_2SO_4$ + $NaOH$ : $\nu = 2$ → $C_aV_a/1 = C_bV_b/2$… vérifier les $\nu$ !). L'équivalence = proportions STŒCHIO — $C_aV_a = C_bV_b$ n'est que le cas 1-1.
/ غير إلا 1-1 ! وإلا : $n_a/\nu_a = n_b/\nu_b$. التكافؤ = النسب الستوكيومترية — تحقق من المعاملات اللول !

**3. Demi-éq : pourquoi $pH = pK_a$ ?**
$V_{éq}/2$ : moitié de $AH$ transformée → $[A^-] = [AH]$ → Henderson : $\log 1 = 0$ → $pH = pK_a$. Mesure DIRECTE (lecture, pas de calcul !) — d'où son usage en TP et au bac.
/ نص $AH$ تحول ← $[A^-] = [AH]$ ← هندرسون : $\log 1 = 0$ ← $pH = pK_a$. قياس مباشر (قراءة !) — لهذا كيتستعمل في TP والوطني.

**4. Indicateur : comment choisir ?**
Zone de virage $\ni$ $pH_{éq}$ ET dans le saut ! Fort-fort (saut $4 \to 10$) : BBT. Acide faible ($pH_{éq} \approx 9$) : phénolphtaléine. Base faible ($pH_{éq} \approx 5$) : hélianthine. Mauvais choix : $V_{éq}$ faux → $C_a$ fausse !
/ المنطقة خاصها تحتوي $pH_{éq}$ وتطيح في القفزة ! قوي-قوي : BBT. حمض ضعيف : الفينولفثالين. الاختيار الغالط : $C_a$ غالطة !

**5. Le saut de $pH$ : pourquoi ?**
$pH = -\log$ : près de l'éq, une goutte fait passer $[H_3O^+]$ de $10^{-4}$ à $10^{-10}$ (×10⁶ !) → 6 unités d'un coup. Le log convertit les ordres de grandeur en marches — le saut = la signature de l'équivalence.
/ قريب من التكافؤ، قطرة كتدوز $[H_3O^+]$ من $10^{-4}$ لـ $10^{-10}$ (×10⁶ !) ← 6 وحدات دقة وحدة. اللوغاريتم كيحول الرتب لدرجات — القفزة = توقيع التكافؤ.

**6. Dosage : pourquoi $K > 10^4$ ?**
L'équivalence doit être FRANCHE (saut net !) : réaction quasi-TOTALE exigée ($K > 10^4$ — P19 !). $K$ petit : pas de saut (courbe molle) → $V_{éq}$ illisible → pas de dosage. Doser = titrer par une réaction qui VA AU BOUT.
/ التكافؤ خاصو يكون واضح (قفزة صافية !) : تفاعل شبه-تام إجباري ($K > 10^4$). $K$ صغير : بلا قفزة ← $V_{éq}$ ما كيتقراش ← بلا معايرة.
