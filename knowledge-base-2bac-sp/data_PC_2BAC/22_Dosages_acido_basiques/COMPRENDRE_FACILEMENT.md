# How to understand this chapter the easy way — 22 Dosages

> بصوت الأستاذ فالقسم : صبّ، سجّل القفزة، حسب التركيز — 5 خطوات والمعايرة كتولي روتين.

## الخطوة 1 — $V_{éq}$ : فين القفزة ؟ (المماسان المتوازيان !)

منحنى $pH = f(V)$ : القفزة = التكافؤ. الطريقة : مماسان متوازيان قبل وبعد القفزة + خط الوسط ← التقاطع مع المنحنى ← $V_{éq}$.

**ولا الكاشف :** اللون كيتبدل في $V_{éq}$ (إلا كان الكاشف صحيح !). $V_{éq}$ = المعلومة رقم 1 — كلشي وراها ($C_a$، $pK_a$...). دقة القراءة = دقة النتائج !

## الخطوة 2 — $C_a$ : $C_aV_a = C_bV_{éq}$ (1-1 ! + اللتر !)

التكافؤ = النسب الستوكيومترية : إلا كانت 1-1 ← $n_{حمض} = n_{قاعدة}$ ← $C_aV_a = C_bV_{éq}$ ← $C_a = C_bV_{éq}/V_a$.

**جوج شروط :** ① المعاملات 1-1 (وإلا : $n/\nu$ متساويين — $H_2SO_4$ : $\nu = 2$ !). ② $V$ **باللتر** في $CV$ (مل ← لتر !). الغلطة الكلاسيكية : $V$ بالمليلتر مع $C$ بالمول/لتر — الوحدات خاصها تنساجم !

## الخطوة 3 — $pH_{éq}$ : سول «شنو بقى ؟» (الناجي كيفرض pH ديالو !)

قوي-قوي : بقى غير الماء ← $7$. حمض ضعيف : بقات $A^-$ (قاعدية !) ← $> 7$ (مثال : $8{,}7$). قاعدة ضعيفة : بقى $BH^+$ ← $< 7$.

**والتركيز ؟** $C'$ مع $V_{الكل}$ (20 + 20 = 40 مل ← التركيز تقسّم على 2 !). التخفيف إجباري : الحجم تضاعف ← $C' = C/2$. (R2 : $0{,}050$ M ماشي $0{,}10$ !)

## الخطوة 4 — نصف التكافؤ : $pH = pK_a$ (هدية !)

$V = V_{éq}/2$ : نص $AH$ تحول ← $[A^-] = [AH]$ ← هندرسون : $\log 1 = 0$ ← $pH = pK_a$.

**قراءة مباشرة على المنحنى :** سقط $V_{éq}/2$ ← قرا pH ← هو $pK_a$ ! بلا حساب. (VRAIE 2021N : هاكا لقاو $pK_a = 4{,}75$.) وخارج نصف التكافؤ ؟ هندرسون بالنسبة الحقيقية ($[B]/[A] = 1/3$ ← $pK_a - 0{,}48$ !).

## الخطوة 5 — الكاشف : شاهد كيتكلم في الوقت المناسب !

المنطقة خاصها تحتوي $pH_{éq}$ **وتطيح في القفزة**. قوي-قوي (القفزة $4 \to 10$) : BBT ✓. حمض ضعيف ($pH_{éq} \approx 9$) : الفينولفثالين ✓ (BBT ✗ : كيتبدل بكري !).

**الكاشف الغالط = الحكم الغالط :** الهيليانتين على قفزة $4 \to 10$ : كيتبدل قبل التكافؤ ← $V_{éq}$ صغير ← $C_a$ **مقللة** ! الشاهد اللي كيتكلم بكري كيزوّر الحكم ($C_a$).

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. $V_{éq}$ : القفزة (مماسان متوازيان !).
2. $C_aV_a = C_bV_{éq}$ (1-1 ! + اللتر !).
3. $pH_{éq}$ : شنو بقى ؟ ($7$ / $> 7$ / $< 7$ + $V_{الكل}$ !).
4. نصف التكافؤ : $pH = pK_a$ (قراءة !).
5. الكاشف : المنطقة في القفزة حول $pH_{éq}$ !
