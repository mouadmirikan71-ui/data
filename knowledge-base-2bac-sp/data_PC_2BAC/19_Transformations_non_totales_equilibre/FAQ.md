# FAQ — Chapitre 19 (Non totales et équilibre)

**1. À l'équilibre, tout s'arrête ?**
Non ! $v_{direct} = v_{inverse} \neq 0$ : les concentrations sont FIXES parce que les flux S'ANNULENT (direct fabrique ce que l'inverse détruit). Les réactions CONTINUENT (traceurs isotopiques !). Équilibre DYNAMIQUE.
/ لا ! $v_{مباشر} = v_{عكسي} \neq 0$ : التراكيز ثابتة حيت التدفقات كتلغى. التفاعلات مستمرة (الواسمات !). توازن ديناميكي.

**2. $\tau = 1$ : ça veut dire quoi exactement ?**
Le limitant est ÉPUISÉ ($x_f = x_{max}$) : transformation TOTALE. $\tau < 1$ : arrêt AVANT ($x_{éq} < x_{max}$) : LIMITÉE. $\tau$ = fraction du chemin ($x_{max}$) parcourue.
/ المحد تسالي ($x_f = x_{max}$) : تام. $\tau < 1$ : الحبس قبل : محدود. $\tau$ = الكسر المقطوع من الطريق.

**3. $K$ grand = totale, toujours ?**
Non ! $\tau$ dépend AUSSI de $[]_0$ : $K = 140$ dilué → $\tau = 11$ % (R2 !). Seul $K > 10^4$ garantit quasi-total (et $K < 10^{-4}$ quasi-nul). Entre : calculer $\tau$ (via $x_{éq}$) !
/ لا ! $\tau$ معتمد حتى على التراكيز الابتدائية : $K = 140$ مخفف ← $\tau = 11$ %. غير $K > 10^4$ كيضمن شبه-التام.

**4. Pourquoi rejeter $x > x_{max}$ ?**
$x_{max}$ = PLAFOND du bilan (limitant épuisé — on ne dépasse JAMAIS !). L'équation $Q_r(x) = K$ donne 2 racines mathématiques ; la physique n'en garde qu'UNE ($\leq x_{max}$). L'équation propose, le bilan dispose.
/ $x_{max}$ = سقف الحصيلة (ما كتفوتوش أبداً !). المعادلة كتعطي جذرين رياضيين ؛ الفيزياء كتحتفظ بواحد ($\leq x_{max}$).

**5. $\tau$ dépend de $[]_0$ : exemple ?**
R2 : MÊME $K = 140$ : concentré → $\tau$ élevé ; dilué ($10^{-3}$ M) → $\tau = 11$ %. $Q_r(x_{éq}) = K$ : le point d'arrivée dépend du point de départ ! (VRAIE 2023N : après ajout, $\tau$ : $66{,}7$ % → $70$ % — MÊME $K = 4$ !)
/ نفس $K = 140$ : مركز ← $\tau$ عالية ؛ مخفف ← $\tau = 11$ %. نقطة الوصول معتمدة على نقطة الانطلاق !

**6. Total = rapide ? (question-piège)**
NON ! $\tau$ = JUSQU'OÙ (thermo, ce chapitre) ; $t_{1/2}$ = EN COMBIEN DE TEMPS (cinétique, P17). Rouille : $\tau \approx 1$ (totale !), $t_{1/2}$ = des mois (lente !). 4 combos possibles — le bac les mélange.
/ لا ! $\tau$ = حتى فين (ترمو) ؛ $t_{1/2}$ = في شحال (حركية). الصدا : تام وبطيء ! 4 تركيبات — الوطني كيخلطهم.
