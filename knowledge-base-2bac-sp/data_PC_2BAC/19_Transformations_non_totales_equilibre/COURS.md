# Chapitre 19 — Transformations non totales, notion d'équilibre

> 📋 **Exigible au bac (SI !)** : TOTALE ($x_f = x_{max}$) vs LIMITÉE ($x_f = x_{éq} < x_{max}$) ; équilibre DYNAMIQUE ($v_{dir} = v_{inv}$, $[\,]$ fixes, réactions continuent !) ; $\boxed{K = Q_r(\text{à l'équilibre})}$ (sans unité, ne dépend que de $T$ ! ; $> 10^4$ quasi-totale, $< 10^{-4}$ quasi-nulle) ; $\boxed{\tau = x_{éq}/x_{max} \leq 1}$ ($\tau = 1$ totale !) ; $x_{éq}$ : $\boxed{Q_r(x_{éq}) = K}$ + REJETER $x > x_{max}$ ! ; **TOTAL ($\tau$) $\neq$ RAPIDE ($t_{1/2}$) !**

## 1. Accroche — l'ascenseur bondé 🛗

Un ascenseur plein à craquer : à chaque étage, 3 personnes sortent et 3 entrent — l'ascenseur RESTE plein, mais ce ne sont plus les mêmes personnes ! L'équilibre chimique, c'est ça : les concentrations ne bougent plus, NON parce que rien ne se passe, mais parce que les réactions DIRECTE et INVERSE vont à la MÊME vitesse. **Équilibre DYNAMIQUE** — le mot-clé du chapitre. (Le COMMENT prédire le sens : P20.)

> بالدارجة : مصعد عامر : في كل طابق، 3 كيخرجو و 3 كيدخلو — المصعد **باقي عامر**، ولكن ماشي نفس الناس ! التوازن الكيميائي هو هادا : التراكيز ما كتتحركش، **ماشي** حيت والو ما واقع، ولكن حيت التفاعلين المباشر والعكسي غاديين **بنفس السرعة**. **توازن ديناميكي** — الكلمة المفتاح ديال الفصل. (كيفاش نتوقعو الاتجاه : P20.)

## 2. Résumé du cours (exigible au bac)

**Totale / limitée.** TOTALE : $x_f = x_{max}$ (limitant ÉPUISÉ, $\tau = 1$) ; LIMITÉE : $x_f = x_{éq} < x_{max}$ (s'arrête AVANT : l'inverse la freine !). Exemple-roi : estérification ($K = 4$, 1 mol + 1 mol → $x_{éq} = 0{,}67$, $\tau = 67$ % — limitée !).

**Équilibre dynamique.** À l'équilibre : $[\,]$ CONSTANTES mais $v_{direct} = v_{inverse} \neq 0$ (les flux s'annulent, RIEN ne s'arrête !). Preuve : traceurs isotopiques — les atomes continuent de s'échanger. Dire « la réaction s'arrête » = FAUX au bac !

**Constante d'équilibre $K$.** $\boxed{K = Q_r\text{ à l'équilibre}}$ — SANS unité, ne dépend que de $T$ (ni $[]_0$, ni catalyseur, ni pression !). $K > 10^4$ : quasi-TOTALE ; $K < 10^{-4}$ : quasi-NULLE ; entre : LIMITÉE (mais $\tau$ dépend AUSSI de $[]_0$ : $K = 140$ dilué → $\tau = 11$ % ! voir R2).

**Taux d'avancement.** $\boxed{\tau = x_{éq}/x_{max}}$ (sans unité, $\leq 1$) : $\tau = 1$ totale, $\tau < 1$ limitée. $x_{éq}$ : poser $Q_r(x_{éq}) = K$ (tableau en $x$ !) → équation (souvent 2nd degré) → **REJETER toute racine $> x_{max}$** (racine parasite — piège bac !).

**TOTAL $\neq$ RAPIDE.** $\tau$ = JUSQU'OÙ (thermo, ce chapitre) ; $t_{1/2}$ = EN COMBIEN DE TEMPS (cinétique, P17) ! Rouille : $\tau \approx 1$, $t_{1/2}$ = des mois. Question-piège garantie.

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**تام / محدود :** التام : $x_f = x_{max}$ (المحد **تسالي**، $\tau = 1$) ؛ المحدود : $x_f = x_{éq} < x_{max}$ (كيحبس **قبل** : العكسي كيفرملو !). المثال الملك : الأسترة ($K = 4$ ← $\tau = 67$ % — محدود !).

**التوازن الديناميكي :** في التوازن : التراكيز **ثابتة** ولكن $v_{مباشر} = v_{عكسي} \neq 0$ (التدفقات كتلغى، والو ما كيحبس !). الدليل : الواسمات النظيرية — الذرات كتبقى تتبادل. قول «التفاعل حبس» = غالط في الوطني !

**ثابت التوازن $K$ :** $\boxed{K = Q_r\text{ في التوازن}}$ — بلا وحدة، معتمد غير على $T$ (لا التراكيز الابتدائية، لا الوسيط !). $K > 10^4$ : شبه-تام ؛ $K < 10^{-4}$ : شبه-منعدم ؛ بيناتهم : محدود (ولكن $\tau$ معتمد حتى على $[]_0$ : $K = 140$ مخفف ← $\tau = 11$ % !).

**نسبة التقدم :** $\boxed{\tau = x_{éq}/x_{max}}$ ($\leq 1$) : $= 1$ تام، $< 1$ محدود. $x_{éq}$ : حط $Q_r(x_{éq}) = K$ (الجدول بـ $x$ !) ← معادلة ← **رفض أي جذر $> x_{max}$** (الجذر الطفيلي — فخ الباك !).

**التام ماشي السريع :** $\tau$ = حتى فين (ترمو، هاد الفصل) ؛ $t_{1/2}$ = في شحال (حركية، P17) ! الصدا : $\tau \approx 1$، $t_{1/2}$ = شهور. سؤال-فخ مضمون.

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **« À l'équilibre, la réaction s'arrête »** : NON — $v_{dir} = v_{inv} \neq 0$ (DYNAMIQUE !). Les concentrations sont fixes, les réactions CONTINUENT.
- 🪤 **Garder la racine $> x_{max}$** : $x_{éq} \leq x_{max}$ TOUJOURS — la racine parasite ($x = 2$ pour $x_{max} = 1$ !) se fait piéger à chaque bac. Vérifier, rejeter !
- 🪤 **« $K = 140$ grand → totale »** : $140 \ll 10^4$ : à ces DILUTIONS, $\tau = 11$ % (R2 !) — $\tau$ dépend AUSSI de $[]_0$, pas que de $K$.
- 🪤 **$\tau = 1$ = « rapide »** : FAUX — finir un marathon ($\tau$) vs sprinter ($t_{1/2}$) : deux qualités différentes (rouille : $\tau \approx 1$, lente !).
- Mots-clés : *DYNAMIQUE ($v_{dir} = v_{inv}$), $K$ = que $T$, $\tau = x_{éq}/x_{max}$, rejeter $> x_{max}$, $\tau$ ($[]_0$ !), total ≠ rapide.*

## 9. Le « pourquoi » profond — pourquoi ça s'arrête avant la fin 🔬

**Pourquoi DYNAMIQUE ?** Les molécules ne savent pas qu'elles sont « à l'équilibre » : les chocs efficaces continuent dans les 2 sens. $Q_r = K$ signifie $v_{direct} = v_{inverse}$ (annulation des FLUX, pas arrêt !). Preuve : traceurs isotopiques — les atomes continuent de s'échanger à l'équilibre. **L'équilibre = match nul avec jeu, pas match arrêté.**

**Pourquoi $K$ ne dépend-il que de $T$ ?** $\Delta G° = -RT\ln K$ : $K$ vient des énergies des LIAISONS (constantes !) et de $T$ (agitation). Concentrations initiales, catalyseur, pression : changent le CHEMIN ou la VITESSE, jamais la DESTINATION. **$K$ = la destination ($T$ la déplace) ; le reste = le voyage.**

**Pourquoi $\tau$ dépend-il de $[]_0$ (à $K$ fixé) ?** $Q_r(x_{éq}) = K$ : le point d'arrivée $x_{éq}$ dépend du POINT DE DÉPART ($[]_0$ diluées → $Q_r$ part de loin → $x_{éq}$ petit → $\tau$ petit, R2 : 11 % !). **Même destination $K$, trajets différents : $\tau$ = fraction du chemin ($x_{max}$) parcourue — diluer allonge le chemin relatif.**

**Liens croisés :** P20 — jumeau ($Q_r$, sens : le COMMENT) ; P17/P18 — cinétique ($t_{1/2}$ : le QUAND — opposition bac $\tau$/$t_{1/2}$ !) ; P26 — estérification (l'exemple-roi : $K = 4$, $\tau = 67$ %) ; P21 — $K_a$ (un $K$ comme un autre !) ; P23 — $Q_r$ vs $K$ (même test !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « Équilibre = réactions arrêtées. »** Non : $v_{dir} = v_{inv} \neq 0$ — les concentrations sont fixes PARCE QUE les flux s'annulent. **Le déclic :** *l'ascenseur reste plein (3 sortent, 3 entrent) — plein fixe, personnes changées. Fixe ≠ arrêté.*

**2. « $K$ grand = totale, toujours. »** Non : $\tau$ dépend AUSSI de $[]_0$ ($K = 140$ dilué → $\tau = 11$ % !). Seul $K > 10^4$ garantit quasi-total (et $K < 10^{-4}$ quasi-nul). **Le déclic :** *$K$ = la pente de la route ; $[]_0$ = le point de départ — même pente, départs différents = arrivées ($\tau$) différentes.*

**3. « $x = 2$ ($> x_{max} = 1$) : solution. »** Non : $x_{éq} \leq x_{max}$ (on ne dépasse JAMAIS le bilan !). L'équation $Q_r(x) = K$ donne 2 racines mathématiques ; la physique n'en garde qu'UNE. **Le déclic :** *l'équation propose, le bilan dispose — $x_{max}$ = le plafond, toute racine au-dessus = parasite à jeter.*
