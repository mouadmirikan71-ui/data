# How to understand this chapter the easy way — 19 Non totales et équilibre

> بصوت الأستاذ فالقسم : المصعد العامر + 67% ديال الأسترة — 5 خطوات والتوازن كيولي بديهي.

## الخطوة 1 — المصعد : ثابت ماشي حابس (ديناميكي !)

المصعد عامر : 3 كيخرجو و 3 كيدخلو — العدد **ثابت** ولكن الناس **تبدلو**. التوازن الكيميائي : التراكيز ثابتة حيت المباشر والعكسي غاديين **بنفس السرعة** ($v_{dir} = v_{inv} \neq 0$).

**«التفاعل حبس» = غالط !** الصحيح : «التفاعلان متوازيان» (الواسمات النظيرية كتشهد : الذرات كتبقى تتبادل في التوازن !). ثابت ≠ حابس — هاد الفرق = نقطة في الوطني.

## الخطوة 2 — $\tau = x_{éq}/x_{max}$ : شحال وصلتي من الطريق ؟

تام ($\tau = 1$) : وصلتي للخر ($x_{max}$ — المحد تسالي). محدود ($\tau < 1$) : حبستي قبل (العكسي فرملك !).

**المثال الملك (حفظو !) :** الأسترة $K = 4$ (1 مول + 1 مول) ← $x_{éq} = 0{,}67$ ← $\tau = 67$ %. محدودة : الثلث ما تفاعلش (الماء والإستر كيرجعو حمض وكحول — العكسي خدام !). التفاصيل الكيميائية : P26 ؛ هنا : الفكرة (محدود !).

## الخطوة 3 — $K$ : الوجهة (الحرارة وحدها كتحركها !)

$K = Q_r$ في التوازن : **الوجهة** اللي النظام غادي ليها. بلا وحدة. معتمدة غير على $T$ : التراكيز الابتدائية كتبدل **الرحلة** (منين بديتي)، الوسيط كيسرّع **الرحلة** — بجوج ما كيبدلوش **الوجهة** !

$K > 10^4$ : شبه-تام (الوجهة بعيدة في جهة النواتج). $K < 10^{-4}$ : شبه-منعدم. بيناتهم : محدود — ولكن $\tau$ معتمد حتى على نقطة الانطلاق ($[]_0$ : R2 !).

## الخطوة 4 — $x_{éq}$ : حط $Q_r(x) = K$ ورفض الطفيلي !

الجدول بـ $x$ (P17 !) ← عوّض كل $[\,]$ بالتعبير ديالها ← ساوي مع $K$ ← معادلة بمجهول واحد (غالباً من الدرجة 2).

**الحيلة :** $x^2/(1-x)^2 = 4$ ← خد الجذر التربيعي من الجهتين ← $x/(1-x) = 2$ ← $x = 0{,}67$ (بلا مميز !). **ومن بعد : تحقق $x \leq x_{max}$** — الجذر اللي فوق السقف ($x = 2$ والسقف 1 !) = طفيلي : رميه ! (الفخ المفضل ديال الوطني.)

## الخطوة 5 — التام ماشي السريع (سؤال-فخ مضمون !)

$\tau$ = **حتى فين** (ترمو : هاد الفصل). $t_{1/2}$ = **في شحال** (حركية : P17). الصدا : $\tau \approx 1$ (تام !) و $t_{1/2}$ = شهور (بطيء !).

**التشبيه :** تكمل الماراطون ($\tau$) ماشي تجري بسرعة ($t_{1/2}$) — جوج صفات مختلفين. 4 تركيبات ممكنة (تام-سريع، تام-بطيء، محدود-سريع، محدود-بطيء) — الوطني كيسول عليهم !

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. التوازن = تعادل مباشر/عكسي (ديناميكي !).
2. $\tau = x_{éq}/x_{max}$ (الأسترة : 67 % — حفظها !).
3. $K$ = الوجهة (غير $T$ ! + القواعد $10^{\pm4}$).
4. $x_{éq}$ : $Q_r(x) = K$ + رفض $> x_{max}$ !
5. $\tau$ = فين / $t_{1/2}$ = شحال (مستقلين !).
