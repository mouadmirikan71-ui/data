# Exercices types — $Q_r$ et sens (P20)

## Méthode — sens en 5 gestes 🧭

1. Équation ÉQUILIBRÉE (exposants !).
2. $Q_r$ : solides/solvant EXCLUS.
3. $Q_{r,i}$ (INITIALES) vs $K$ → sens ($Q_r$ chasse $K$ !).
4. $T$ : ↑ → endo, ↓ → exo.
5. Catalyseur : même $K$ !

## R1 — TYPE-BAC (sens : estérification)

🏷️ matière=PC · année=— · session=— · chapitre=P20 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** $acide + alcool \rightleftharpoons ester + eau$, $K = 4$. Mélange : $[ac]_0 = [alc]_0 = 0{,}50$ M, $[est]_0 = [eau]_0 = 0{,}10$ M. Sens ?

**Corrigé-type.** $Q_{r,i} = 0{,}10\times0{,}10/(0{,}50\times0{,}50) = 0{,}04 < 4 = K$ → $\boxed{\text{sens DIRECT}}$ (le système fabrique ester + eau jusqu'à $Q_r = 4$).
🪤 *Piège testé : « $Q_r < K$ → inverse » — $Q_r$ doit MONTER vers $K$ : monter = produire des PRODUITS = sens DIRECT. $Q_r$ chasse $K$ !*

## R2 — TYPE-BAC (solides exclus + T)

🏷️ matière=PC · année=— · session=— · chapitre=P20 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** $CaCO_3(s) \rightleftharpoons CaO(s) + CO_2(g)$, $K = 0{,}050$ (endo). a) $Q_r$ ? b) $[CO_2]_{éq}$ ? c) On double $CaCO_3$ ? d) $T$ ↑ ?

**Corrigé-type.** a) $Q_r = \boxed{[CO_2]}$ (solides EXCLUS !). b) $[CO_2] = K = \boxed{0{,}050\text{ M}}$. c) $\boxed{\text{RIEN}}$ — le solide n'est pas dans $Q_r$ ! d) Endo + $T$ ↑ → $K$ ↑ → sens DIRECT, plus de $CO_2$.
🪤 *Piège testé : $Q_r = [CaO][CO_2]/[CaCO_3]$ — solides JAMAIS dans $Q_r$ : doubler un solide ne déplace RIEN.*

## R3 — TYPE-BAC (perturbation : 2 méthodes !)

🏷️ matière=PC · année=— · session=— · chapitre=P20 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** Estérification ($K = 4$) à l'équilibre : $[ac] = [alc] = 0{,}33$ M, $[est] = [eau] = 0{,}67$ M (vérifier !). On ajoute $0{,}50$ M d'ester (sans changer $V$). Sens d'évolution ?

**Corrigé-type — Méthode 1 (calcul $Q_{r,i}$).** Vérif : $0{,}67^2/0{,}33^2 = 4{,}1 \approx 4$ ✓ (équilibre). Après ajout : $[est] = 1{,}17$ → $Q_{r,i} = 1{,}17\times0{,}67/0{,}33^2 = 7{,}2 > 4 = K$ → $\boxed{\text{sens INVERSE}}$ (le système consomme l'ester ajouté jusqu'à $Q_r = 4$).

**Corrigé-type — Méthode 2 (raisonnement).** Si DIRECT : $[est]$ ↑ encore → $Q_r$ ↑ → s'ÉLOIGNE de $K = 4$ (absurde : le système fuit son équilibre ?). Si INVERSE : $[est]$ ↓ → $Q_r$ ↓ vers $4$ ✓. Donc $\boxed{\text{INVERSE}}$ — par l'absurde, sans calcul.
🪤 *Piège testé : « ajout d'ester → direct (plus de matière !) » — ajouter un PRODUIT sature le numérateur : le système RECULE (Le Chatelier : opposition à la perturbation !).*
