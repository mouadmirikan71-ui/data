## R1 — TYPE-BAC (excès : 67 % → 90 % — 2 méthodes !)

🏷️ matière=PC · année=— · session=— · chapitre=P27 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** $1{,}0$ mol acide + $3{,}0$ mol éthanol, $K = 4$. a) $x_{éq}$ ? b) $\tau$ vs 1-1 ? c) $m(ester)$ ($M = 88$) ?

**Corrigé-type — Méthode 1 (discriminant).** $x^2/((1-x)(3-x)) = 4$ → $3x^2-16x+12 = 0$ → $\Delta = 256-144 = 112$ → $x = (16\pm10{,}58)/6$ → $x = \boxed{0{,}90}$ ($4{,}43$ REJETÉE : $> x_{max} = 1{,}0$ !). $\tau = \boxed{90\%}$ vs $67\%$ (1-1) : l'excès DÉPLACE ✓. $m = 0{,}90\times88 = \boxed{79\text{ g}}$.

**Corrigé-type — Méthode 2 (test intelligent).** $\tau$ entre $67$ % (1-1) et $100$ % : tester $x = 0{,}90$ : $Q_r = 0{,}90^2/(0{,}10\times2{,}10) = 0{,}81/0{,}21 = 3{,}86 \approx 4 = K$ ✓ → $\boxed{x_{éq} \approx 0{,}90}$ (vérifié !). Affiner : $x = 0{,}904$ → $Q_r = 4{,}00$ ✓.
🪤 *Piège testé : garder $x = 4{,}43$ — $> x_{max} = 1{,}0$ : IMPOSSIBLE : la racine parasite frappe encore (cf P19 R1 !).*

## R3 — TYPE-BAC (saponification : totale + rendement)

🏷️ matière=PC · année=— · session=— · chapitre=P27 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** $0{,}20$ mol d'éthanoate d'éthyle ($M = 88$) + $HO^-$ en excès (saponification, TOTALE). a) $m$ (ester initial) ? b) $m$ (savon, carboxylate de sodium $M = 82$) ? c) On obtient $14{,}8$ g : $\rho$ ?
