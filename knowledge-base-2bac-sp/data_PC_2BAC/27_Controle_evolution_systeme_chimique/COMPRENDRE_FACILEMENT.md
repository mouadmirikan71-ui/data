# How to understand this chapter the easy way — 27 Contrôle

> بصوت الأستاذ فالقسم : 67% ما كافياش — زيد، سحب، بدّل — 5 خطوات وصانع العطور كيولي راضي.

## الخطوة 1 — الزيادة : غرّق المتفاعلات ($Q_{r,i}$ صغير ← المباشر مفروض !)

$Q_{r,i}$ = النواتج/المتفاعلات : كثر المتفاعلات ← $Q_{r,i}$ صغير ← $Q_{r,i} \ll K$ ← النظام «كيجري» مدة أطول نحو $K$.

1-3 (حمض + 3 كحول) : $x = 0{,}90$ ← $\tau = 90$ % (مقابل 67 % !). **بالزيادة : الرخيص** (الكحول !) — الغالي (الحمض !) هو المحد. الزيادة = رجّع نقطة الانطلاق للور باش تطول الجرية نحو $K$ !

## الخطوة 2 — الإزالة : سحب الناتج ($Q_r$ ↓ ← ممصوص !)

قطّر الإستر المتطاير (كيهرب !) ولا مصّ الماء ($H_2SO_4$ المجفف !) ← $Q_r$ كيهبط ← التوازن «كيجري» وراء الناتج المسحوب (لوشاتوليي !).

**سحبتي كلشي ؟ وصلتي للخر (100 %) !** التوازن ما كيلحقش $K$ أبداً (الناتج كيهرب ديما !) ← كيمشي حتى النهاية. الإزالة المستمرة = الشفط المستمر = التحول الكامل !

## الخطوة 3 — التغيير : الأنهيدريد و $HO^-$ (تامات !)

الأنهيدريد + كحول ← إستر : **تام + سريع** (الأنهيدريد فوق-تفاعلي : العكس شبه-مستحيل !). كلورور الأسيل : نفس الشي (عنيف — كيحتاج الحيطة !).

التصبن ($إستر + HO^-$) : $HO^-$ كيستهلك الحمض **أول بأول** (تام !) : التوازن ممصوص لليمين باستمرار ← كيمشي للخر ← **الصابون** (كربوكسيلات الصوديوم : منظف !). $Q_r$ ما كيلحقش $K$ أبداً (مصيدة الحمض !) ← التحول الكامل.

## الخطوة 4 — المردود : $\rho$ = المحصل/النظري ($\leq \tau$ ديما !)

$\tau$ = الحد **الترموديناميكي** (التوازن : 90 % مثلاً). $\rho$ = النتيجة **العملية** (الضياعات : النقل، التنقية !).

$m_{نظري} = 79$ غ، $m_{محصل} = 71$ غ ← $\rho = 90$ %. **$\tau$ = الفيزياء (السقف) ؛ $\rho$ = الفيزيائي (الضياعات)** — ما كتفوتش السقف أبداً ($\rho > \tau$ = غلطة في الحساب !).

## الخطوة 5 — الاختبارات : DNPH اللول، فهلنغ من بعد ! (الترتيب !)

البروم : $C=C$ (إزالة اللون !). DNPH : $C=O$ (راسب أصفر — ألدهيد **ولا** كيتون !). فهلنغ ساخن : الألدهيد **بوحدو** (راسب أحمر — المرجع !). ثنائي الكرومات : الكحول القابل للأكسدة (برتقالي ← أخضر !).

**3 قنينات (بروبانال، بروبانون، بروبان-1-أول) ؟** DNPH اللول : $-$ ← الكحول (تعزل !) ؛ الجوج $+$ ← فهلنغ : $+$ ← بروبانال، $-$ ← بروبانون ✓. **DNPH = المجموعة ($C=O$ ؟) ؛ فهلنغ = السلوك (مرجع = ألدهيد ؟).** المجموعة اللول، السلوك من بعد — ترتيب البروتوكول !

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. الزيادة : الرخيص بالزيادة (67 ← 90 % !).
2. الإزالة : قطّر المتطاير (الشفط المستمر !).
3. الأنهيدريد/$HO^-$ : تامات (فوق-تفاعلي/مصيدة !).
4. $\rho \leq \tau$ (السقف/الضياعات !).
5. DNPH ← فهلنغ (المجموعة ← السلوك !).
