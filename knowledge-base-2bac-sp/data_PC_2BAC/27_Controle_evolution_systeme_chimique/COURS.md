# Chapitre 27 — Contrôle de l'évolution d'un système chimique

> 📋 **Exigible au bac (SI !)** : 67 % (1-1) ne suffit pas → FORCER : EXCÈS d'un réactif (1-3 → $\tau = 90$ % !), ÉLIMINATION d'un produit (distillation ester/eau, $H_2SO_4$ déshydratant — $Q_r$ ↓ → DIRECT !), CHANGER de réactif (anhydride/chlorure d'acyle + alcool → TOTALE + RAPIDE ! ; SAPONIFICATION $ester + HO^-$ → TOTALE → savon !) ; $\boxed{\rho = n_{obtenu}/n_{théo}}$ (rendement PRATIQUE : $\rho \leq \tau$ !) ; oxydation : 1aire → ALDÉHYDE → ACIDE / 2aire → CÉTONE / 3aire → RIEN ($Cr_2O_7^{2-}$ orange → vert !) ; TESTS : brome ($C=C$), DNPH ($C=O$), Fehling (ALDÉHYDE seul !) ; contrôle : dosage acide restant (P22 !), indice d'acide.

## 1. Accroche — le parfumeur veut 100 %, pas 67 % 🌸📈

L'estérification 1-1 plafonne à 67 % (P26) : le parfumeur perd 1/3 de matière ! Alors il TRICHE : excès d'alcool (90 % !), distillation de l'eau (l'équilibre aspire !), anhydride (100 % direct !). Et il VÉRIFIE (tests, dosage) : c'est le contrôle qualité. Tout le chapitre : *forcer (3 leviers), mesurer ($\rho$), oxyder (alcools), tester (4 tests), contrôler (dosage).* La réaction de base : P26.

> بالدارجة : الأسترة 1-1 كتحبس في 67 % (P26) : صانع العطور كيضيع الثلث ! إذن **كيغش** : زيادة الكحول (90 % !)، تقطير الماء (التوازن كيمص !)، الأنهيدريد (100 % مباشرة !). و**كيتحقق** (الاختبارات، المعايرة) : هادي هي مراقبة الجودة. كاع الفصل : *فرض (3 رافعات)، قيس ($\rho$)، أكسد (الكحولات)، اختبر (4 اختبارات)، راقب (المعايرة).* التفاعل الأساسي : P26.

## 2. Résumé du cours (exigible au bac)

**Levier 1 — EXCÈS.** $Q_{r,i}$ petit (réactifs ↑) → DIRECT forcé (P20 !). Estérification 1-3 (acide + 3 alcool) : $x^2/((1-x)(3-x)) = 4$ → $x = 0{,}90$ → $\tau = 90$ % (vs 67 % !). En excès : l'alcool (pas cher !) — l'acide (cher !) est limitant.

**Levier 2 — ÉLIMINATION d'un produit.** Retirer ester ou eau (DISTILLATION : l'ester volatil s'échappe ! ; $H_2SO_4$ DÉSHYDRATANT : pompe l'eau !) → $Q_r$ ↓ → DIRECT aspiré (Le Chatelier !). L'équilibre « court » après le produit retiré — jusqu'au bout si on retire tout !

**Levier 3 — CHANGER de réactif (totales !).** ANHYDRIDE d'acide + alcool → ester + acide : TOTALE + RAPIDE (l'anhydride est SUR-réactif !). CHLORURE d'acyle : idem (violent !). SAPONIFICATION : $ester + HO^- \to carboxylate + alcool$ : TOTALE — $HO^-$ consomme l'ACIDE au fur et à mesure (aspiration Le Chatelier !) → SAVON (carboxylate de sodium : tensioactif !).

**Rendement.** $\boxed{\rho = n_{obtenu}/n_{théo}}$ (ou $m_{obtenu}/m_{théo}$) : PRATIQUE (pertes manip : transferts, purif !). $\rho \leq \tau$ TOUJOURS ($\tau$ = la chimie ; $\rho$ = le chimiste !). Ex. : $m_{théo} = 79$ g, $m_{obtenu} = 71$ g → $\rho = 90$ %.

**Oxydation ménagée des alcools** ($Cr_2O_7^{2-}$ + $H^+$ : orange → VERT = TEST !). Primaire → ALDÉHYDE → ACIDE (2 étapes : 2 $H$ !) ; secondaire → CÉTONE (1 étape, bloqué !) ; **tertiaire → RIEN** (pas de $H$ sans casser C-C !). Redox : P23 ($Cr_2O_7^{2-}/Cr^{3+}$ !).

**Les 4 TESTS (par cœur !).** $C=C$ : eau de BROME (DÉCOLORATION !) ; $C=O$ (ald + cétones) : 2,4-DNPH (précipité JAUNE) ; ALDÉHYDE seul : FEHLING à chaud (précipité ROUGE) / TOLLENS (miroir Ag) ; alcool oxydable : $Cr_2O_7^{2-}$ (orange → VERT). Stratégie : DNPH D'ABORD (isole l'alcool : $-$ !), Fehling ENSUITE (tranche ald/cétone !).

**Contrôle qualité.** DOSAGE de l'acide restant ($C_aV_a = C_bV_{éq}$ — P22 !) → $x$ réel → $\rho$ ; INDICE D'ACIDE (mg $KOH$/g : contrôle huiles/beurre !).

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**الرافعة 1 — الزيادة :** $Q_{r,i}$ صغير (متفاعلات ↑) ← المباشر مفروض (P20 !). الأسترة 1-3 : $\tau = 90$ % (مقابل 67 % !). بالزيادة : الكحول (رخيص !) — الحمض (غالي !) هو المحد.

**الرافعة 2 — إزالة ناتج :** سحب الإستر ولا الماء (التقطير : الإستر المتطاير كيهرب ! ؛ $H_2SO_4$ المجفف : كيمص الماء !) ← $Q_r$ ↓ ← المباشر ممصوص (لوشاتوليي !). التوازن «كيجري» وراء الناتج المسحوب — حتى الخر إلا سحبتي كلشي !

**الرافعة 3 — تغيير المتفاعل (تامات !) :** الأنهيدريد + كحول ← إستر : **تام + سريع** (الأنهيدريد فوق-تفاعلي !). كلورور الأسيل : نفس الشي (عنيف !). التصبن : $إستر + HO^-$ ← **تام** — $HO^-$ كيستهلك الحمض أول بأول (المص اللوشاتوليي !) ← الصابون !

**المردود :** $\boxed{\rho = n_{المحصل}/n_{النظري}}$ : عملي (ضياعات المناولة !). $\rho \leq \tau$ ديما ($\tau$ = الكيمياء ؛ $\rho$ = الكيميائي !).

**الأكسدة اللطيفة للكحولات** ($Cr_2O_7^{2-}$ : برتقالي ← أخضر = اختبار !). أولي ← ألدهيد ← حمض (جوج مراحل !) ؛ ثانوي ← كيتون (مرحلة، مبلوكي !) ؛ **ثالثي ← والو** (لا $H$ بلا تكسير C-C !).

**الـ 4 اختبارات (حفظ !) :** $C=C$ : ماء البروم (**إزالة اللون** !) ؛ $C=O$ : DNPH (راسب أصفر) ؛ الألدهيد بوحدو : فهلنغ ساخن (راسب أحمر) ؛ الكحول القابل للأكسدة : ثنائي الكرومات (برتقالي ← أخضر). الاستراتيجية : DNPH **اللول** (كيعزل الكحول !)، فهلنغ **من بعد** (كيفصل ألدهيد/كيتون !).

**مراقبة الجودة :** معايرة الحمض الباقي (P22 !) ← $x$ الحقيقي ← $\rho$ ؛ دليل الحموضة (مراقبة الزيوت !).

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **DNPH (+) = aldéhyde** : NON — DNPH = $C=O$ (aldéhyde OU cétone !). Seul Fehling/Tollens tranche (aldéhyde SEUL réduit). DNPH = le GROUPE ; Fehling = le COMPORTEMENT.
- 🪤 **Fehling D'ABORD** : Fehling $-$ = cétone OU alcool (2 suspects !) : DNPH D'ABORD (isole l'alcool : $-$ !), Fehling ENSUITE !
- 🪤 **« Catalyseur DÉPLACE ($H^+$ → 90 %) »** : NON — $H^+$ = VITESSE (même $K$, même $\tau$ !). Déplacer : excès, élimination, anhydride — PAS le catalyseur (P17/P20 !).
- 🪤 **$\rho = \tau$** : NON — $\rho \leq \tau$ ($\tau$ = équilibre, THERMO ; $\rho$ = manip, PRATIQUE : pertes !). $\rho > \tau$ = IMPOSSIBLE (erreur !).
- Mots-clés : *excès (pas cher !), éliminer ($Q_r$ ↓ !), anhydride/$HO^-$ (totales !), $\rho \leq \tau$, 1→ald/2→cét/3→RIEN, DNPH PUIS Fehling.*

## 9. Le « pourquoi » profond — pourquoi forcer marche 🔬

**Pourquoi l'EXCÈS déplace ?** $Q_{r,i}$ = produits/réactifs : noyer les réactifs → $Q_{r,i}$ PETIT → $Q_{r,i} \ll K$ → DIRECT forcé (P20 : $Q_r$ chasse $K$ DE LOIN !). 1-3 : le système « court » plus longtemps vers $K = 4$ → $x = 0{,}90$. **L'excès = reculer le point de départ pour allonger la course vers $K$.**

**Pourquoi SAPONIFICATION totale ?** $HO^-$ consomme l'ACIDE au fur et à mesure ($acide + HO^- \to$ carboxylate + eau, TOTALE) : l'équilibre est ASPIRÉ vers la droite (Le Chatelier — retrait CONTINU d'un produit de l'hydrolyse !). C'est le même $Q_r$ vs $K$ (P19/P20) avec un PIÈGE À ACIDE : $Q_r$ ne rattrape JAMAIS $K$ → va au bout !

**Pourquoi le TERTIAIRE ne s'oxyde PAS ?** Oxyder = arracher des H du C-OH (ou ajouter O) : le C tertiaire n'a AUCUN H (3 voisins C) — oxyder exigerait CASSER une liaison C-C (trop chère : pas « ménagée » !). Primaire (2 H) → 2 étapes ; secondaire (1 H) → 1 étape (cétone, bloqué !). **Pas de H = pas d'oxydation douce — le squelette verrouille.**

**Liens croisés :** P19/P20 — $Q_r$ vs $K$ (LE MOTEUR : excès/élimination = jouer sur $Q_r$ !) ; P26 — la réaction de base ; P22 — dosage de contrôle (acide restant !) ; P23 — redox ($Cr_2O_7^{2-}/Cr^{3+}$ : l'oxydant !) ; P17 — catalyseur ($\neq$ déplacement !) ; SVT S01 — savon (lipides !) ; industrie — parfums, savons, biocarbures (esters !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « $H^+$ déplace (plus de produit). »** Non : $H^+$ = VITESSE (même $K = 4$, même $\tau$ !). **Le déclic :** *le catalyseur = l'autoroute (même destination $K$, plus vite — P17 !) ; l'excès/l'élimination = déménager la destination. Autoroute ≠ déménagement.*

**2. « $\rho = \tau$ (ou $\rho > \tau$ !). »** Non : $\rho \leq \tau$ TOUJOURS. $\tau$ = limite THERMO (l'équilibre) ; $\rho$ = résultat PRATIQUE (pertes : transferts, purification !). **Le déclic :** *$\tau$ = la physique (le plafond) ; $\rho$ = le physicien (les pertes) — on ne dépasse jamais le plafond ($\rho > \tau$ = erreur de calcul !).*

**3. « Fehling (+) = $C=O$. »** Non : Fehling (+) = ALDÉHYDE (réducteur !) ; $C=O$ (les deux) = DNPH. **Le déclic :** *DNPH détecte le GROUPE ($C=O$ présent ?) ; Fehling détecte le COMPORTEMENT (réducteur = aldéhyde ?). Groupe d'abord (DNPH), comportement ensuite (Fehling) — l'ordre du protocole !*
