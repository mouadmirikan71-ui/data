# FAQ — Chapitre 27 (Contrôle)

**1. Excès : quel réactif ?**
Le MOINS CHER (éthanol !) — le cher (acide !) est limitant (tout consommé… enfin, à 90 % !). Économique ET chimique : l'excès noie $Q_{r,i}$ (→ DIRECT !) — peu importe lequel, mais le portefeuille tranche.
/ الأرخص (الإيثانول !) — الغالي (الحمض !) هو المحد. اقتصادية وكيميائية : الزيادة كتغرق $Q_{r,i}$ — الجيب هو اللي كيحسم !

**2. Éliminer : comment en pratique ?**
DISTILLATION (l'ester volatil s'échappe au fur et à mesure !), $H_2SO_4$ DÉSHYDRATANT (pompe l'eau !), PRÉCIPITATION (le produit sort en solide !). Retirer en CONTINU → $Q_r$ ne rattrape jamais $K$ → va au bout !
/ التقطير (الإستر المتطاير كيهرب أول بأول !)، $H_2SO_4$ المجفف (كيمص الماء !)، الترسيب ! السحب المستمر ← $Q_r$ ما كيلحقش $K$ ← التحول الكامل !

**3. Anhydride : pourquoi TOTALE ?**
L'anhydride est SUR-réactif (l'inverse est quasi-impossible : $K \gg 10^4$ !) : la réaction VA AU BOUT (et VITE !). Idem chlorure d'acyle (violent !) et saponification ($HO^-$ : aspiration !). Changer de réactif = changer de $K$ !
/ الأنهيدريد فوق-تفاعلي (العكس شبه-مستحيل : $K$ ضخم !) : كيمشي للخر (وبسرعة !). تغيير المتفاعل = تغيير $K$ !

**4. $\rho$ vs $\tau$ ?**
$\tau$ = limite THERMO (l'équilibre : 90 % max !) ; $\rho$ = résultat PRATIQUE (pertes : transferts, purif !). $\rho \leq \tau$ TOUJOURS ($\rho > \tau$ = erreur !). $\tau$ = le plafond (physique) ; $\rho$ = le score (chimiste).
/ $\tau$ = الحد الترموديناميكي (التوازن !) ؛ $\rho$ = النتيجة العملية (الضياعات !). $\rho \leq \tau$ ديما ($\rho > \tau$ = غلطة !).

**5. Tertiaire : vraiment RIEN ?**
Vraiment RIEN (en oxydation MÉNAGÉE !) : pas de $H$ sur le C-OH sans casser une liaison C-C (trop chère !). Oxydation FORTE (combustion !) : tout brûle — mais ce n'est plus « ménagé ». Ménagé = doux (pas de casse C-C).
/ والله والو (في الأكسدة اللطيفة !) : لا $H$ بلا تكسير C-C (غالي بزاف !). الأكسدة القوية (الاحتراق !) : كلشي كيتحرق — ولكن ماشي «لطيفة».

**6. DNPH puis Fehling : pourquoi cet ordre ?**
DNPH isole l'ALCOOL ($-$ : pas de $C=O$ !) ; Fehling tranche les 2 restants (aldéhyde $+$ / cétone $-$). Fehling d'abord : $-$ = cétone OU alcool (2 suspects — ambigu !). L'ordre dissout l'ambiguïté : groupe (DNPH) PUIS comportement (Fehling).
/ DNPH كيعزل الكحول ($-$ !) ؛ فهلنغ كيفصل الجوج الباقيين. فهلنغ اللول : $-$ = كيتون ولا كحول (جوج مشتبهين — غامض !). الترتيب كيحل الغموض.
