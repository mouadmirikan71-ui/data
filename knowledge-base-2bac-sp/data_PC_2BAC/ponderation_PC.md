# Pondération — Physique-Chimie 2BAC SP (2008–2026)

> De quoi est fait un national de PC, en chiffres : fréquence par chapitre,
> points moyens, combinaisons classiques, tendances récentes. Base de calcul du
> moteur de sélection (`poids_chapitres_PC.json`, `moteur_selection_PC.md`).

## 1. Méthode (lis-moi avant de citer un chiffre)

- **37 sessions** codées (2008N → 2026N ; 2026R indisponible ; 2019R : chimie
  seule, physique exclue du calcul).
- **Points par exercice** : gabarit mesuré sur les sessions exactes
  (2023N, 2024R, 2025R, 2026N + 2009R) — format 4 exos : chimie **7** + petit
  exo **2,5** + élec **5** + méca **5,5** = 20 ; format 5 exos (2020N/R, 2021N/R,
  2024R) : 7 + 2,5 + 2 + 3,5 + 5 = 20.
- **Intra-exercice** : points répartis uniformément entre les chapitres codés
  (documenté, faute de barème détaillé par question pour les anciens sujets).
- **Cases vagues** (« électricité », « mécanique » des vieux descriptifs) :
  réparties selon la distribution des sessions détaillées — élec :
  P06 19 % / P07 26 % / P08 37 % / P09 19 % ; méca : P10 10 % / P11 19 % /
  P12 19 % / P13 6 % / P14 13 % / P15 26 % / P28 6 % ; nucléaire :
  P04 87 % / P05 13 % ; ondes : P01 65 % / P02 10 % / P03 25 %.
- **P19/P20/P23** (τ, Qr/K, sens spontané) : jamais un exercice à part —
  transverses mobilisés dans chaque exo de chimie (convention : 0,9 / 0,7 /
  0,6 pt de support). **P16** (atome/Newton) : zéro apparition → plancher 0,05.
- Total contrôlé : 727,0 pts = 37 × 20 − 13 (physique 2019R exclue). ✓
