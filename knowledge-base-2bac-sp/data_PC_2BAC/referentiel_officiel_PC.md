# Référentiel officiel — Physique-Chimie 2BAC SP

> Transcription fidèle du **cadre de référence officiel (2015)** qui fait foi pour
> l'examen national : unités dans l'ordre officiel, objectifs, savoirs et
> savoir-faire exigibles, poids des domaines, niveaux d'habileté, structure de
> l'épreuve et TP. Chaque unité est mappée vers le chapitre KB (`Pxx`).
> **Aucune restructuration** : le découpage KB P01–P28 est conservé tel quel.

## 0. Conformité de la structure KB (tâche 1 — verdict)

- L'ordre officiel S1/S2 (AlloSchool, 29 items) se superpose exactement aux
  27 chapitres P01–P27 + bonus P28. **Aucun chapitre manquant, aucun en trop.**
- Le cadre regroupe chute / projectiles / particules / Kepler dans une seule
  rubrique « Applications » → KB : P11 / P12 / P28. **On garde le découpage KB.**
- ⚠️ Écart signalé (sans restructuration) : le cadre officiel limite le circuit
  RLC aux **oscillations libres + entretien** ; le KB P08 traite en plus le
  **régime sinusoïdal forcé** (utile SM/supérieur, hors cadre SPC).
- ⚠️ P22 (dosages) : le KB en fait un chapitre séparé ; l'officiel le range dans
  le sous-domaine « Transformations non totales ». Pas de changement.

## 1. Structure officielle de l'épreuve

- **3 ou 4 exercices thématiques** (en pratique 4, parfois 5 depuis 2020),
  couvrant **tout le programme**, 3 h, calculatrice scientifique **non
  programmable** autorisée.
- Chaque exercice thématique = un thème, parties indépendantes possibles,
  difficulté progressive, situations habituelles ou inédites liées au réel et aux TP.
- Styles d'items : QCM / Vrai-Faux / appariement, réponse courte, développement,
  synthèse, questions complexes multi-domaines.
- Grille de correction officielle : n° d'exercice + note, éléments de réponse par
  question, **référence de chaque question au cadre**.

## 4. PHYSIQUE — savoirs et savoir-faire exigibles

### 4.1 Ondes mécaniques progressives → P01
- **Savoirs** : onde mécanique, célérité ; transversale vs longitudinale ;
  onde progressive ; relation $y_M(t) = y_S(t-\tau)$.
- **Savoir-faire** : exploiter retard $\tau$ / distance / célérité ; déterminer
  distance, retard, célérité sur documents ; proposer un montage de mesure.

### 4.2 Ondes mécaniques progressives périodiques → P02
- **Savoirs** : onde périodique et sa période ; onde sinusoïdale, $T$, $f$,
  $\lambda$ ; $\lambda = v \cdot T$ ; condition de diffraction
  (ouverture $\lesssim \lambda$) ; caractéristiques de l'onde diffractée ;
  milieu dispersif.
- **Savoir-faire** : reconnaître diffraction sur documents (sonores/ultrasons) ;
  proposer le montage de mise en évidence.

### 4.3 Propagation d'une onde lumineuse → P03
- **Savoirs** : aspect ondulatoire (via diffraction) ; influence de l'ouverture ;
  $\lambda = c/\nu$ ; monochromatique vs polychromatique ; spectre visible ;
  $\nu$ inchangée entre milieux ; milieux dispersifs ; $n = c/v$ ;
  $\theta = \lambda/a$ (unités et sens).
- **Savoir-faire** : exploiter une figure de diffraction ; déterminer $n$ ;
  vérifier $\theta = \lambda/a$ ; proposer le montage.

### 4.4 Décroissance radioactive → P04
- **Savoirs** : symbole $^A_Z X$, composition, isotopie, diagramme $(N,Z)$ ;
  noyau radioactif ; lois de conservation ; $\alpha$, $\beta^+$, $\beta^-$,
  $\gamma$ ; loi de décroissance et sa courbe ; $1\ \mathrm{Bq} = 1\ \mathrm{dés/s}$ ;
  $\tau$, $\lambda$, $t_{1/2}$ et leurs relations ; unités par analyse
  dimensionnelle ; choix du radioélément pour une datation.
- **Savoir-faire** : écrire une équation nucléaire ; identifier le type de
  radioactivité ; exploiter $(N,Z)$ et les courbes.

### 4.5 Noyaux — masse et énergie → P05
- **Savoirs** : défaut de masse, énergie de liaison, $E_l/A$ ; unités
  ($u$, $\mathrm{MeV}$) ; courbe d'Aston et stabilité ; $E = \Delta m \cdot c^2$ ;
  fission vs fusion et leur intérêt énergétique ; applications et dangers.
- **Savoir-faire** : bilans $\Delta E$ (masses, liaisons, $\Delta m$) ;
  écrire et identifier les équations ; $E_{lib} = |\Delta E|$.

### 4.6 Dipôle RC → P06
- **Savoirs** : condensateur (symbole, charges, convention récepteur) ;
  $i = dq/dt$, $q = C \cdot u$ ; $F$, $\mu F$, $nF$, $pF$ ; associations
  série/parallèle ; continuité de $u_C$, discontinuité de $i$ à $t=0$ ;
  constante de temps ; énergie $E_e = \frac{1}{2}C u_C^2$.
- **Savoir-faire** : établir l'EDL + vérifier la solution (échelon) ;
  expressions $u_C(t)$, $i(t)$, $q(t)$ ; courbes et régimes ;
  influence de $R$, $C$, amplitude ; montage + oscilloscope/acquisition.

### 4.7 Dipôle RL → P07
- **Savoirs** : bobine (symbole) ; $u = r \cdot i + L \cdot di/dt$ ;
  $L$ (henry), $r$ ; continuité de $i$, retard à l'établissement ;
  constante de temps ; énergie $E_m = \frac{1}{2}L i^2$.
- **Savoir-faire** : déterminer $L$, $r$ sur données ; EDL + solution ;
  $i(t)$ et tensions ; courbes ; influence de $R$, $L$ ; montage + visu.

### 4.8 Oscillations libres RLC série → P08 (officiel : libres + entretien)
- **Savoirs** : régimes périodique / pseudo-périodique / apériodique ;
  $q(t)$, $i(t)$, période propre $T_0 = 2\pi\sqrt{LC}$ ; lecture énergétique
  (transferts, effet Joule) ; rôle de l'entretien (compenser Joule) ;
  entretien par $u_g = k \cdot i$.
- **Savoir-faire** : EDL (faible amortissement, amorti, entretenu) + vérification ;
  courbes des 3 régimes ; pseudo-période et $T_0$ ; influence de $R$, $L$, $C$ ;
  montage + oscilloscope.

### 4.9 Modulation / démodulation d'amplitude → P09
- **Savoirs** : ondes EM et transport d'énergie sans matière ; antenne
  émettrice/réceptrice (même fréquence) ; tension sinusoïdale ;
  modulation d'amplitude (principe, anti-surmodulation $m<1$) ;
  spectre de fréquences ; étages du récepteur AM ; circuit bouchon $LC$
  sélectif ; détecteur d'enveloppe ; filtres et leurs rôles ; conditions
  de bonne démodulation.
- **Savoir-faire** : reconnaître les étages sur schéma ; exploiter les courbes ;
  identifier $u_{AM}$, enveloppe, $F$, $f$, $m$.

### 4.10 Lois de Newton → P10
- **Savoirs** : vecteurs $\vec v$, $\vec a$ (cartésien, Frenet) ; unité de $a$ ;
  nature du mouvement via $\vec a \cdot \vec v$ ; référentiel galiléen ;
  2e loi ($\sum \vec F_{ext} = m\vec a_G$, domaine de validité, rôle de $m$) ;
  3e loi (actions réciproques).
- **Savoir-faire** : déterminer grandeurs cinématiques et dynamiques ;
  analyse dimensionnelle.

### 4.11 Chute verticale → P11
- **Savoirs** : chute libre (définition, MRUV, équations horaires) ;
  chute avec frottement ($v_\ell$, $\tau$, régimes) ; méthode d'Euler.
- **Savoir-faire** : EDL du centre d'inertie (libre + frottement) ;
  exploiter $v_G = f(t)$ ; choisir le référentiel.

### 4.12 Mouvements plans → P12 (+ P10 pour plans, + P28 pour Kepler)
- **Savoirs** : solide sur plan horizontal/incliné ; projectile (équations
  horaires, trajectoire, portée, flèche) ; particule chargée dans
  $\vec B$ uniforme ($\vec B \perp \vec v_0$ : nature, déflexion) ; Lorentz ;
  référentiels héliocentrique/géocentrique ; Kepler (3 lois, circulaire +
  elliptique) ; gravitation universelle vectorielle ; force centripète.
- **Savoir-faire** : EDL + horaires + trajectoire (projectile, particule) ;
  établir la 3e loi de Kepler (circulaire) ; appliquer Newton à un
  satellite/une planète.

### 4.13 Rotation autour d'un axe fixe → P13
- **Savoirs** : abscisse et accélération angulaires (unités) ; $a_N$, $a_T$ ;
  RFD rotation $\sum \mathcal{M}_\Delta = J_\Delta \ddot\theta$ ;
  unité de $J_\Delta$ ; rotation uniformément variée ; système
  translation + rotation (câble, poulie).
- **Savoir-faire** : EDL + résolution ; horaires ; grandeurs cinématiques
  et dynamiques d'un système couplé.

### 4.14–4.15 Systèmes oscillants + énergétique → P14, P15
- **Savoirs** : oscillations libres, amortissements (solide/fluide), régimes ;
  force de rappel du ressort ; $T_0$ (ressort, torsion, pesant, simple) ;
  couple de torsion ; pendule synchrone ; résonance mécanique
  (excitateur/résonateur, amortissement) ; travaux et énergies
  ($E_{pe}$, $E_{pt}$, $E_m$, torsion, pesanteur, cinétique).
- **Savoir-faire** : EDL + solution (ressort horizontal/incliné/vertical,
  torsion, pesant petites oscillations) ; $x(t)$, $v(t)$, $\theta(t)$ et
  conditions initiales ; diagrammes d'énergie (conservation ou non) ;
  systèmes oscillants couplés translation + rotation.

### 4.16 Atome et mécanique de Newton → P16
- **Savoirs** : gravitation vs électrostatique ; énergie atomique quantifiée ;
  limites de Newton ; $\Delta E = h\nu$ ; spectres de raies ; Planck.
- **Savoir-faire** : exploiter $\Delta E = h\nu$ ; expliquer un spectre.

## 5. CHIMIE — savoirs et savoir-faire exigibles

### 5.1 Transformations lentes et rapides → P17
- **Savoirs** : couples Ox/Red, demi-équations ($\rightleftharpoons$) ;
  transformations lentes vs rapides ; facteurs cinétiques ($T$, concentrations).
- **Savoir-faire** : écrire une oxydoréduction ; dégager l'influence des
  facteurs cinétiques sur données.

### 5.2 Suivi temporel — vitesse → P18
- **Savoirs** : méthodes de suivi (dosage, $pH$, $\sigma$/$G$, $p$, $V$) ;
  équivalence d'un titrage ; tableau d'avancement ;
  $v = \frac{1}{V}\frac{dx}{dt}$ ; évolution de $v$ ; $t_{1/2}$ ;
  chocs efficaces (microscopique).
- **Savoir-faire** : justifier un protocole et l'exploiter ; courbes
  $n$, $C$, $x$, $\sigma$, $p$ ; $v$ graphique (tangente) ; $t_{1/2}$
  graphique ; choisir la méthode selon $t_{1/2}$.

### 5.3 Non-totales : deux sens + équilibre → P19, P20 (+ P21, P22)
- **Savoirs** : Bronsted ; $pH$ ; $x_f < x_{max}$, $\tau = x_f/x_{max}$ ;
  équilibre dynamique (microscopique) ; $Q_r$ (expression, homogène/hétérogène) ;
  $Q_{r,éq} = K$ (indépendant des concentrations) ; $\tau_f(K$, état initial).
- **Savoir-faire** : écrire une réaction AB + identifier les couples ;
  calculer $x_f$, $\tau$ ; utiliser $G = \sum \lambda_i [X_i]$ ;
  exprimer et utiliser $Q_r$ et $K$.

### 5.4 Acido-basiques en solution aqueuse → P21 (+ P22)
- **Savoirs** : autoprotolyse, $K_e$, $pK_e$ ; nature acide/basique/neutre ;
  $K_A$, $pK_A$ ; $K$ d'une réaction AB via les $K_A$ ; prédominance
  ($pH$ vs $pK_A$) ; diagrammes de prédominance/distribution ;
  équation de dosage (flèche unique) ; montage et courbe de dosage ;
  équivalence ; choix de l'indicateur (zone de virage).
- **Savoir-faire** : $pH$ depuis $[H_3O^+]$/$[HO^-]$ ; $K_A$, espèce
  prédominante ; exploiter la courbe ; $V_{éq}$ ; justifier l'indicateur.

### 5.5 Évolution spontanée → P23
- **Savoirs** : critère $Q_r \to K$ au cours du temps.
- **Savoir-faire** : calculer $Q_r$ ; prévoir le sens spontané (AB et Ox/Red).

### 5.6 Piles → P24
- **Savoirs** : transfert spontané d'électrons ($M^{n+}/M$) ; constitution
  (courant, f.e.m., porteurs, pont salin, électrodes) ; pile hors équilibre ;
  pile usée ($Q_r = K$, $Q_{max}$).
- **Savoir-faire** : schématiser ; sens des porteurs (critère) ; interpréter
  (courant, f.e.m., polarité...) ; demi-équations ($\rightleftharpoons$) +
  bilan ($\to$) ; $Q = I \cdot t = n(e^-) \cdot F$ → $x$, $\Delta m$...

### 5.7 Électrolyse (transformations forcées) → P25
- **Savoirs** : transformation forcée (courant imposé inverse) ;
  anode = oxydation, cathode = réduction ; principe et applications.
- **Savoir-faire** : schématiser ; identifier anode/cathode (sens imposé) ;
  équations ($\rightleftharpoons$) + bilan ($\to$) ; $Q = I \cdot t$ →
  $x$, $\Delta m$, $V_{gaz}$...

### 5.8 Estérification / hydrolyse → P26
- **Savoirs** : groupes $-OH$, $-CO_2H$, $-CO_2R$, anhydride ;
  équations ; retrouver acide + alcool depuis l'ester ; nommer (≤ C5) ;
  lentes et limitées ; catalyseur ($v \uparrow$, équilibre inchangé) ;
  excès / élimination → déplacement ; composition à $t$ donné.
- **Savoir-faire** : écrire et exploiter les équations ; rendement
  $r = x_f/x_{max}$.

### 5.9 Contrôle : réactif, catalyse → P27
- **Savoirs** : anhydride + alcool (rapide, totale) ; hydrolyse basique ;
  saponification (savon, hydrophile/hydrophobe, structure-propriétés) ;
  matériel (reflux, distillation, cristallisation, filtration) + sécurité ;
  rôles accélérateur et sélectif du catalyseur.
- **Savoir-faire** : proposer et justifier un protocole ; rendement.

## 6. TP officiels exigibles (annexe 2 — résumé)

- **Ondes** : célérité (corde, eau, son) ; diffraction (son/ultrasons, lumière,
  $\theta = \lambda/a$) ; dispersion ($n$).
- **Électricité** : charge à courant constant ($C$) ; RC et RL (influence
  $R$/$C$/$L$, $\tau$) ; RLC libre (régimes) ; modulation/démodulation AM
  (récepteur radio simple).
- **Mécanique** : 2e loi de Newton ; chute avec frottement ; projectile ;
  RFD rotation ; ressort ($T_0$, amortissement) ; torsion ($J_\Delta$, $C$) ;
  pesant (isochronisme) ; résonance.
- **Chimie** : facteurs cinétiques ; suivi conductimétrique ($t_{1/2}$) ;
  $x_f$ AB ($pH$) ; $K$ par conductimétrie ; dosage $pH$-métrique (vie courante) ;
  piles ($M^{n+}/M$, sens spontané) ; électrolyse ($F$) ; estérification
  (rendement) ; savon ; dosage direct de l'aspirine.
