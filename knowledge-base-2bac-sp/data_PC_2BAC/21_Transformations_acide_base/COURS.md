# Chapitre 21 — Transformations acide-base

> 📋 **Exigible au bac (SI !)** : Brönsted : acide DONNE $H^+$, base PREND $H^+$ (couple $AH/A^-$ : $AH + H_2O \rightleftharpoons A^- + H_3O^+$) ; eau AMPHOTÈRE ; autoprotolyse $2H_2O \rightleftharpoons H_3O^+ + OH^-$, $\boxed{K_e = 10^{-14}}$ (25 °C) → $\boxed{pH + pOH = 14}$ ; FORT = TOTAL ($\tau = 1$ : HCl, NaOH) / faible = LIMITÉ ($\tau < 1$) ; $\boxed{K_a = [H_3O^+][A^-]/[AH]}$ (eau exclue !), $\boxed{pK_a = -\log K_a}$ ; pH : fort $- \log C$ / base forte $14 + \log C$ / faible $\sqrt{K_aC}$ ($C/K_a > 100$ !) / $\boxed{pH = pK_a + \log([B]/[A])}$ (Henderson !).

## 1. Accroche — le volcan et le sang 🌋🩸

Vinaigre (acide) + bicarbonate (base) = explosion de mousse : $H^+$ donné, $H^+$ pris, $CO_2$ libéré. Et ton sang : $pH = 7{,}40 \pm 0{,}05$ — écart de 0,3 = coma ! Régulé par le couple $CO_2/HCO_3^-$ (un tampon Henderson vivant). Tout le chapitre : *donner/prendre des $H^+$ (Brönsted), calculer des pH (4 formules), manier Henderson.* Les DOSAGES : P22.

> بالدارجة : الخل (حمض) + البيكاربونات (قاعدة) = انفجار الرغوة : $H^+$ تعطى، $H^+$ تخادى، $CO_2$ تحرر. والدم ديالك : $pH = 7{,}40 \pm 0{,}05$ — فرق 0,3 = غيبوبة ! منظم بالثنائية $CO_2/HCO_3^-$ (محلول منظم هندرسوني حي). كاع الفصل : *عطي/خود $H^+$ (برونستد)، حسب pH (4 صيغ)، تحكم في هندرسون.* المعايرات : P22.

## 2. Résumé du cours (exigible au bac)

**Brönsted.** Acide = DONNEUR de $H^+$ ; base = ACCEPTEUR de $H^+$. Couple $AH/A^-$ : $AH + H_2O \rightleftharpoons A^- + H_3O^+$ (demi-équation dans les 2 sens !). L'eau est AMPHOTÈRE : acide dans $H_2O/OH^-$, base dans $H_3O^+/H_2O$. Autoprotolyse : $2H_2O \rightleftharpoons H_3O^+ + OH^-$, $K_e = 10^{-14}$ (25 °C) → $\boxed{pH + pOH = 14}$ ($pOH = -\log[OH^-]$).

**Fort / faible.** FORT = TOTAL ($\tau = 1$ : HCl, $H_2SO_4$ 1er $H^+$, NaOH, $KOH$ — 4 à connaître !) ; faible = LIMITÉ ($\tau < 1$ : $CH_3COOH$, $NH_3$, amines…). ⚠️ « Faible » = peu DISSOCIÉ ($\tau$ petit) — PAS « dilué » (peu nombreux) ! Un acide faible CONCENTRÉ reste faible.

**$K_a$, $pK_a$ : la carte d'identité.** $\boxed{K_a = \frac{[H_3O^+][A^-]}{[AH]}}$, $\boxed{pK_a = -\log K_a}$ (M05 !). Eau EXCLUE (solvant — P20 !). $K_a$ = constante d'équilibre COMME UNE AUTRE ($Q_r$ vs $K$ — P19/P20 !). Ex. : acide acétique $K_a = 1{,}8\times10^{-5}$, $pK_a = 4{,}75$. Base faible : $K_b = K_e/K_a$ ($NH_3$ : $K_b = 1{,}8\times10^{-5}$).

**pH : 4 formules, 4 cases (ne pas mélanger !).** Acide FORT : $\boxed{pH = -\log C}$ (HCl $0{,}10$ M : $pH = 1{,}0$) ; base FORTE : $\boxed{pH = 14 + \log C}$ (NaOH $0{,}10$ M : $13{,}0$) ; acide faible : $\boxed{[H_3O^+] \approx \sqrt{K_aC}}$ SI $C/K_a > 100$ (acétique $0{,}10$ M : $pH = 2{,}87$ ✓) ; base faible : $[OH^-] \approx \sqrt{K_bC}$ ; **Henderson** (mélange $AH + A^-$) : $\boxed{pH = pK_a + \log([B]/[A])}$ ($[B] = [A]$ → $pH = pK_a$ !).

**$\tau$ et $K_a$ via $pH$.** $x_f = [H_3O^+]V$ → $\tau = 10^{-pH}/C$ ; puis $K_a = Q_{r,éq} = C\tau^2/(1-\tau)$ (VRAIE 2021N : $\tau = 1{,}32$ % → $K_a = 1{,}77\times10^{-5}$ → $CH_3COOH$ au tableau !).

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**برونستد :** الحمض = **معطي** $H^+$ ؛ القاعدة = **آخذة** $H^+$. الثنائية $AH/A^-$ : $AH + H_2O \rightleftharpoons A^- + H_3O^+$. الماء **مذبذب** : حمض في $H_2O/OH^-$، قاعدة في $H_3O^+/H_2O$. التفكك الذاتي : $K_e = 10^{-14}$ ← $\boxed{pH + pOH = 14}$.

**القوي / الضعيف :** القوي = **تام** ($\tau = 1$ : $HCl$، $NaOH$ — 4 تحفظهم !) ؛ الضعيف = **محدود** ($\tau < 1$). ⚠️ «الضعيف» = قليل **التفكك** — ماشي «مخفف» (قليل العدد) ! حمض ضعيف **مركز** كيبقى ضعيف.

**$K_a$/$pK_a$ : بطاقة الهوية.** $\boxed{K_a = [H_3O^+][A^-]/[AH]}$، $\boxed{pK_a = -\log K_a}$. الماء **مستبعد** (مذيب — P20 !). $K_a$ = ثابت توازن **بحال أي واحد** (P19/P20 !). الأسيتيك : $K_a = 1{,}8\times10^{-5}$، $pK_a = 4{,}75$.

**pH : 4 صيغ، 4 خانات (ما تخلطهومش !) :** حمض قوي : $\boxed{pH = -\log C}$ ؛ قاعدة قوية : $\boxed{pH = 14 + \log C}$ ؛ حمض ضعيف : $\boxed{[H_3O^+] \approx \sqrt{K_aC}}$ (إلا $C/K_a > 100$ !) ؛ **هندرسون** : $\boxed{pH = pK_a + \log([B]/[A])}$ ($[B] = [A]$ ← $pH = pK_a$ !).

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **$pH = -\log C$ partout** : SEULEMENT acide FORT (acétique $0{,}10$ M : $pH = 2{,}87$, pas $1{,}0$ !). $-\log C$ suppose $\tau = 1$ — un faible : $[H_3O^+] < C$.
- 🪤 **Eau dans $K_a$** : $K_a = [H_3O^+][A^-]/[AH]$ — PAS de $[H_2O]$ (solvant exclu, P20 !). $[H_2O] = 55{,}5$ M absorbée dans $K_a$.
- 🪤 **$\sqrt{K_aC}$ sans vérifier $C/K_a > 100$** : l'approximation ($x_f \ll C$) exige $C/K_a > 100$ (acétique $0{,}10$ M : $5556$ ✓). Sinon : 2nd degré complet !
- 🪤 **Henderson pour un acide SEUL** : Henderson = MÉLANGE ($AH$ + $A^-$ présents !). Acide seul : $\sqrt{K_aC}$ (pas de $[B]$ initial !).
- Mots-clés : *fort ou faible ? (d'abord !), $-\log C$ = forts, $\sqrt{}$ ($C/K_a > 100$ !), Henderson (mélange !), $K_a$ = $K$ (P19/P20 !).*

## 9. Le « pourquoi » profond — pourquoi 4 formules 🔬

**Pourquoi $\sqrt{K_aC}$ ?** $K_a = x_f^2/(C - x_f)$ (tableau : $[H_3O^+] = [A^-] = x_f/V$). Si $x_f \ll C$ ($C/K_a > 100$ !) : $C - x_f \approx C$ → $x_f^2 \approx K_aC$ → $[H_3O^+] \approx \sqrt{K_aC}$. **La racine = l'approximation « presque rien ne se dissocie » — d'où la condition $C/K_a > 100$ (vérifier !).**

**Pourquoi Henderson ?** $K_a = [H_3O^+][B]/[A]$ → $[H_3O^+] = K_a[A]/[B]$ → $-\log$ : $pH = pK_a + \log([B]/[A])$ (M05 : $-\log$ d'un produit !). 2 lignes, zéro magie. **Henderson = $K_a$ réécrit en $pH$ — le couteau suisse (tampons, demi-éq P22, rapports !).**

**Pourquoi $pH + pOH = 14$ ?** $K_e = [H_3O^+][OH^-] = 10^{-14}$ → $-\log$ : $pH + pOH = 14$ (M05 !). À 25 °C UNIQUEMENT ($K_e$ dépend de $T$ !). **Connaître $[H_3O^+]$ = connaître $[OH^-]$ (et inverser) — les deux faces d'une pièce.**

**Liens croisés :** P19/P20 — $K_a$ = un $K$ ($Q_r$ vs $K$, $\tau$ !) ; M05 — $\log$ (le langage du chapitre !) ; P22 — dosages (Henderson à la demi-éq !) ; P18 — suivi pH-métrique ; S01 — $CO_2$ respiratoire (tampon sanguin : $pH = 6{,}1 + \log([HCO_3^-]/[CO_2])$ !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « $pH = -\log C$ (acide faible). »** Non : $-\log C$ suppose $\tau = 1$ (TOUT dissocié). Faible : $\tau < 1$ → $[H_3O^+] < C$ → $pH > -\log C$ (acétique $0{,}10$ M : $2{,}87$ vs $1{,}0$ !). **Le déclic :** *$-\log C$ = « tout le monde donne son $H^+$ » — un faible est TIMIDE (peu donnent) : $[H_3O^+] = \sqrt{K_aC}$, pas $C$.*

**2. « Faible = dilué. »** Non : faible = peu DISSOCIÉ ($\tau$ petit, propriété $K_a$ !) ; dilué = peu NOMBREUX ($C$ petit). Acétique $1$ M : CONCENTRÉ mais FAIBLE ($\tau = 0{,}4$ % !). **Le déclic :** *faible = timide (peu donnent) ; dilué = clairsemé (peu nombreux) — 2 axes indépendants (timide-nombreux existe !).*

**3. « Henderson pour $AH$ seul. »** Non : Henderson exige $AH$ ET $A^-$ PRÉSENTS (mélange/tampon !). $AH$ seul : $[B]_{initial} = 0$ → $\sqrt{K_aC}$. **Le déclic :** *Henderson = balance à 2 plateaux ($[B]/[A]$) — un seul plateau ($AH$ seul) : pas de balance, $\sqrt{K_aC}$ !*

## 11. Signaux adaptatifs — prérequis + plan B 🧭

**Prérequis :** P19/P20 ($K$, $\tau$, $Q_r$ — $K_a$ EST un $K$ !), M05 ($\log$ : $-\log$, $\log(ab)$), P17 (tableau). **Test 30 s :** $pH = pK_a - 1$ — rapport $[B]/[A]$ ? ($\log = -1$ → $[B]/[A] = 0{,}1$ ✓) ; HCl $0{,}01$ M : $pH$ ? ($2{,}0$ ✓).

**Plan B — si Henderson bloque :** $pH = pK_a$ quand $[B] = [A]$ (demi-éq, P22 !) ; si $[B] > [A]$, $pH > pK_a$ (plus basique) ; si $[B] < [A]$, $pH < pK_a$. Le SENS suffit pour la moitié des QCM — le calcul exact ($+\log$) pour le reste.

**Fiche réflexes :** *fort ou faible ? · $-\log C$ = forts · $\sqrt{K_aC}$ ($C/K_a > 100$ !) · Henderson = mélange · $\tau = 10^{-pH}/C$ · $K_a$ = $K$ !*
