# How to understand this chapter the easy way — 21 Acide-base

> بصوت الأستاذ فالقسم : قوي ولا ضعيف ؟ هو السؤال اللي كيحل كل تمرين — 5 خطوات.

## الخطوة 1 — قوي ولا ضعيف ؟ (السؤال اللي كيفتح كل تمرين !)

الأقوياء : 4 تحفظهم ($HCl$، $H_2SO_4$ للـ $H^+$ اللول، $NaOH$، $KOH$) ← $pH$ مباشر ($-\log C$ / $14 + \log C$). **كلشي آخر = ضعيف** ($K_a$، $\sqrt{}$، هندرسون).

**هاد السؤال اللول قبل أي حساب !** 90 % ديال أغلاط pH : صيغة القوي على حمض ضعيف (الأسيتيك $0{,}10$ : $2{,}87$ ماشي $1{,}0$ !). قوي/ضعيف = البوابة — دوز منها صح.

## الخطوة 2 — برونستد : عطي/خود $H^+$ (والماء مذبذب !)

الحمض كيعطي $H^+$، القاعدة كتاخدو. الثنائية $AH/A^-$ : $AH + H_2O \rightleftharpoons A^- + H_3O^+$ (كتبها في الاتجاهين !).

الماء **مذبذب** : كيعطي (في $H_2O/OH^-$) وكياخذ (في $H_3O^+/H_2O$). والتفكك الذاتي $K_e = 10^{-14}$ ← $pH + pOH = 14$ : عرفتي $[H_3O^+]$ ← عرفتي $[OH^-]$ (والعكس !) — وجهين لعملة وحدة.

## الخطوة 3 — الـ 4 صيغ : خانة لكل حالة (ما تخلطهومش !)

حمض قوي : $-\log C$. قاعدة قوية : $14 + \log C$. حمض ضعيف : $\sqrt{K_aC}$ (**تحقق** $C/K_a > 100$ !). مزيج ($AH + A^-$) : هندرسون.

**الجذر منين جا ؟** $K_a = x_f^2/(C - x_f)$ : إلا كان $x_f$ صغير بزاف قدام $C$ ($C/K_a > 100$ !) ← $C - x_f \approx C$ ← $x_f \approx \sqrt{K_aC}$. الجذر = تقريب «شبه والو كيتفكك» — لهذا الشرط إجباري (تحقق منو في كل تمرين !).

## الخطوة 4 — هندرسون : الميزان ($[B]/[A]$ !)

$pH = pK_a + \log([B]/[A])$ : المزيج ($AH$ **و** $A^-$ حاضرين !). $[B] = [A]$ ← $pH = pK_a$ (الميزان متوازن !). $[B] > [A]$ ← $pH > pK_a$ (أكثر قاعدية).

**الاتجاه كافي لنص QCM !** والحساب الدقيق ($+\log$) للباقي. والاشتقاق في سطرين : $K_a = [H_3O^+][B]/[A]$ ← عزل $[H_3O^+]$ ← خد $-\log$ ← خرجات ! (M05 : $-\log$ ديال الجداء.)

## الخطوة 5 — $\tau$ و $K_a$ من pH (طريقة VRAIE 2021N !)

قستي $pH_0$ ؟ ← $x_f = [H_3O^+]V = 10^{-pH}V$ ← $\tau = 10^{-pH}/C$ ← $K_a = C\tau^2/(1-\tau)$ (صيغة $Q_{r,éq}$ !) ← $pK_a$ ← **قلب في الجدول** : شكون هاد الحمض ؟ (VRAIE 2021N : $pK_a = 4{,}75$ ← الأسيتيك !).

**السلسلة :** $pH_0$ ← $\tau$ ← $K_a$ ← الهوية. 4 حلقات — كل وحدة كتعطي اللي وراها. هاد هي «التحقيق الكيميائي» ديال الوطني !

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. قوي (4 !) ولا ضعيف (الباقي) ؟ — البوابة !
2. برونستد : عطي/خود + $K_e = 10^{-14}$.
3. 4 صيغ : $-\log C$ / $14+\log C$ / $\sqrt{K_aC}$ ($C/K_a > 100$ !) / هندرسون.
4. هندرسون = ميزان $[B]/[A]$ (متوازن ← $pK_a$ !).
5. $pH_0$ ← $\tau$ ← $K_a$ ← الهوية (التحقيق !).
