# FAQ — Chapitre 21 (Acide-base)

**1. $pH = -\log C$ partout ?**
NON — acide FORT seulement ($\tau = 1$ : tout dissocié → $[H_3O^+] = C$). Faible : $[H_3O^+] = \sqrt{K_aC} < C$ (acétique $0{,}10$ M : $2{,}87$, pas $1{,}0$ !). La question « fort ou faible ? » ouvre chaque exo.
/ لا — الحمض القوي فقط ($\tau = 1$). الضعيف : $\sqrt{K_aC}$ (الأسيتيك $0{,}10$ : $2{,}87$ ماشي $1{,}0$ !). سؤال «قوي ولا ضعيف ؟» كيفتح كل تمرين.

**2. Faible = dilué ?**
NON ! Faible = peu DISSOCIÉ ($\tau$ petit — propriété $K_a$) ; dilué = peu NOMBREUX ($C$ petit). Acétique $1$ M : CONCENTRÉ mais FAIBLE ($\tau = 0{,}4$ % !). 2 axes indépendants : timide-nombreux existe !
/ لا ! الضعيف = قليل التفكك ($\tau$ صغير) ؛ المخفف = قليل العدد ($C$ صغير). الأسيتيك 1 M : مركز ولكن ضعيف ! جوج محاور مستقلين.

**3. Eau dans $K_a$ ?**
NON : $K_a = [H_3O^+][A^-]/[AH]$ — PAS de $[H_2O]$ (solvant exclu, P20 !). $[H_2O] = 55{,}5$ M constante, absorbée dans $K_a$. (Comme tout solvant : le décor ne s'écrit pas !)
/ لا : الماء مستبعد (مذيب، P20 !). $[H_2O] = 55{,}5$ M ثابتة مدمجة في $K_a$. (بحال أي مذيب : الديكور ما كيتكتبش !)

**4. $\sqrt{K_aC}$ : conditions ?**
$C/K_a > 100$ (approximation $x_f \ll C$ : « presque rien ne se dissocie ») ! Vérifier À CHAQUE FOIS (acétique $0{,}10$ M : $5556$ ✓). Sinon : 2nd degré complet ($K_a = x_f^2/(C-x_f)$ sans approximation).
/ $C/K_a > 100$ (تقريب $x_f \ll C$) ! تحقق في كل مرة. وإلا : الدرجة الثانية كاملة بلا تقريب.

**5. Henderson : quel sens ($pH$ vs $pK_a$) ?**
$[B] = [A]$ → $pH = pK_a$ (balance !). $[B] > [A]$ → $pH > pK_a$ (plus basique). $[B] < [A]$ → $pH < pK_a$. Le SENS suffit pour la moitié des QCM ; le calcul ($+\log$) pour le reste.
/ $[B] = [A]$ ← $pH = pK_a$ (الميزان !). $[B] > [A]$ ← $pH > pK_a$. الاتجاه كافي لنص QCM ؛ الحساب للباقي.

**6. $K_b$ ?**
Constante de basicité : $B + H_2O \rightleftharpoons BH^+ + OH^-$ ($K_b = [BH^+][OH^-]/[B]$). Lien : $K_a \times K_b = K_e$ ($NH_3$ : $K_b = 1{,}8\times10^{-5}$ → $[OH^-] = \sqrt{K_bC}$). Mêmes maths que $K_a$, côté $OH^-$ !
/ ثابتة القاعدية. العلاقة : $K_a \times K_b = K_e$. نفس رياضيات $K_a$، في جهة $OH^-$ !
