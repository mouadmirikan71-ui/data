# Exercices types — Électrolyse (P25)

## Méthode — électrolyse en 5 gestes 🧭

1. Générateur ? → anode(+) = ox, cathode(−) = red.
2. Demi-éq des 2 électrodes → produits.
3. $Q = It$ → $n(e^-) = Q/F$.
4. $n = n(e^-)/\nu$ (PRIX en $e^-$ de chacun !).
5. $m = nM$, $V = nV_m$ ; $\rho$ = réel/théo.

## R1 — ENTRAÎNEMENT (eau : $H_2$ double de $O_2$)

🏷️ matière=PC · année=— · session=— · chapitre=P25 · type=ENTRAÎNEMENT · fidélité=n.a. · type_question=électrolyse-eau-gaz · niveau=★ · compétence=demi-éq+stœchiométrie-e⁻ · barème=—

**Énoncé.** Électrolyse de l'eau, $I = 2,0$ A, $t = 30$ min ($V_m = 24$ L/mol). a) Demi-éq + pôles ? b) $V(H_2)$, $V(O_2)$ ?

**Corrigé-type.** a) Cathode(−) : $2H_2O + 2e^- \to H_2$ ; anode(+) : $2H_2O \to O_2 + 4e^-$. b) $Q = 2,0\times1800 = 3600$ C → $n(e^-) = 0,0373$ → $n(H_2) = 0,0187$ → $\boxed{0,45\text{ L}}$ ; $n(O_2) = 0,00933$ → $\boxed{0,22\text{ L}}$ (moitié ✓).
🪤 *Piège testé : $V(O_2) = 0,45$ L (« même $n(e^-)$ ») — MÊMES $e^-$, PRIX différents (2 vs 4 !) : $n = n(e^-)/\nu$.*
🗣️ الخلاصة : الإلكترونات **عملة** — $H_2$ بثمن 2 و $O_2$ بثمن 4 : نفس المبلغ كيعطي ضعف الحجم ديال $H_2$.

## R2 — ENTRAÎNEMENT (affinage Cu, 2 méthodes !)

🏷️ matière=PC · année=— · session=— · chapitre=P25 · type=ENTRAÎNEMENT · fidélité=n.a. · type_question=affinage-masse-rendement · niveau=★★ · compétence=chaîne-Q + formule-directe · barème=—

**Énoncé.** Affinage Cu : $I = 10$ A, $t = 1$ h. a) $m(Cu)_{théo}$ ? b) $m_{réelle} = 10,7$ g : $\rho$ ?

**Corrigé-type.** a) **Méthode 1 (chaîne)** : $Q = 36000$ C → $n(e^-) = 0,373$ → $n(Cu) = 0,187$ → $m = 0,187\times63,5 = \boxed{11,8\text{ g}}$. **Méthode 2 (formule directe)** : $m = ItM/\nu F = 10\times3600\times63,5/(2\times96500) = \boxed{11,8\text{ g}}$ ✓. b) $\rho = 10,7/11,8 = \boxed{90\%}$ ($H_2$ parasite sur cathode !).
🪤 *Piège testé : $t = 1$ (heure !) → $Q = 10$ C — $t$ en SECONDES : $1$ h $= 3600$ s !*
🗣️ الخلاصة : السلسلة $Q \to n(e^-) \to n \to m$ **دائما خدامة** — والصيغة المباشرة $m = ItM/\nu F$ للسرعة.

## R3 — ENTRAÎNEMENT (saumure : $H_2$ + $Cl_2$, pas Na !)

🏷️ matière=PC · année=— · session=— · chapitre=P25 · type=ENTRAÎNEMENT · fidélité=n.a. · type_question=concurrence-eau-chlore · niveau=★★★ · compétence=concurrence+potentiels · barème=—

**Énoncé.** Électrolyse $NaCl$ concentré, $I = 5,0$ A, $t = 1$ h. a) Produits ? b) $V(Cl_2)$ ? c) Pourquoi pas $Na(s)$ ?

**Corrigé-type.** a) Cathode(−) : $H_2$ (l'EAU se réduit : $2H_2O + 2e^- \to H_2 + 2OH^-$) ; anode(+) : $2Cl^- \to Cl_2$. b) $Q = 18000$ → $n(e^-) = 0,187$ → $n(Cl_2) = 0,0933$ → $V = \boxed{2,24\text{ L}}$. c) $E°(Na^+/Na) = -2,71 \ll E°(H_2O)$ : l'eau gagne — $Na^+$ reste spectateur !
🪤 *Piège testé : « cathode : $Na^+$ → $Na$ » — en AQUEUX, l'eau concurrence TOUJOURS : comparer les potentiels !*
🗣️ الخلاصة : فالمحلول المائي، **الماء منافس دائم** — اللي جهدو أعلى هو اللي كيتفاعل، والصوديوم كيتفرج.

## R4 — ENTRAÎNEMENT (recharger 60 Ah de batterie Pb)

🏷️ matière=PC · année=— · session=— · chapitre=P25 · type=ENTRAÎNEMENT · fidélité=n.a. · type_question=batterie-charge · niveau=★★ · compétence=bilan+Ah-C · barème=—

**Énoncé.** Batterie Pb $60$ Ah déchargée ($PbSO_4$). a) Réaction de charge ? b) $Q$ ? c) $m(PbSO_4)$ régénérée ($M = 303$ g/mol) ?

**Corrigé-type.** a) Charge = INVERSE décharge : $2PbSO_4 + 2H_2O \to Pb + PbO_2 + 2H_2SO_4$ (électrolyse !). b) $Q = 60\times3600 = \boxed{216000\text{ C}}$. c) $n(e^-) = 2,24$ → $n(PbSO_4) = 2,24$ (2 par $2e^-$ !) → $m = 2,24\times303 = \boxed{679\text{ g}}$.
🪤 *Piège testé : $n(PbSO_4) = n(e^-)/2$ — ici 2 $PbSO_4$ (1 par électrode) pour 2 $e^-$ circulants : LIRE le bilan, pas diviser aveuglément !*
🗣️ الخلاصة : الشحن = **عكس التفريغ** — وهاد المعادلة فيها 2 $PbSO_4$ لكل 2 إلكترونات : قرا الحصيلة قبل ما تقسم.

## R5 — ENTRAÎNEMENT (dorure : retrouver $\Delta t$, esprit 2022R)

🏷️ matière=PC · année=— · session=— · chapitre=P25 · type=ENTRAÎNEMENT · fidélité=n.a. · type_question=dorure-durée · niveau=★★★ · compétence=formule-durée · barème=—

**Énoncé.** Dorure : dépôt de $m = 1,20$ g d'or ($Au^{3+} + 3e^- \to Au$, $M = 197$ g/mol) sous $I = 0,80$ A. Durée $\Delta t$ ? Schéma : où brancher l'objet ?

**Corrigé-type.** $\Delta t = m\nu F/(IM) = 1,20\times3\times96500/(0,80\times197) = 347400/157,6 = \boxed{2204\text{ s} \approx 36{,}7\text{ min}}$. L'objet = CATHODE (dépôt = réduction !) → branché au pôle **−** ; anode graphite au +.
🪤 *Piège testé : objet à l'anode (« + attire ») — le dépôt est une RÉDUCTION → cathode → pôle −. « Le dépôt va au moins » !*
🗣️ الخلاصة : الترسيب = **اختزال** = كاثود = القطب السالب — «الذهب كيمشي للسالب» !

## VRAIE — 2022N Ex1-P1 (chromage d'une plaque d'acier)

🏷️ matière=PC · année=2022 · session=N · chapitre=P25 · type=VRAIE · fidélité=reconstitué-corrigé · type_question=chromage-cathode-masse · niveau=★★★ · compétence=identifier-cathode+stœchiométrie-e⁻ · barème=partie de l'Ex1/7 (reste = P21 propanoïque)

> Reconstituée d'après la correction détaillée (Pr Moujahid, scribd) — questions et équations fidèles ; $m = 2{,}59$ g (⚠️ CORRIGÉ le 2026-09-15 : 2,58 erroné — $2\times7200\times52/(3\times96500) = 2{,}5865$ → 2,59 à 3 c.s.) ; énoncé exact à recouper sur le PDF officiel.
**1. Cathode ?** On observe un dépôt de chrome sur la plaque d'acier → réduction $Cr^{3+} + 3e^- \to Cr$ → **la plaque est la CATHODE** (branchée au −).
**2. Équations.** Anode (graphite) : $\boxed{2H_2O \to O_2 + 4H^+ + 4e^-}$ (oxydation). Cathode (acier) : $\boxed{Cr^{3+} + 3e^- \to Cr}$ (réduction).
**3. Masse déposée.** $Q = n(e^-)F = It$ → tableau d'avancement : $n(e^-) = 3x$ → $x = It/3F$ → $m = xM(Cr) = ItM/3F$. AN ($I = 2$ A, $\Delta t = 2$ h, $M = 52$) : $m = 2\times7200\times52/(3\times96500) = 748800/289500 = \boxed{2{,}59\text{ g}}$.
🪤 *vraie : cathode identifiée par l'OBSERVATION (le dépôt !), pas par le schéma ; $\nu = 3$ pour Cr (pas 2 !) ; $\Delta t$ en secondes ($2$ h $= 7200$ s).*
🗣️ الخلاصة : الوطني كيقولك «ترسيب على الصفيحة» = هي **الكاثود** — والكروم بثمن 3 إلكترونات ($m = ItM/3F$).

## VRAIE — 2022R Ex1 (électrolyse de l'or : schéma + $\Delta t \approx 15{,}2$ min)

🏷️ matière=PC · année=2022 · session=R · chapitre=P25 · type=VRAIE · fidélité=reconstitué-corrigé · type_question=électrolyse-or-schéma-durée · niveau=★★★ · compétence=schéma+relation-Q · barème=partie de l'Ex1/7 (reste = P21 méthylamine)

> Reconstituée d'après les éléments de réponse officiels (PDF netschool1.net : anode/cathode, schéma, équations, $\Delta t \approx 15{,}2$ min) — données d'énoncé ($I$, $m$) à recouper sur le sujet officiel.
**1. Anode/cathode + schéma.** Depuis le sens du courant imposé : anode = électrode branchée au + (graphite, oxydation), cathode = objet doré (réduction $Au^{3+} + 3e^- \to Au$). Schéma exigible : cuve, électrodes nommées, générateur, sens du courant (extérieur : + → −) et des $e^-$.
**2. Équations.** Demi-éq aux électrodes + équation bilan (flèche simple).
**3. Durée.** Relation $Q = n(e^-)F = I\Delta t$ → $\Delta t = m\nu F/(IM)$ → résultat officiel $\boxed{\Delta t \approx 15{,}2\text{ min}}$.
🪤 *vraie : le SCHÉMA noté (électrodes + sens du courant !) ; bilan flèche simple vs demi-éq ; $\Delta t$ en minutes à la fin (reconvertir depuis les secondes !).*
🗣️ الخلاصة : الاستدراكية 2022 نقطات **الرسم** — الأقطاب مسماة واتجاه التيار واضح، والمدة كتحسب بالعلاقة $Q = It$ وكترجع للدقائق.
