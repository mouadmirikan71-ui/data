# Chapitre 26 — Estérification et hydrolyse

> 📋 **Exigible au bac (SI !)** : socle organique (1BAC) : alcanes $C_nH_{2n+2}$ (-ane), alcènes (-ène, $C=C$ réactif !), fonctions (-ol, -al BOUT, -one MILIEU, -oïque, -oate, -amine), classes d'alcools (C autour du C-OH : 1/2/3 !) ; ESTÉRIFICATION : $acide + alcool \rightleftharpoons ester + eau$ — LENTE, LIMITÉE ($\boxed{K \approx 4}$ : $\tau = 67$ % à 1-1 !), quasi-athermique, catalysée par $H^+$ ; HYDROLYSE (inverse !) : $\boxed{K' = 1/K \approx 0{,}25}$ ($\tau = 33$ % à 1-1 !).

## 1. Accroche — le parfum et le savon 🌸🧼

Parfum (ESTER : éthanoate d'éthyle !), vinaigre (ACIDE), digestif (ALCOOL) : l'estérification fabrique les parfums — LENTEMENT (des heures !) et PARTIELLEMENT (67 % !). Et ton corps fait l'inverse : HYDROLYSE des graisses (triglycérides = tri-esters !) pour les digérer. Tout le chapitre : *le socle organique (nommer !), l'estérification ($K \approx 4$), l'hydrolyse ($K' = 1/4$).* Forcer le rendement (90 %+, totale !) : P27.

> بالدارجة : العطر (إستر !)، الخل (حمض)، المشروب (كحول) : الأسترة كتصنع العطور — **بشوية** (ساعات !) و**جزئياً** (67 % !). والجسم ديالك كيدير العكس : **حلمأة** الدهون (ثلاثي الغليسيريد = ثلاثي-إستر !) باش يهضمها. كاع الفصل : *الأساس العضوي (سمّي !)، الأسترة ($K \approx 4$)، الحلمأة ($K' = 1/4$).* فرض المردود (90 %+، تام !) : P27.

## 2. Résumé du cours (exigible au bac)

**Socle organique (rappels 1BAC — INDISPENSABLES).** Alcanes $C_nH_{2n+2}$ (méth/éth/prop/but… + -ane ; ramifié : -yle + position MINIMALE !). Alcènes $C_nH_{2n}$ (-ène + position de $C=C$ = site RÉACTIF : addition !). Représentations : brute, semi-développée, topologique (zigzag : sommet = $C$ !). Fonctions : alcool -ol (+ position), ALDÉHYDE -al (CHO en BOUT !), CÉTONE -one ($CO$ au MILIEU !), acide -oïque ($COOH$), ester -oate ($COO$), amine (-$NH_2$). **Classes d'alcools** : C portant $OH$ lié à 1C (primaire), 2C (secondaire), 3C (tertiaire) — compter les CARBONES, pas les $H$ !

**Estérification.** $acide + alcool \rightleftharpoons ester + eau$ : LENTE (heures ! — P17), LIMITÉE ($\boxed{K \approx 4}$ : 1-1 → $\tau = 67$ % — P19 !), quasi-athermique ($K$ ≈ cste avec $T$), catalysée par $H^+$ ($H_2SO_4$ concentré : plus VITE — P17 !). L'exemple-roi des chapitres P19/P20 ($K = 4$ partout !).

**Hydrolyse = réaction INVERSE.** $ester + eau \rightleftharpoons acide + alcool$ : LENTE, LIMITÉE, $\boxed{K' = 1/K \approx 0{,}25}$ (1-1 → $x/(1-x) = 1/2$ → $\tau = 33$ % !). Moins avancée que l'estérification (logique : $K' < K$ !). Saponification ($HO^-$) : PAS une hydrolyse simple — TOTALE (P27 : $HO^-$ aspire l'équilibre !).

**Combustion (culture bac).** Complète : $C_nH_{2n+2} + \frac{3n+1}{2}O_2 \to nCO_2 + (n+1)H_2O$ (butane : $2C_4H_{10} + 13O_2 \to 8CO_2 + 10H_2O$ — question offerte si formule connue !).

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**الأساس العضوي (تذكير الأولى باك — إجباري) :** الألكانات $C_nH_{2n+2}$ (ميث/إيث/بروب... + التفرعات : -yle + **أصغر** رقم !). الألكينات (-ène + موقع $C=C$ = موقع **تفاعلي** !). الوظائف : كحول (-ol)، ألدهيد (-al في **الطرف** !)، كيتون (-one في **الوسط** !)، حمض (-oïque)، إستر (-oate)، أمين. **درجات الكحول** : الكربون اللي هاز $OH$ مربوط بـ 1 (أولي)، 2 (ثانوي)، 3 (ثالثي) — حسب **الكربونات**، ماشي $H$ !

**الأسترة :** $حمض + كحول \rightleftharpoons إستر + ماء$ : **بطيئة** (ساعات !)، **محدودة** ($\boxed{K \approx 4}$ : 1-1 ← $\tau = 67$ % !)، شبه-لا-حرارية، محفزة بـ $H^+$ (أسرع !). المثال الملك ديال P19/P20 !

**الحلمأة = التفاعل العكسي :** $إستر + ماء \rightleftharpoons حمض + كحول$ : بطيئة، محدودة، $\boxed{K' = 1/K \approx 0{,}25}$ (1-1 ← $\tau = 33$ % !). أقل تقدماً من الأسترة (منطقي : $K' < K$ !). التصبن ($HO^-$) : **ماشي** حلمأة بسيطة — تام (P27 !).

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **Classe : compter les $H$** : NON — compter les CARBONES liés au C-OH ! (3 voisins C = tertiaire = RIEN à l'oxydation — P27 !)
- 🪤 **-al au milieu / -one au bout** : $CHO$ n'a qu'UN bras libre (BOUT obligé !) ; $CO$ en a DEUX (MILIEU !). La structure impose la place.
- 🪤 **« Estérification TOTALE »** : NON — $K \approx 4$ → $\tau = 67$ % (1-1) ! Limitée (l'inverse — hydrolyse — n'est pas négligeable !). Totale : P27 (anhydride, $HO^-$…).
- 🪤 **« 3-méthylbutane »** : positions les PLUS PETITES : numéroter depuis le bout le plus proche ($2$-méthylbutane !).
- Mots-clés : *longue chaîne + suffixe + petits n°, C autour de C-OH, -al BOUT/-one MILIEU, $K \approx 4$ (67 %), $K' = 1/4$ (33 %), $H^+$ = vitesse.*

## 9. Le « pourquoi » profond — pourquoi 67 % et pourquoi $C=C$ réagit 🔬

**Pourquoi $C=C$ réagit (addition) ?** Double liaison = $\sigma$ (solide) + $\pi$ (FRAGILE, au-dessus/dessous) : la $\pi$ se ROMPT facilement pour accrocher 2 atomes ($Br_2$ → décoloration = TEST — P27 !). L'alcane (que des $\sigma$) est inerte — d'où « paraffine » (peu d'affinité) ! **La $\pi$ = la poignée de la molécule.**

**Pourquoi estérification LIMITÉE ($K \approx 4$) ?** Direct et inverse ont des vitesses comparables (mécanismes miroirs, $E_a$ proches !) : l'équilibre s'établit AVANT épuisement ($K = 4$ : ni $\gg 1$ ni $\ll 1$ !). **$K \approx 4$ = les deux sens jouent à égalité (4-1 pour le direct) — d'où 67 %, pas 100 %.**

**Pourquoi hydrolyse à 33 % ?** $K' = 1/K$ (P23 : inverser → inverser $Q_r$ !) : $K' = 0{,}25$ : l'équilibre favorise ester + eau (les « réactifs » de l'hydrolyse !). $x/(1-x) = 1/2$ → $x = 1/3$ : **l'hydrolyse simple avance MOINS (33 %) — d'où la saponification ($HO^-$ : totale ! — P27).**

**Liens croisés :** P19/P20 — $K \approx 4$, $\tau = 67$ % (l'exemple-roi !) ; P17 — lente + catalyse $H^+$ ; P27 — forcer (excès, élimination, anhydride, $HO^-$) ; P23 — $K' = 1/K$ (même règle !) ; S01 — lipides (triglycérides = TRI-ESTERS : hydrolyse digestive !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « Classe = nombre de $H$ sur le C-OH. »** Non : CARBONES voisins (1/2/3) ! **Le déclic :** *c'est le SQUELETTE qui bloque l'oxydation (P27 : pas de H arrachable sans casser C-C) : 3 voisins C = tertiaire = RIEN. Compter les C (le décor), pas les H (les figurants).*

**2. « -al et -one : pareil ($C=O$). »** Non : $CHO$ (BOUT : 1 bras !) vs $CO$ (MILIEU : 2 bras !). **Le déclic :** *$CHO$ n'a qu'UNE main libre (il se tient au bout !) ; $CO$ en a DEUX (il se tient au milieu !). La structure impose l'adresse.*

**3. « Hydrolyse = inverse donc 67 % aussi. »** Non : 33 % ! Inverser ÉCHANGE les rôles ($K' = 1/4$ : l'équilibre favorise l'ester !). **Le déclic :** *inverser le match inverse le score ($4 \to 1/4$) : le gagnant change de camp. 67 % dans un sens = 33 % dans l'autre (pas 67-67 !).*
