# How to understand this chapter the easy way — 26 Estérification

> بصوت الأستاذ فالقسم : سمّي صح، حسب $K \approx 4$، وقلب للعكس — 5 خطوات.

## الخطوة 1 — التسمية : الأطول + اللاحقة + أصغر الأرقام

السلسلة **الأطول** (اللي فيها الوظيفة !) + لاحقة الوظيفة (-ol، -al، -one، -oïque، -oate) + **أصغر** الأرقام (رقّم من الطرف القريب !).

$CH_3-CH_2-CH(CH_3)-CH_3$ : الأطول = 4 (بيوتان) + ميثيل في 2 ← **2-ميثيلبيوتان** (ماشي 3- !). الترقيم من الطرف القريب — ديما ! والتسمية = نقطة ؛ التفاعلات/الحسابات = الباقي : ما تبلوكيش على الاسم !

## الخطوة 2 — درجة الكحول : حسب الكربونات حول C-OH !

الكربون اللي هاز $OH$ مربوط بـ : 1 كربون ← أولي ؛ 2 ← ثانوي ؛ 3 ← ثالثي.

$CH_3-CH(OH)-CH_3$ : الـ C الأوسط مربوط بـ 2 كربون ← **بروبان-2-أول، ثانوي** ← الأكسدة : بروبانون (P27 !). **الدرجة = توقع الأكسدة** : أولي ← ألدهيد ← حمض ؛ ثانوي ← كيتون ؛ ثالثي ← والو ! (التفاصيل : P27 ؛ هنا : حسب صح !)

## الخطوة 3 — الأسترة : بطيئة + محدودة ($K \approx 4$ ← 67 % !)

$حمض + كحول \rightleftharpoons إستر + ماء$ : **بطيئة** (ساعات — بلا $H^+$ !)، **محدودة** ($K \approx 4$ : المباشر والعكسي كيلعبو تقريباً بالتعادل !).

1-1 : $x^2/(1-x)^2 = 4$ ← $x/(1-x) = 2$ ← $x = 0{,}67$ ← **$\tau = 67$ %** (نفس حساب P19-R1 — المثال الملك !). الثلث ما تفاعلش : الحلمأة (العكس) خدامة — ماشي مهملة !

## الخطوة 4 — الحلمأة : العكس ($K' = 1/4$ ← 33 % !)

$إستر + ماء \rightleftharpoons حمض + كحول$ : عكس الأسترة ← $K' = 1/K = 0{,}25$ (قلب المعادلة ← قلب $Q_r$ — نفس قاعدة P23 !).

1-1 : $x/(1-x) = 1/2$ ← $x = 1/3$ ← **$\tau = 33$ %** : الحلمأة البسيطة أقل تقدماً (التوازن كيحبذ الإستر !). **قلب الماتش كيقلب النتيجة** ($4 \to 1/4$) : 67 % في اتجاه = 33 % في العكسي (ماشي 67-67 !).

## الخطوة 5 — $H^+$ : الوسيط (السرعة فقط !)

$H_2SO_4$ المركز : وسيط (طريق بـ $E_a$ هابطة — P17 !) : الأسترة كتولي أسرع **بزاف** (دقائق بدل ساعات !).

**الحصيلة ما تبدلاتش :** نفس $K \approx 4$، نفس $\tau = 67$ % (1-1) — غير الوقت تبدل (P17 : «أسرع، نفس الحصيلة، ما كيتستهلكش» !). $H^+$ = السرعة ؛ الرافعات ديال الحصيلة (الزيادة، الإزالة، تغيير المتفاعل) : P27 !

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. الأطول + اللاحقة + أصغر الأرقام (ما تبلوكيش !).
2. الدرجة : C حول C-OH (1/2/3 ← ألدهيد/كيتون/والو).
3. الأسترة : $K \approx 4$ (67 % : 1-1 !).
4. الحلمأة : $K' = 1/4$ (33 % : قلب النتيجة !).
5. $H^+$ : السرعة فقط (الحصيلة : P27 !).
