# FAQ — Chapitre 26 (Estérification et hydrolyse)

**1. Classe de l'alcool : compter quoi ?**
Les CARBONES liés au C-OH (1/2/3) — PAS les $H$ ! C'est le SQUELETTE qui bloque l'oxydation (P27 : tertiaire = RIEN). $CH_3-CH(OH)-CH_3$ : 2 C voisins → secondaire.
/ الكربونات المرتبطة بـ C-OH (1/2/3) — ماشي $H$ ! الهيكل هو اللي كيبلوكي الأكسدة. جوج جيران ← ثانوي.

**2. -al vs -one ?**
$CHO$ (ALDÉHYDE) : UN bras libre → BOUT obligé. $CO$ (CÉTONE) : DEUX bras → MILIEU. La structure impose l'adresse : bout ($-al$) vs milieu ($-one$) — jamais l'inverse !
/ $CHO$ : يد وحدة حرة ← الطرف إجباري. $CO$ : جوج يدين ← الوسط. البنية كتفرض العنوان !

**3. $K \approx 4$ : pourquoi 67 % ?**
1-1 : $x^2/(1-x)^2 = 4$ → $x/(1-x) = 2$ → $x = 0{,}67$ → $\tau = 67$ %. $K = 4$ : le direct gagne 4-1 (pas KO !) : l'inverse (hydrolyse) survit → $1/3$ non transformé.
/ $x/(1-x) = 2$ ← $x = 0{,}67$. $K = 4$ : المباشر رابح 4-1 (ماشي بالضربة القاضية !) : العكسي باقي حي ← الثلث ما تفاعلش.

**4. Hydrolyse : pourquoi 33 % ?**
$K' = 1/K = 0{,}25$ (inverser → inverser $Q_r$ — P23 !) : 1-1 → $x/(1-x) = 0{,}5$ → $x = 1/3$ → $\tau = 33$ %. L'équilibre favorise l'ESTER (côté « réactifs » de l'hydrolyse !). 67 % dans un sens = 33 % dans l'autre.
/ $K' = 1/4$ : التوازن كيحبذ الإستر ! 67 % في اتجاه = 33 % في العكسي (ماشي 67-67 !).

**5. $H^+$ : change-t-il le bilan ?**
NON ! Catalyseur (P17) : plus VITE (minutes vs heures !), MÊME $K \approx 4$, même $\tau = 67$ % (1-1). « Plus vite, même bilan, non consommé » — $H^+$ = vitesse ; leviers du bilan : P27 (excès, élimination, anhydride) !
/ لا ! وسيط : أسرع (دقائق بدل ساعات !)، نفس $K$، نفس $\tau$. $H^+$ = السرعة ؛ رافعات الحصيلة : P27 !

**6. Athermique ?**
Quasi-athermique : $K \approx 4$ VARIE PEU avec $T$ (estérification : $\Delta H \approx 0$). Donc $T$ ↑ : guère d'effet sur $\tau$ (contrairement à P20-endo !) — mais ACCÉLÈRE (P17 : $T$ = vitesse !). $T$ : vitesse OUI, déplacement NON (ici !).
/ شبه-لا-حرارية : $K$ كتتبدل شوية مع $T$. إذن الحرارة : السرعة إيه (P17 !)، الإزاحة لا (هنا !).
