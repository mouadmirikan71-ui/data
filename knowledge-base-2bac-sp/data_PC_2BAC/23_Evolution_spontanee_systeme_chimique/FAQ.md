# FAQ — Chapitre 23 (Évolution spontanée)

**1. Oxydation : perte ou gain d'$e^-$ ?**
PERTE ! Le réducteur (généreux) DONNE ses $e^-$ et s'OXYDE. Mnémo : « perdre ses $e^-$ = s'oxyder » (donner = s'appauvrir). L'oxydant (affamé) MANGE et se RÉDUIT.
/ الفقدان ! المرجع (الكريم) كيعطي إلكتروناتو وكيتأكسد. «العطاء = الافتقار = الأكسدة». المؤكسد (الجيعان) كياكل وكيرجع.

**2. Équilibrer : quel ordre ?**
ATOMES d'abord (dont $H$ via $H^+$, $O$ via $H_2O$ en milieu acide), CHARGES ensuite (avec $e^-$ : dernier ajusteur !). Puis bilan : annuler les $e^-$ (multiplier si besoin !).
/ الذرات اللول (منها $H$ و $O$)، الشحنات من بعد (بالإلكترونات !). من بعد الحصيلة : إلغاء الإلكترونات.

**3. Le critère : nouveau ?**
NON — c'est P20 déguisé en redox ! $Q_{r,i} < K$ → DIRECT spontané ; $>$ → inverse ; $=$ → équilibre. UN SEUL critère pour trois chapitres (P20, P23, P24 !). $Q_{r,i}$ (initiales !) chasse $K$ — toujours.
/ لا — هو P20 متنكر في ريدوكس ! معيار واحد لثلاثة فصول. $Q_{r,i}$ كيطارد $K$ — ديما.

**4. $n$ : coefficients stœchio ?**
NON — $n$ = $e^-$ ÉCHANGÉS dans le bilan (Daniell : 2 !). $n$ compte les électrons qui VOYAGENT (dans le fil, P24 !). Un seul Zn libère DEUX $e^-$ → $n = 2$ (et $0{,}06/2 = 0{,}03$ !).
/ لا — $n$ = الإلكترونات المتبادلة في الحصيلة (دانيال : 2 !). $n$ كيحسب الإلكترونات اللي كتسافر (في السلك !).

**5. $K' = 1/K$ ?**
Constante du sens INVERSE : inverser l'équation → inverser $Q_r$ → $K' = 1/K$. Daniell inverse : $K' = 2{,}2\times10^{-37} \approx 0$ : IMPOSSIBLE spontanément (pas « lent » : ZÉRO !). La spontanéité a UN sens — pour forcer : P25 !
/ ثابتة الاتجاه العكسي : قلب المعادلة ← قلب $Q_r$ ← $K' = 1/K$. عكس دانيال ≈ 0 : مستحيل تلقائياً (ماشي «بطيء» : صفر !).

**6. Le métal dans $Q_r$ ?**
JAMAIS (solide ! — P20 : exclus). $Zn + Cu^{2+} \to$ : $Q_r = [Zn^{2+}]/[Cu^{2+}]$ — le Zn solide ne s'écrit pas. Doubler la lame de Zn : RIEN (comme doubler $CaCO_3$ en R2-P20 !).
/ أبداً (صلب !). الزنك الصلب ما كيتكتبش. مضاعفة الصفيحة : والو (بحال $CaCO_3$ !).
