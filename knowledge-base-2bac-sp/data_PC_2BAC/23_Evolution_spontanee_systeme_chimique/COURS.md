# Chapitre 23 — Évolution spontanée d'un système chimique

> 📋 **Exigible au bac (SI !)** : redox : couple $Ox/Red$ ($Ox + ne^- \rightleftharpoons Red$), OXYDATION = PERTE d'$e^-$ / RÉDUCTION = GAIN ; équilibrer : ATOMES puis CHARGES ($e^-$, $H^+$, $H_2O$ en milieu acide) ; CRITÈRE (le même que P20 !) : $\boxed{Q_{r,i} < K \to \text{DIRECT spontané}}$, $Q_{r,i} > K \to$ inverse ; $\boxed{\log K = n(E°_+ - E°_-)/0{,}06}$ ($n$ = $e^-$ ÉCHANGÉS !) ; sens inverse : $K' = 1/K$ (la spontanéité a UN sens !).

## 1. Accroche — le clou qui rouille et l'or qui brille 🔩✨

Un clou en fer rouille (attaqué !) ; un bijou en or reste intact (jamais attaqué !). Même air, même eau — mais le fer DONNE ses électrons (spontané !) et l'or les GARDE. Tout le chapitre : *écrire le redox (demi-équations + bilan), calculer $K$ (depuis $E°$), prédire (attaque ? protection ? sens ?).* Récolter le courant : P24 (piles) ; forcer l'inverse : P25 (électrolyse).

> بالدارجة : مسمار الحديد كيصدا (مهاجم !) ؛ خاتم الذهب كيبقى كيلمع (أبداً ما كيتهاجم !). نفس الهواء، نفس الماء — ولكن الحديد **كيعطي** إلكتروناتو (تلقائي !) والذهب **كيحافظ** عليهم. كاع الفصل : *كتب الأكسدة-إرجاع (نصف-المعادلات + الحصيلة)، حسب $K$ (من $E°$)، توقع (هجوم ؟ حماية ؟ اتجاه ؟).* جني التيار : P24 (الأعمدة) ؛ فرض العكس : P25 (التحليل الكهربائي).

## 2. Résumé du cours (exigible au bac)

**Couples redox.** $Ox + ne^- \rightleftharpoons Red$ : l'OXYDANT mange des $e^-$ (se réduit), le RÉDUCTEUR donne des $e^-$ (s'oxyde). OXYDATION = PERTE d'$e^-$ (réducteur → oxydant) ; RÉDUCTION = GAIN (oxydant → réducteur). Ex. : $Zn^{2+}/Zn$ ($Zn \to Zn^{2+} + 2e^-$), $Cu^{2+}/Cu$ ($Cu^{2+} + 2e^- \to Cu$).

**Équilibrer (milieu acide).** ATOMES d'abord (dont $H$ via $H^+$, $O$ via $H_2O$), CHARGES ensuite (avec $e^-$). Puis BILAN : additionner les demi-équations en ANNULANT les $e^-$ (multiplier si besoin !). Ex. Daniell : $Zn + Cu^{2+} \to Zn^{2+} + Cu$ (les $2e^-$ s'annulent !).

**Critère de spontanéité = P20 déguisé !** $\boxed{Q_{r,i} < K \to}$ sens DIRECT spontané ; $Q_{r,i} > K \to$ INVERSE ; $Q_{r,i} = K \to$ équilibre (rien !). LE MÊME TEST que P20 — appliqué au redox. $Q_{r,i}$ avec les INITIALES, solides exclus (métaux : hors $Q_r$ !).

**$K$ depuis $E°$.** $\boxed{\log K = n(E°_{(+)} - E°_{(-)})/0{,}06}$ ($n$ = $e^-$ ÉCHANGÉS dans le bilan !). Daniell : $\log K = 2\times1{,}10/0{,}06 = 36{,}7$ → $K = 4{,}6\times10^{36}$ (TOTALE !). Sens inverse : $\boxed{K' = 1/K}$ (Daniell inverse : $K' \approx 0$ : IMPOSSIBLE spontanément !).

**Attaque / protection.** Lame Zn dans $Cu^{2+}$ : $Q_{r,i} \ll K$ → DIRECT : Zn ATTAQUÉ (rongé !), Cu DÉPOSÉ. Lame Cu dans $Zn^{2+}$ : $Q'_{r,i} \gg K'$ → RIEN : Cu INTACT (voir R3 : Zn OUI, Cu NON !).

## 3. الشرح بالدارجة — الفهم قبل الحفظ 🇲🇦

**الثنائيات :** $Ox + ne^- \rightleftharpoons Red$ : المؤكسد **كياكل** الإلكترونات (كيرجع)، المرجع **كيعطيهم** (كيتأكسد). الأكسدة = **فقدان** الإلكترونات ؛ الإرجاع = **كسب**. مثال : $Zn^{2+}/Zn$، $Cu^{2+}/Cu$.

**الموازنة (وسط حمضي) :** الذرات **اللول** (منها $H$ عبر $H^+$، و $O$ عبر $H_2O$)، الشحنات **من بعد** (بالإلكترونات). من بعد الحصيلة : جمع نصف-المعادلات مع **إلغاء** الإلكترونات (ضرب إلا لزم !). مثال دانيال : $Zn + Cu^{2+} \to Zn^{2+} + Cu$.

**معيار التلقائية = P20 متنكر !** $\boxed{Q_{r,i} < K \to}$ المباشر تلقائي ؛ $>$ ← العكسي ؛ $=$ ← التوازن (والو !). **نفس الاختبار** ديال P20 — مطبق على الأكسدة-إرجاع. $Q_{r,i}$ بالابتدائية، الصلب مستبعد (المعادن : خارج $Q_r$ !).

**$K$ من $E°$ :** $\boxed{\log K = n\Delta E°/0{,}06}$ ($n$ = الإلكترونات **المتبادلة** في الحصيلة !). دانيال : $K = 4{,}6\times10^{36}$ (تام !). الاتجاه العكسي : $\boxed{K' = 1/K}$ (عكس دانيال : مستحيل تلقائياً !).

**الهجوم / الحماية :** صفيحة Zn في $Cu^{2+}$ : $Q_{r,i} \ll K$ ← المباشر : Zn **مهاجم** (متآكل !)، Cu **مترسب**. صفيحة Cu في $Zn^{2+}$ : والو — Cu **سالم** (R3 : Zn إيه، Cu لا !).

## 7. Pièges classiques + mots-clés ⚠️

- 🪤 **« Oxydation = gain d'$e^-$ »** : NON — OXYDATION = PERTE (le réducteur s'oxyde en PERDANT !). Mnémo : « perdre ses $e^-$ = s'oxyder » (comme perdre : s'appauvrir).
- 🪤 **Équilibrer charges AVANT atomes** : ATOMES d'abord ($e^-$ en dernier ajusteur !). L'ordre compte : atomes → $H^+$ → $H_2O$ → $e^-$.
- 🪤 **$n$ = coefficients stœchio** : NON — $n$ = $e^-$ ÉCHANGÉS dans le bilan (Daniell : 2, pas 1 !). $n$ compte les électrons qui VOYAGENT.
- 🪤 **« Attaque symétrique » (Cu attaqué comme Zn)** : $K' = 1/K \approx 0$ : l'inverse est IMPOSSIBLE — la spontanéité a UN SENS (R3 !).
- Mots-clés : *Ox mange/Red donne, atomes PUIS charges, bilan ($e^-$ annulés !), $Q_{r,i}$ vs $K$ (P20 !), $\log K = n\Delta E°/0{,}06$, $K' = 1/K$.*

## 9. Le « pourquoi » profond — pourquoi ça part tout seul 🔬

**Pourquoi l'oxydant MANGE-t-il ?** Le potentiel $E°$ = « faim d'électrons » : $Cu^{2+}$ affamé ($+0{,}34$ V) aspire les $e^-$ du zinc repu ($-0{,}76$ V). Le redox spontané = les $e^-$ vont du REPUS vers les AFFAMÉS (comme l'eau coule vers le bas !). **$E = E(+) - E(-)$ (P24) = la différence de faim = la force du courant.**

**Pourquoi $\log K = n\Delta E°/0{,}06$ ?** Deux visages d'une énergie : $\Delta G° = -nFE°$ (électrique) $= -RT\ln K$ (chimique) → $\ln K = nFE°/RT$ → à 25 °C : $\log K = n\Delta E°/0{,}06$. **$K$ (chimie) et $E°$ (élec) disent la MÊME chose (la pente thermodynamique) en deux langues — d'où la passerelle.**

**Pourquoi l'inverse est-il IMPOSSIBLE (pas juste lent) ?** $K' = 1/K$ : Daniell inverse $K' = 2{,}2\times10^{-37}$ — l'équilibre est à $10^{-37}$ : RIEN ne se produit (pas « lentement » : ZÉRO !). **Thermodynamique $\neq$ cinétique : $K' \approx 0$ = interdit (pas lent) — pour forcer : P25 (générateur externe !).**

**Liens croisés :** P19/P20 — LE test ($Q_r$ vs $K$ : un seul critère, trois chapitres !) ; P24 — récolte (la pile = spontané canalisé !) ; P25 — l'ENVERS (forcer $Q_r$ LOIN de $K$ : non-spontané imposé) ; M05 — $\log K$ (le langage !) ; corrosion/protection (Zn sur fer : galvanisation !).

## 10. Les 3 confusions qui coûtent des points 😵

**1. « Oxydation = gain d'oxygène/$e^-$. »** Non : OXYDATION = PERTE d'$e^-$ (le nom vient de l'oxygène historique, la définition est électronique !). **Le déclic :** *le réducteur (généreux) DONNE et s'OXYDE — donner = s'appauvrir = s'oxyder. Généreux oxydé, affamé réduit.*

**2. « $n = 1$ (Daniell). »** Non : UN Zn libère DEUX $e^-$ ($Zn \to Zn^{2+} + 2e^-$) → $n = 2$ ! $n$ = $e^-$ du BILAN (qui voyagent), pas nombre d'atlas. **Le déclic :** *$n$ compte les électrons dans le FIL — un seul Zn en envoie 2 : $n = 2$, et $0{,}06/2 = 0{,}03$ (P24 !).*

**3. « $Q_{r,i} > K$ → direct quand même (un peu). »** Non : $>$ → INVERSE (ou rien si déjà à l'éq du mauvais côté — R3b : RIEN !). Le critère est BINAIRE : $<$ direct, $>$ inverse, $=$ stop. **Le déclic :** *$Q_r$ chasse $K$ (P20) : au-dessus, il DESCEND (inverse) — jamais « un peu direct ». Le chasseur ne fait pas demi-tour à moitié.*
