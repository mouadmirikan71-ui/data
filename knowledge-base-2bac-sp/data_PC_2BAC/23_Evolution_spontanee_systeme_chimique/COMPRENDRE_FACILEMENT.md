# How to understand this chapter the easy way — 23 Évolution spontanée

> بصوت الأستاذ فالقسم : الجيعان كياكل والشبعان كيعطي — 5 خطوات والتلقائية كتولي توقع.

## الخطوة 1 — الجيعان/الشبعان : المؤكسد كياكل، المرجع كيعطي ($e^-$)

الجهد $E°$ = «الجوع» للإلكترونات : $Cu^{2+}$ الجيعان ($+0{,}34$) كيمص الإلكترونات من Zn الشبعان ($-0{,}76$). التفاعل التلقائي = الإلكترونات كتمشي من **الشبعان للجيعان** (بحال الماء كيهبط لتحت !).

**الأكسدة = الفقدان** (المرجع الكريم كيعطي وكيتأكسد — العطاء = الافتقار = الأكسدة !). **الإرجاع = الكسب** (المؤكسد الجيعان كياكل وكيرجع). الكريم متأكسد، الجيعان مرجع — حفظ هاد الجملة !

## الخطوة 2 — الموازنة : الذرات اللول، الشحنات من بعد !

الترتيب إجباري : الذرات (منها $H$ عبر $H^+$، و $O$ عبر $H_2O$ في الوسط الحمضي) ← **من بعد** الشحنات (بالإلكترونات : آخر ضابط !).

ومن بعد الحصيلة : جمع نصف-المعادلتين مع **إلغاء** الإلكترونات (ضرب إلا كان العدد مختلف !). دانيال : $Zn + Cu^{2+} \to Zn^{2+} + Cu$ (الـ $2e^-$ تلغاو !). **الإلكترونات ما كتبانش في الحصيلة** — كتسافر في السلك (P24 !).

## الخطوة 3 — المعيار : نفس P20 (متنكر في ريدوكس !)

$Q_{r,i} < K$ ← المباشر **تلقائي** ؛ $>$ ← العكسي ؛ $=$ ← التوازن (والو !). **نفس اختبار P20** — غير مطبق على الأكسدة-إرجاع ($Q_r$ كيطارد $K$ — ديما !).

$Q_{r,i}$ بالتراكيز **الابتدائية**، والمعادن **خارج** $Q_r$ (صلبة !). $Zn + Cu^{2+} \to$ : $Q_r = [Zn^{2+}]/[Cu^{2+}]$ — الزنك الصلب ما كيتكتبش !

## الخطوة 4 — $K$ من $E°$ : $\log K = n\Delta E°/0{,}06$ ($n$ = إلكترونات الحصيلة !)

دانيال : $n = 2$ (ذرة Zn وحدة كتحرر **جوج** إلكترونات !) ← $\log K = 2\times1{,}10/0{,}06 = 36{,}7$ ← $K = 4{,}6\times10^{36}$ (تام !).

**$K$ (الكيمياء) و $E°$ (الكهرباء) كيقولو نفس الشي** (المنحدر الترموديناميكي) بجوج لغات — لهذا القنطرة بيناتهم. و $n$ = الإلكترونات اللي **كتسافر في السلك** — ماشي المعاملات !

## الخطوة 5 — الهجوم : Zn إيه، Cu لا (التلقائية عندها اتجاه واحد !)

صفيحة Zn في $Cu^{2+}$ : $Q_{r,i} = 100 \ll K = 10^{36}$ ← المباشر : Zn **مهاجم** (متآكل !)، Cu **مترسب** (المحلول كيشحب !).

صفيحة Cu في $Zn^{2+}$ : الاتجاه العكسي $K' = 1/K \approx 0$ ← $Q'_{r,i} \gg K'$ ← **والو** : Cu سالم. **$K' = 1/K$ : العكس شبه-مستحيل** — ماشي «بطيء» : **صفر** ! (بغيتي تفرضو ؟ P25 : مولد خارجي !)

## ✅ خلاصة الخطوات (راجعها ليلة الوطني)

1. الجيعان كياكل / الشبعان كيعطي (الأكسدة = فقدان !).
2. الذرات ← $H^+$ ← $H_2O$ ← $e^-$ (الحصيلة : إلغاء $e^-$ !).
3. $Q_{r,i}$ مقابل $K$ (نفس P20 ! + المعادن خارج !).
4. $\log K = n\Delta E°/0{,}06$ ($n$ = إلكترونات السلك !).
5. $K' = 1/K$ : اتجاه واحد (Zn إيه، Cu لا !).
