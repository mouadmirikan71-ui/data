# Exercices types — Atome et mécanique de Newton (P16)

## Méthode — quanta en 5 gestes 🧭

1. $E = hc/\lambda$ (J !) — convertir eV $\leftrightarrow$ J.
2. Photoélectrique : $h\nu = W_0 + E_c$, seuil $\nu_0 = W_0/h$.
3. Niveaux : $E_n = -13,6/n^2$ eV + diagramme fléché.
4. Bas = émission (donne), haut = absorption (prend pile $\Delta E$).
5. Ionisation : $E \geq |E_n|$ → excès en $E_c$.

## R1 — TYPE-BAC (la couleur = l'énergie)

🏷️ matière=PC · année=— · session=— · chapitre=P16 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** Photon rouge $\lambda = 700$ nm vs bleu $450$ nm. Énergies en eV ?

**Corrigé-type.** $E = hc/\lambda$ : rouge $= 1,99\times10^{-25}/7,0\times10^{-7} = 2,84\times10^{-19}$ J $= \boxed{1,77\text{ eV}}$ ; bleu $= 4,41\times10^{-19}$ J $= \boxed{2,76\text{ eV}}$. Le bleu est $\times 1,56$ plus énergétique !
🪤 *Piège testé : $\lambda$ en nm dans $hc/\lambda$ (→ $10^{-16}$ J, $\times 10^9$ !) — $\lambda$ en MÈTRES : $700$ nm $= 7,0\times10^{-7}$ m.*

## R2 — TYPE-BAC (photoélectrique, 2 méthodes !)

🏷️ matière=PC · année=— · session=— · chapitre=P16 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** Métal $W_0 = 2,0$ eV éclairé à $\lambda = 400$ nm. $E_{c,max}$ ? $v_{max}$ ($m_e = 9,11\times10^{-31}$ kg) ?

**Corrigé-type — Méthode 1 (énergies).** $E_{ph} = hc/\lambda = 3,10$ eV → $E_c = 3,10-2,0 = \boxed{1,10\text{ eV}} = 1,77\times10^{-19}$ J → $v = \sqrt{2E_c/m_e} = \boxed{6,2\times10^5\text{ m/s}}$.
**Corrigé-type — Méthode 2 (fréquences).** $\nu_0 = W_0/h = 4,83\times10^{14}$ Hz ; $\nu = c/\lambda = 7,50\times10^{14}$ Hz → $E_c = h(\nu-\nu_0) = 6,63\times10^{-34}\times2,67\times10^{14} = \boxed{1,77\times10^{-19}\text{ J}}$ ✓.
🪤 *Piège testé : $\lambda = 700$ nm (rouge, $1,77 < 2,0$ eV) « $E_c$ négative » — en DESSOUS du seuil : $E_c = 0$, RIEN ne sort (pas de $E_c$ négative !).*

## R3 — TYPE-BAC (H$\alpha$ + Lyman $\alpha$)

🏷️ matière=PC · année=— · session=— · chapitre=P16 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** a) Transition $3 \to 2$ : $\Delta E$, $\lambda$, couleur ? b) $2 \to 1$ ?

**Corrigé-type.** a) $\Delta E = -1,51+3,40 = 1,89$ eV → $\lambda = hc/E = 1,99\times10^{-25}/3,03\times10^{-19} = \boxed{656\text{ nm}}$ (rouge H$\alpha$ ✓). b) $\Delta E = 10,2$ eV → $\lambda = \boxed{122\text{ nm}}$ (UV, Lyman $\alpha$).
🪤 *Piège testé : $3 \to 2$ « absorption » — $n$ DIMINUE = l'atome DONNE = ÉMISSION. Bas = donne !*

## R4 — TYPE-BAC (ionisation : le photon de trop)

🏷️ matière=PC · année=— · session=— · chapitre=P16 · type=ENTRAÎNEMENT · fidélité=n.a. · niveau=— · barème=—

**Énoncé.** H dans l'état $n = 2$. a) Énergie d'ionisation ? b) Photon $5,0$ eV : que se passe-t-il ? c) Même photon sur H fondamental ?

**Corrigé-type.** a) $E_{ion} = 0-(-3,40) = \boxed{3,40\text{ eV}}$. b) $5,0 > 3,40$ → IONISE : $E_c = 5,0-3,40 = \boxed{1,6\text{ eV}}$ (l'excès part en cinétique — continuum !). c) Fondamental : écarts $10,2$ / $12,1$ eV $\neq 5,0$ et $< 13,6$ → $\boxed{\text{transparent, RIEN}}$ (ni absorption ni ionisation !).
🪤 *Piège testé : c) « absorbe 5,0 eV » — absorption = EXACTEMENT $\Delta E$ (raie !) : entre deux niveaux, l'atome est TRANSPARENT.*
