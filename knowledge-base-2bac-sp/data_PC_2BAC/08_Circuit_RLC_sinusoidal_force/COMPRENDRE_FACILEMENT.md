# How to understand this chapter the easy way — 08 RLC force 📻

> بصوت الأستاذ فالقسم : الراديو ! الدائرة ما كتسمع مزيان غير تردد واحد — ملي كيطابق التردد الخاص ← **الرنين** : التيار عظمى ! هاد القسم كيبني الفهم خطوة بخطوة بالدارجة.

## 1. Le vrai probleme — شكون كيفرض التردد ؟
فالنظام **الحر** الدائرة كتهتز بترددها الخاص ($\omega_0 = 1/\sqrt{LC}$) وكتموت (Joule). فالنظام **القسري** المولد GBF كيفرض $u = U_m\cos(\omega t)$ **بصفة دائمة** والدائرة **كتجاوب** بنفس $\omega$ : $i = I_m\cos(\omega t - \varphi)$. المشكل : **كيفاش $I_m$ و$\varphi$ كيتبدلو مع $\omega$ ؟** الجواب : كلشي كيتفجر... فـ $\omega_0$ !

## 2. La carte avant les details — الخريطة (4 نقط)
1. **المعاوقة $Z$** : $Z = U_m/I_m = \sqrt{(R+r)^2 + (L\omega - 1/C\omega)^2}$ — مقاومة معممة كتبدل مع $\omega$ !
2. **فرق الطور $\varphi = \varphi_u - \varphi_i$** : موجب = تحريضي ($u$ سابقة)، سالب = سعوي ($i$ سابقة) !
3. **الرنين ($\omega = \omega_0$)** : $Z$ صغرى ($= R+r$)، $I$ عظمى، $\varphi = 0$ — المنحنى $I(f)$ = **جرس** !
4. **$Q$ والنطاق** : $Q = f_0/\Delta f$ — كبير = انتقائي (راديو مزيان) + **فرط التوتر** ($U_C = Q \cdot U$) !

## 3. Le « pourquoi » — علاش هكذا ؟
**علاش الرنين فـ $\omega_0$ بالضبط ؟** حيت التبادل الطبيعي للطاقة ($E_e \leftrightarrow E_m$) **متزامن** مع دفعات المولد : كل دفعة كتجي فالوقت المناسب وكتزاد (الارجوحة : دفع بالايقاع !). خارج $\omega_0$ المولد كيدفع ضد الايقاع ← **عدم الاتفاق** = فرق الطور $\varphi$ !
**علاش $Z$ صغرى ؟** $L$ (كتعاكس التغيرات السريعة) و$C$ (كيعاكس البطيئة) **تأثيرين متعاكسين** — فـ $\omega_0$ كيتلغاو بالضبط ($L\omega_0 = 1/C\omega_0$) : كيبقى غير الاحتكاك الخالص $R+r$ !

## 4. L'analogie qui colle — الراديو والارجوحة 📻
**الراديو** : دوّر الزر ← محطة وحدة واضحة ($f_0$) والباقي تشويش ! الدائرة « كتسمع » غير التردد اللي كيطابق ترددها الخاص. **والانتقائية** = النطاق الضيق ($Q$ كبير) : محطة وحدة صافية !
**الارجوحة** : دفع **بالايقاع** ← كطلع فوق (رنين !)؛ دفع عشوائي ← ما كتحركش (عدم الاتفاق $\varphi$ !). **القاعدة** : ملي تشوف $L\omega = 1/C\omega$ ← **رنين** : $Z = R+r$، $I$ عظمى، $\varphi = 0$ !

## 5. Les pieges a eviter — الأخطاء اللي كتقتل النقاط
1. **« $Z$ عظمى فالرنين »** ← غلط ! $I$ عظمى = $Z$ **صغرى** ! (الرنين = الدائرة كتفتح والتيار كيهجم !)
2. **إشارة $\varphi$** ← $\varphi = \varphi_u - \varphi_i$ ($u$ ناقص $i$ !) — الغلط = تحريضي/سعوي معكوس !
3. **$\omega$ و$f$** ← $1/\sqrt{LC}$ = $\omega_0$ (rad/s) — قسم على $2\pi$ باش تجيب $f_0$ !
4. **النطاق** ← كيتقرا فـ $I_{max}/\sqrt{2}$ (ماشي $I_{max}/2$ !) — $-3$ dB = نص الاستطاعة !
5. **العظمى والفعالة** ← الراسم = $U_m$؛ الفولطمتر والاستطاعة = $U_{eff} = U_m/\sqrt{2}$ !

## 6. Exemple resolu commente (2 min)
**RLC : $R+r = 30\,\Omega$, $L = 0{,}10$ H, $C = 10\,\mu$F, $u = 6\cos(1000t)$.** $\omega = 1000$ ؛ $L\omega = 100$ ؛ $1/C\omega = 100$ ← **تساواو = رنين !** $Z = 30\,\Omega$ ؛ $I_m = 6/30 = 0{,}20$ A ؛ $\varphi = 0$ ؛ $i = 0{,}20\cos(1000t)$ (في الطور !). $Q = L\omega_0/30 = 3{,}3$ ← $U_C = 3{,}3 \times 6 \approx 20$ V (فرط التوتر !). **الدرس** : $L\omega = 1/C\omega$ ملي تشوفها ← كلشي كيسهال (رنين !).
