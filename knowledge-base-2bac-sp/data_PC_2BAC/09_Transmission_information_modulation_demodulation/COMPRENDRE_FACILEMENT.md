# How to understand this chapter the easy way — 09 Transmission & modulation 📡

> بصوت الأستاذ فالقسم : المعلومة كتسافر ! المرسل ← القناة ← المستقبل — والتضمين هو اللي كيركب الصوت على الموجة، وكاشف الغلاف هو اللي كيرجعو ! هاد القسم كيبني الفهم خطوة بخطوة بالدارجة.

## 1. Le vrai probleme — كيفاش الصوت كيوصل بعيد ؟
الصوت ($f_s \sim$ kHz) ما يمكنش يتبث مباشرة (الهوائي خاصو يكون **300 km** !). الحل : **التضمين** — نركبو الصوت على سعة موجة حاملة ($F_p \sim$ MHz) كتبث بهوائي صغير ! ومن بعد فالراديو : **إزالة التضمين** (كاشف الغلاف : ديود + RC) كيرجع الصوت الأصلي ! المشكل : **شروط الجودة** ($\tau < 1$، $F_p \geq 10f_s$، $T_p \ll RC \ll T_s$) !

## 2. La carte avant les details — الخريطة (5 نقط)
1. **السلسلة** : مرسل ← قناة (حرة ولا موجهة) ← مستقبل — الأعداء : التوهين والضجيج !
2. **شانون** : $f_e \geq 2f_{max}$ — التقطيع الرقمي (CD : 44,1 kHz !).
3. **الفايبر** : الانعكاس الكلي ($\sin i_c = n_2/n_1$) — **صفر ضياع** !
4. **التضمين AM** : الغلاف = المعلومة ($\tau = S_m/U_0 < 1$ + $F_p \geq 10f_s$) !
5. **كاشف الغلاف** : ديود (كيحيد السالب) + RC (كيتبع الغلاف : $T_p \ll RC \ll T_s$) !

## 3. Le « pourquoi » — علاش هكذا ؟
**علاش كانضمّنو ؟** (1) الهوائي : $f_s$ صغيرة ← $\lambda$ عملاقة (300 km !) — مستحيل ! (2) الفرز : كل محطة عندها $F_p$ ديالها (الراديو كيختار بالرنين — P08 !). التضمين = النقل ممكن + الفرز ممكن !
**علاش $T_p \ll RC \ll T_s$ ؟** المكثف خاصو يكون **بطيء** قدام الحاملة (ما يتبعش كل اهتزازة : $RC \gg T_p$ ← تنعيم) و**سريع** قدام الغلاف (يتبع الطلعات والنزلات : $RC \ll T_s$). $RC$ = **المساومة** بين التنعيم والتتبع !

## 4. L'analogie qui colle — الظرف والرسالة ✉️
**التضمين** : الرسالة (الصوت) كتحطها فـ **ظرف** (الحاملة) باش تسافر ! الغلاف ديال الإشارة = **الظرف** — والداخل (التموجات السريعة) ما كيهمش ! **إزالة التضمين** : كتحل الظرف (الديود كيحيد التحت) وكتقرا الرسالة (RC كيتبع الغلاف) ! **القاعدة** : ملي تشوف تضمين ← قلب على **الغلاف** ($U_M$ و$U_m$) : $\tau = (U_M-U_m)/(U_M+U_m)$ !

## 5. Les pieges a eviter — الأخطاء اللي كتقتل النقاط
1. **البت والبايت** ← $1$ o $= 8$ b ! 10 Mo/s $\neq$ 10 Mb/s (العامل 8 !) — قرا الوحدة قبل ما تقسم !
2. **اتجاه $i_c$** ← $\sin i_c = n_2/n_1$ ($n_1 > n_2$ : الانطلاق من **الكثيف** !) — $\sin > 1$ مستحيل = مقلوب !
3. **الديسيبيل بلا log** ← dB = $10\log$ ديماً ! ($\times 2$ = $+3$ dB ماشي $+6$ !)
4. **متراجحة وحدة فكاشف الغلاف** ← خاص **بجوج** ($T_p \ll RC$ **و** $RC \ll T_s$) ! وحدة ما كافية !
5. **القص والتموج معكوسين** ← $RC$ كبير = كسول (كيقص !)؛ $RC$ صغير = عصبي (كيتموج !)

## 6. Exemple resolu commente (2 min)
**AM : $F_p = 100$ kHz، $f_s = 1$ kHz؛ $R = 10$ k$\Omega$، $C = 10$ nF.** $T_p = 10\,\mu$s ؛ $T_s = 1$ ms ؛ $RC = 0,10$ ms ← $10 \ll 100 \ll 1000$ ($\mu$s) : **بجوج المتراجحات محققين** ← إزالة جيدة ! ($RC/T_p = 10$ : تنعيم ✓؛ $T_s/RC = 10$ : تتبع ✓). إلا بدلنا $C$ بـ $1\,\mu$F ← $RC = 10$ ms $> T_s$ ← **قص** (النزلات مسطحة !). **الدرس** : $RC$ خاصو يكون **بين** الدورين — حسب النسب ($RC/T_p$ و$T_s/RC$ : $\geq 10$ !).
